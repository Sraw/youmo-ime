# v0.3.0 的 UAT（发版门槛）

2026-10-19，x86_64 发布包（R8 之后的代码，包名 io.github.sraw.youmo），`UAT_BUILD=release uat/tools/uat.py run`。
包是 `4439941a` 加上发版前的修复（最下面一排字母的大小写、KB-39、测试脚本），版本名还是 `0.2.0-32-g4439941a`。
全部用例都跑了（0.2.0 以来每个功能区都改过）：redroid 两台跑文字版，模拟器跑实体键盘和语音版。

- 文字版（redroid）：436 条，通过 373，跳过 61（实体键盘、语音，在模拟器上跑），阻塞 2：
  SET-10（要上游 Fcitx5 导出的数据）、KB-21（测试浏览器不处理“下一项”），两条每次都阻塞，和这个版本无关。
- 实体键盘（模拟器）：35 条，通过 32，跳过 3。
- 语音版（模拟器）：17 条，全部通过（VO-12 模拟器麦克风丢帧，重跑通过）。
- 第一遍的失败和阻塞查下来是测试的问题，已改测试后重跑通过：PY-52 用了宿主的日期（redroid 是 UTC）、
  ST-32 的设置项被上面变长的说明挤到屏幕外、导入的文件被之前导出的文件挤到选择器下面、ST-08 把发布包默认主题
  的蓝色回车键当成了图片、SET-01 设备上同时装着 debug 和发布包、TB-22 截图早于按键气泡；其余是“等键盘超时”的偶发。
- 发布包上新发现的问题：没开 Shift 时最下面一排字母显示成大写（加 `;` 键带出的），已修，加了 KB-39（P0）。
- 覆盖升级：redroid 上装 0.2.0 的 arm64 发布包，学一个词（油墨输入法），再装 0.3.0 的 arm64 包覆盖：学到的词还在首位，照常打字。
- 插桩测试（模拟器）：70 条全部通过（改了两处测试跟上 0.3.0：本应用自己的输入框不学词、九键严格连按）。
