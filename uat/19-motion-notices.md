# 提示条、动画、始终显示悬浮条、候选字号

规则见 [specs/app.md](../specs/app.md) 的提示一节；用户文档 [键盘](../docs/keyboard.md) 的提示和悬浮键盘两节、[设置](../docs/settings.md) 的外观一节。

## 提示条

### MN-01 [P0] 提示从键盘上沿出来，点一下收起，没人管两秒后自己走
- **前提**：B0，在「长文本」框。
- **操作**：工具栏 → 文本编辑 → 全选 → 复制；看提示；点一下提示；再复制一次，不碰它，等 3 秒。
- **预期**：「已复制」出现在键盘上方、紧贴键盘上沿，不盖候选栏（截图看：从键盘里滑出、淡入）；点一下立刻收起；不碰它的那次 2 秒多就没了。
- **JVM**：`BarUatTest.noticeAboveKeysTapAndTimeout`（提示出来、点一下收起、不碰 2 秒多自己走，虚拟时钟）；设备上不跑。位置由 ime-core 的 `UndoChipPlacement` 测；滑入、淡入的动画发版时人工看一眼。

### MN-02 [P1] 「不用我的输入习惯」关和开都提示，新提示替换旧提示
- **前提**：B0。
- **操作**：工具栏 → ⋯ → **不用我的输入习惯**；提示还在时马上再点一次（恢复）。
- **预期**：第一次提示「已不用我的输入习惯，在 ⋯ 里恢复」；第二次换成「已恢复用我的输入习惯」，屏幕上同时只有一条提示。
- **JVM**：`MotionNoticeUatTest.habitsOffAndOnEachSaidTheNewInTheOldsPlace`（关、开各说一次，新提示在旧提示的位置）；设备上不跑。

### MN-03 [P1] 悬浮键盘的提示在键盘朝屏幕中间的一侧：贴顶在下方，横屏贴左在右侧
- **前提**：B0，状态面板里打开 **悬浮键盘**，拖着横条把键盘拖到屏幕最上面。
- **操作**：工具栏 → 文本编辑 → 全选 → 复制。再转横屏，拖着横条把键盘拖到屏幕最左边，再复制一次。
- **预期**：「已复制」在悬浮键盘的**下面**（朝屏幕中间），不在屏幕外，也不盖键盘。横屏贴左时提示在键盘**右侧**，整条在屏幕里，不压键。
- **JVM**：`MotionNoticeUatTest.floatingAtTheLeftTheNoticeGoesRight`（悬浮键盘靠左时提示往右，靠上时在下面（另见 floatingAtTheTopTheNoticeGoesBelow））；设备上不跑。

### MN-04 [P1] 剪贴板删条目用同一个提示条撤销，配色跟着主题
- **前提**：B0，复制过「公园」。
- **操作**：工具栏 → 剪贴板，长按「公园」→ 删除；看提示；点 **撤销**。再在系统深色模式下做一遍。回到浅色，再复制「散步」，在剪贴板里把「散步」向右滑掉，提示还在时长按「公园」→ 删除，点 **撤销**。
- **预期**：提示和别的提示同一个样子、同一个位置（不是屏幕底部的黑条）；「撤销」是文字按钮，和提示底色同一块，不是另贴的色块；点了以后「公园」回来。亮、暗两种主题下截图都协调、看得清。滑掉「散步」提示「已删除 1 项」，接着删「公园」同一条提示变成「已删除 2 项」，点 **撤销** 两条都回来。
- **JVM**：`MotionNoticeUatTest.clipboardDeleteUndoneOnTheNoticeInEitherTheme`（亮暗主题下删条目都在同一提示条上撤销，接连删两条变成已删除 2 项、一起撤销）；设备上不跑。

## 始终显示悬浮条

### MN-10 [P1] 打开后停靠的键盘也有悬浮条，按键高度不变
- **前提**：B0-设置。
- **操作**：**外观 → 大小与样式** 打开 **始终显示悬浮条**；回测试页点「普通文本」框；再把 **悬浮键盘拖动条** 改成"上面"看。
- **预期**：停靠的键盘下面（改成上面后在按键上面）多一条带短横的条，右端什么都没有；按键行和没开时一样高，整个键盘高出那一条。
- **JVM**：`MotionNoticeUatTest.theDockedHandleUnderOrOverTheKeysTheKeysAsTall`（停靠时悬浮条在下或在上，按键高度不变）；设备上不跑。

### MN-11 [P0] 长按悬浮条中间脱离成悬浮键盘，手指不松接着拖
- **前提**：同 MN-10，悬浮条在下面。
- **操作**：按住条中间的短横不动，觉得一震后不松手往上拖到屏幕中间，松手；再拖着横条往下拖到屏幕底部松手。再长按短横，一震后不松手稍往上再一路拖进屏幕底部那条空位松手；然后 ⋯ → **悬浮键盘**。
- **预期**：长按后键盘变成悬浮的小键盘，在手指下面跟着手指走，松手停在屏幕中间；拖到底部松手又放回底部，悬浮条还在。第二次长按后不松手拖进底部空位，松手就放回底部；再悬浮时回到第一次停的屏幕中间。
- **JVM**：`MotionNoticeUatTest.aLongPressOnTheHandleLetsItFloatUnderTheFinger`（长按悬浮条脱离成悬浮键盘并跟着手指）；设备上不跑。

### MN-12 [P2] 单手模式时悬浮条和键盘一样宽
- **前提**：同 MN-10；状态面板里打开 **单手模式**。
- **操作**：看悬浮条。
- **预期**：悬浮条只有靠边那块键盘那么宽，短横在那块键盘的正中。
- **JVM**：`MotionNoticeUatTest.oneHandedTheHandleAsWideAsTheKeyboard`（单手时悬浮条和键盘一样宽）；设备上不跑。

### MN-13 [P2] 读屏时用把手分离的悬浮键盘，转屏、换主题后还在原处
- **前提**：同 MN-10；能开 TalkBack 的真机或模拟器（redroid 没有 TalkBack），打开 TalkBack。
- **操作**：在「普通文本」框里让键盘出来；用 TalkBack 选中悬浮条的把手，双击并按住（读屏把它当一次长按，没有手指可拖，键盘在原处脱离成悬浮的）；记下悬浮键盘的位置；转屏再转回来；再换一个主题（或切夜间模式）回来看。
- **预期**：双击按住后键盘变成悬浮键盘，停在脱离的地方；转屏和换主题后悬浮键盘仍在原处，没有跳回底部或别的位置。

## 候选字号

### MN-20 [P1] 候选字号调大调小，候选栏跟着变，按键不变
- **前提**：B0-设置。
- **操作**：**外观 → 大小与样式 → 候选字号** 拉到最大（28 sp）；回测试页在「普通文本」框打「公园」，选中复制，让剪贴板有条目；打 n i h a o 看候选栏，点 ⌄ 展开看；再打开剪贴板面板看左上的返回键盘和右上的清空，打开状态区域看设置键，打开文本编辑面板看剪贴板键；每种字号下打字前都点空闲栏的 › 展开工具栏看一眼再收起；再把字号拉到最小（14 sp），打字前先看空闲栏的几个键，再同样看一遍。
- **预期**：28 sp 时候选字明显变大、候选栏变高，展开的候选格子里字也变大；展开的候选格子一行也变高；14 sp 时都变小，打字前空闲栏的 ›（展开工具栏）、表情、语音输入（语音版）、收起键盘几个键完整、每个不窄于 40 dp，两种字号下展开的工具栏五个键（撤销、重做、文本编辑、剪贴板、状态区域）都完整、和栏一样高；14 sp 时每个不窄于 40 dp，28 sp 时屏幕窄放不下可以挤窄，但不窄于 28 dp（再窄就改成左右滑动）；候选栏右边的 ⌄ 和剪贴板面板的返回键盘仍完整、不被裁；剪贴板面板的清空、状态区域的设置键、文本编辑面板的剪贴板键两种字号下也都完整、和栏一样高、图标居中，14 sp 时不窄于 40 dp；按键行的高度两次都一样（整个键盘跟着候选栏高矮）。设置里实体键盘那一项叫 **浮动候选窗字号**，和这一项分开（名字由 ST-33 查）。
- **JVM**：`BarUatTest.candidateTextSizeChangesBarNotKeys`（28/14 sp 下栏变高变矮、按键行一样高、空闲栏和工具栏的键不窄于 40/28 dp，剪贴板的清空、状态区域的设置、文本编辑的剪贴板和栏一样高；四张图）；设备上不跑。

### MN-22 [P1] 外观页预览的候选栏跟着候选字号变高变矮
- **前提**：B0-设置。
- **操作**：**外观 → 大小与样式**，看本页上方的键盘预览；把 **候选字号** 拉到最大（28 sp），确定；再看预览；再拉到最小（14 sp），确定，再看。
- **预期**：28 sp 时预览的候选栏马上变高（按键行跟着往下挪），14 sp 时变矮；不用离开本页；预览按键行的高度三次都一样。

### MN-23 [P1] 候选字号小时候选之间更紧，第一页放得下更多
- **前提**：B0-设置。
- **操作**：**候选字号** 设 20 sp，在「普通文本」框打 n i h a o，数候选栏上不展开能看到几个候选；再设 14 sp，同样数；再设 28 sp 看一眼。
- **预期**：14 sp 时看到的候选比 20 sp 时多；候选之间的空隙随字号变小变大；单个字的候选也不会窄到难点（至少 32 dp）；候选少到一行放得下时靠左挨着排，不会摊满整栏。
- **JVM**：`BarUatTest.candidateSpacingFollowsTextSize`（14/20/28 sp 时每个候选左右留白 6/9/10 dp（最多 10 dp），单字量出的宽不小于 32 dp、放得下时不拉宽）；`CandidateSpacingTest` 按候选栏打包的模型（不是真实候选栏）算 nihao 第一页 14/20/28 sp 放 10/8/6 个，真实个数看设备。

### MN-21 [P2] 横屏时候选字号最大也不超过约七成
- **前提**：同 MN-20 拉到 28 sp，**始终显示悬浮条** 打开；**键盘高度** 选"很高"。
- **操作**：转横屏，回测试页点「普通文本」框。
- **预期**：整个键盘区（候选栏、悬浮条、按键）最多占屏幕高度约七成（封顶优先，同 LS-27；脚本只量这个上限），按键被压矮（截图看）。
- **JVM**：`MotionNoticeUatTest.landscapeLargestCandidatesStillCappedAtSevenTenths`（横屏最大候选字号时仍不超过七成高）；设备上不跑。
