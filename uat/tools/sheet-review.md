# 看拼图（给看图的人或代理）

`uat.py run` 把每组里要看图的用例拼成一张图：`dev/uat-out/<run>/sheet-<组>.png`。每格上面写着
用例编号、这张图是哪一步拍的，和这条用例的「预期」原文；图是裁过、缩小过的屏幕（候选栏和键盘、
一个设置页、或预览）。

做法：

1. 读一遍这份说明（所有看图的代理都先读它，启动提示一字不差，见 `uat/README.md`「用代理看拼图」）。
2. 打开分给你的那张拼图（启动提示最后一行写着路径）；一格一格看：图里看得到的，是否就是预期写的。
3. 只按预期判断：预期没写的不算失败；图看不清、看不出来就写"看不出"，不要猜。
4. 结果每条一行，不要别的：

```
<编号> 通过|失败|看不出 <一句话：看到了什么>
```

5. 不要自己跑 `uat.py mark`，交回结果，由派你的人统一标。
