# 15 隐私、密码框、备份与恢复

区域代号 `PR`。

## 隐私与权限

### PR-01 [P0] 不联网
- **前提**：设备上装了要测的版本。
- **操作**：在系统 **设置 → 应用 → 幽默输入法 → 权限**（或"应用详情"）里看权限；在电脑上跑 `adb shell dumpsys package io.github.sraw.youmo | grep -A20 "requested permissions"`。
- **预期**：没有"网络"或 `android.permission.INTERNET`；文字版只有振动，语音版多一个录音。

### PR-02 [P1] 存储、通讯录等权限一个都不要
- **前提**：同 PR-01。
- **操作**：看系统的权限页。
- **预期**：没有通知、通讯录、位置、存储、相机权限；导入导出文件走的是系统文件选择器。

### PR-03 [P0] 密码框里自动用英文，字母直接上屏
- **前提**：B0（当前是拼音）。
- **操作**：点「密码」框，看空格键；点 n i h a o。
- **预期**：空格键上显示"英文"；没有候选，框里是 5 个圆点（内容是 nihao）。

### PR-04 [P1] 离开密码框回到原来的输入法
- **前提**：B0，添加了五笔并切到五笔。
- **操作**：点「密码」框；再点「普通文本」框，看空格键，点 q。
- **预期**：在密码框里是英文；回到「普通文本」框后空格键上是"五笔"，q 出五笔候选（「我」）。

### PR-05 [P1] 密码框的工具栏是数字行
- **前提**：B0。
- **操作**：点「密码」框，看键盘上方；点那一排里的 1、2、3。
- **预期**：键盘上方显示 1–0 一排数字键；框里多了 3 个圆点（内容是 123）。

### PR-06 [P1] 无痕标签页里显示隐私图标
- **前提**：B0，在 Chrome 无痕标签页打开测试页，点「普通文本」框。
- **操作**：看工具栏最左边。
- **预期**：最左边的图标是一个隐私图标（不是 >）。

### PR-07 [P1] 无痕标签页里不学习
- **前提**：B0，在 Chrome 无痕标签页打开测试页，点「普通文本」框。
- **操作**：一段一段打出「这个誓言很难」（打 zhegeshiyanhennan，依次选「这个」「誓言」「很难」）；打开 **自动学到的词**。
- **预期**：列表里没有它。

### PR-08 [P1] 敏感的剪贴板内容显示为圆点
- **前提**：B0-设置，**剪贴板与表情 → 隐藏敏感信息** 开着（默认）；设备是 Android 13 或更新；装了一个复制密码时会标"敏感"的密码管理器（如 Bitwarden、Google 密码管理工具），用它复制一个密码。没有这样的应用记"阻塞"。
- **操作**：回测试页打开剪贴板面板；看剪贴板提示。
- **预期**：那一条和提示都显示成圆点，不显示明文。

## 备份与恢复

### PR-09 [P0] 备份全部
- **前提**：B0-设置，加一个自定义短语（`dz` → 北京市海淀区）、手动加一个词「澜境花园」（拼音 lan jing hua yuan；没加时这个拼音第一个是「蓝鲸花园」）。
- **操作**：**备份与恢复 → 备份全部**，存到"下载"。
- **预期**：得到 `youmo_<时间>.zip`，提示备份成功。

### PR-10 [P0] 从备份恢复
- **前提**：B0-设置，按 PR-09 备份了一个文件；然后重置应用（README「重置」）。
- **操作**：**备份与恢复 → 从备份恢复**，选那个文件并确认；等应用重启；回测试页打 d z，再打 lanjinghuayuan。
- **预期**：确认前有"会覆盖全部数据"的提示；应用自动重启；`dz` 出「北京市海淀区」，「澜境花园」排第一。

### PR-11 [P1] 恢复会覆盖现有数据
- **前提**：B0-设置，按 PR-09 备份；之后再加一个短语 `yx` → test@example.com。
- **操作**：从刚才的备份恢复；回测试页打 y x。
- **预期**：`yx` 那条短语没有了（被备份覆盖）。

### PR-12 [P1] 标为敏感的剪贴板条目不进备份
- **前提**：B0，按 PR-08 复制了一个敏感条目，再复制一条普通文字「公园」；然后 **备份全部**。
- **操作**：重置应用，从这个备份恢复；打开剪贴板面板。
- **预期**：「公园」在；敏感的那条不在。

### PR-13 [P1] 文字版和语音版互相覆盖安装保留数据
- **前提**：装着文字版，加了词「澜境花园」（拼音 lan jing hua yuan）。
- **操作**：直接安装同版本的语音版（`adb install -r`，不卸载）；打 lanjinghuayuan。
- **预期**：安装成功；「澜境花园」还在并排第一（没加时第一个是「蓝鲸花园」）。

### PR-14 [P0] 从上一版升级后设置都在新位置
- **前提**：装着上一版正式版（现在是 v0.2.0，不是要测的这一版），在它的设置里勾选模糊音 z↔zh、每页候选数设成 5、把 `,` 的中文标点改成「、」、打开禁用动画。
- **操作**：不卸载，直接安装要测的这一版正式版（`adb install -r`）；打开设置看。
- **预期**：**通用输入** 里 z↔zh 勾着、中文标点里 `,` 是「、」；**实体键盘** 里每页候选数是 5；**外观 → 大小与样式** 里禁用动画开着。这一条在发版时用正式版跑。

### PR-15 [P1] 本应用自己的输入框什么都不学
- **前提**：B0-设置。
- **操作**：点设置页顶上的搜索框；打 n i h a o，点第二个候选；打开符号面板点一个没用过的符号（例如 ※）；打 `1+1=`（数字键盘）；回测试页「普通文本」框打 n i h a o 看第一候选，打开符号面板看"最近"；打开 **词库与短语 → 用户词库 → 自动学到的词**。
- **预期**：搜索框里打 `1+1=` 时栏上没有"= 2"（不读本应用框里的字）；回测试页 nihao 的第一候选和平时一样（第二候选没被学到前面）；符号面板的"最近"里没有 ※；自动学到的词里没有新词（见 docs/keyboard.md「本应用的输入框」）。

### PR-16 [P1] 本应用的输入框里退格删掉的字不再当前文
- **前提**：B0-设置。
- **操作**：点设置页顶上的搜索框，切到拼音；打 z a i 记下第一候选；清空；打 w o 选「我」；点 ⌫ 删掉它（框里空了）；再打 z a i。
- **预期**：最后的第一候选和开头一样（如「在」），不是跟在「我」后面的「再」。这个框不学习，删掉的字也不留作前文（见 docs/keyboard.md「本应用的输入框」）。
