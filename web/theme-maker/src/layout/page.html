      怎么做一个键盘布局

      1. 「文件 › 新建」：从内置键盘（26 键、14 键、18 键、九键、数字键盘、符号面板）或示例（17 键、AZERTY、大按键数字键盘）开始，或者打开一个 .layout 文件；打开 .theme 主题时，预览换成这个主题，还可以从它带的键盘开始。
      2. 上面是预览，点一个键就选中它，拖它换位置、拖右边缘改宽；Shift 或 Ctrl 点多选。预览下面换输入法、输入框、设备和横竖屏，顶栏换预览用的主题。
      3. 下面的标签页逐项改：「键」加键、改字和图标、按下和长按做什么，选两个以上字母键能合并成分组键；「行」换行序、加行；「整块」改名字、底稿、列数、分体，数字键盘还有它管哪几种输入框；「信息」写作者、版本、许可、说明；「源码」是布局全文。
      4. 「问题」里有错误时不能保存（App 会拒收），警告可以不管。点一条跳到那一行。
      5. 「文件 › 保存 .layout」，再在手机上：幽默输入法 → 外观 → 布局 → ＋ → 导入布局文件，导入后选它用在哪个输入法上（数字键盘、符号面板选「数字键盘用这个」）。

      撤销、重做在顶栏；草稿自动存在这个浏览器里，下次打开会问要不要恢复。什么都不会上传。
