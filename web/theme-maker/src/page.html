    保存前检查

      怎么做一个主题

      1. 「文件 › 新建」：从示例、内置主题或一张图片开始，或者打开一个 .theme 文件（4.0、3.0、2.1 都行）。
      2. 上面是预览，点一个键就选中它；「环境」换设备、横竖屏、键盘、深浅色。
      3. 下面的标签页逐项改：配色、背景、按键、字和图标、栏、弹出、面板和窗口、尺寸、动效、信息；「源码」是 theme.xml 全文。
      4. 「问题」里有错误时不能保存（App 会拒收），警告可以不管。点一条跳到那一行。
      5. 「文件 › 保存 .theme」，再在手机上：幽默输入法 → 主题 → 新增主题 → 导入主题文件。

      撤销、重做在顶栏；草稿自动存在这个浏览器里，下次打开会问要不要恢复。什么都不会上传。
