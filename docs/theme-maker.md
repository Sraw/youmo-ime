# 用网页做主题

幽默输入法的主题在网页上做：主题制作页 https://sraw.github.io/youmo-ime/theme-maker/ 。App 里只能导入、导出、使用和删除主题（[设置 · 主题](settings.md#主题)）。
页面在浏览器里运行，什么都不上传。手机、电脑都能用，手机竖着用时上面是预览，下面是编辑区。

主题文件每个元素、每个属性的说明在[主题格式参考](theme-format.md)；这一页讲怎么用制作页。

## 开始

打开页面时会弹出 **新建主题**（之后在 **文件 › 新建…** 再打开）：

- **从示例开始**：三个做好的示例，打开后照着改。
  - **晚霞（渐变）**：键盘是一道从上到下的渐变，键是半透明的白，回车键另有一道渐变。浅色、深色各一套颜色。
  - **夜湖（图片背景）**：一张图片做键盘背景，竖屏、横屏各裁一块；颜色是从图片上取的。
  - **薄荷（17 键、动效）**：主题里带自己的 18 键键盘，把 H 和 JK 并成一个键，成了 17 键；按键在状态之间有 160 毫秒的过渡（松开时淡出、按 Shift 时新旧两面交叉淡），按下时缩小一点、往下沉一点。
- **从内置主题开始**：Material、Pixel、Nord、Deep Blue、Monokai、AMOLED、系统取色，和 App 里的一样。
- **从一张图片开始**：先选一套配色和浅色还是深色，再选图片。图片做键盘背景，颜色按图片算好；之后在 **背景** 里调裁切，在 **配色** 里还能再从图片取色。
- **打开文件…**：`.theme` 文件，4.0 的主题包、0.5 版 App 导出的 3.0 主题、更早的 2.1 主题都行，旧的会转成 4.0（页面会提示）。主题包里带自定义键盘的，提示带了哪些，保存时原样保留。

上次没做完的，下次打开页面会问要不要 **恢复** 草稿。草稿只存在这个浏览器里；无痕窗口里没有草稿。

## 预览

- 点预览上的一个键就选中它（**按键** 页的「选中的这个键」就是它）；按住看按下的样子。
- **环境**：设备尺寸、横屏、键盘（26 键、九键、14 键、18 键、注音、数字、符号、手写……）、形态（紧凑、悬浮、单手、分体、平铺）、Shift、输入框和输入法、按键气泡、长按弹出、菜单、候选栏和面板的样例。
- 顶栏的 **浅色 / 深色** 切换看哪一版。
- 主题带了自己的键盘（`layouts/`），预览画的就是它的键盘；它读不了时，问题列表给一条警告，预览和 App 一样画 App 自己的键盘。

## 编辑

下面的标签页逐项改，每一步都能 **撤销 / 重做**（顶栏的 ↶ ↷，或 Ctrl+Z / Ctrl+Shift+Z；正在输入的框里 Ctrl+Z 撤销的是框里的字）：

| 标签页 | 改什么 |
|---|---|
| 配色 | 主题的颜色，分组列出，可以加自己的颜色；「这个主题有深色版」；从背景图取色 |
| 背景 | 背景图片、竖横两个裁切框、亮度、模糊、键透出背景 |
| 按键 | 先选范围（全部键、字母、功能键、空格、回车、选中的键、某个场景），再选状态，再改填充、圆角、描边、阴影、厚度、内缩、形状、按下效果 |
| 字和图标 | 键上的字、角标、图标：颜色、字体、大小、位置、描边、投影；换图标 |
| 栏 | 候选栏、预编辑、工具栏 |
| 弹出 | 按键气泡、长按弹出、菜单 |
| 面板和窗口 | 悬浮窗、单手、分体、剪贴板、表情、编辑、语音、手写板 |
| 尺寸 | 键盘高度、两侧和底部边距、键缝（在 App 里自己设过这些的，App 用自己设的） |
| 动效 | 状态过渡、按下缩放和下沉；「试一下」在预览上播一遍 |
| 信息 | 名称、作者、版本、许可、预览图 |
| 源码 | `theme.xml` 全文，改完马上重读；表单不认识的写法原样保留 |

## 问题和保存

页面下方的 **问题** 列出主题的错误和警告，点一条跳到源码里那一行。

**文件 › 保存 .theme** 之前先在所有键盘、浅色深色两版上检查一遍，再按 App 导入时的规则查一遍（缺文件、图片太大、Shift 退格空格回车成了空白键……）：

- 有 **错误** 时不保存，App 会拒收；错误都列在问题里，改好再存。
- 只有 **警告** 时列出来让你看，点 **仍然保存** 照样保存（比如用了新版 App 才认的属性，这版 App 会忽略它）。

保存下来是 `<主题名>.theme`。在手机上：打开幽默输入法 → 外观 → 主题 → 新增主题 → **导入主题文件**，选这个文件。
