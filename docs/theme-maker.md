# 用网页做主题

幽默输入法的主题在网页上做：主题制作页 https://sraw.github.io/youmo-ime/theme-maker/ 。App 里只能导入、导出、使用和删除主题（[设置 · 主题](settings.md#主题)）。
页面在浏览器里运行，什么都不上传。手机、电脑都能用，手机竖着用时上面是预览，下面是编辑区。

主题文件每个元素、每个属性的说明在[主题格式参考](theme-format.md)；这一页讲怎么用制作页。

## 开始

打开页面时会弹出 **新建主题**（之后在 **文件 › 新建…** 再打开）：

- **从示例开始**：三个做好的示例，打开后照着改。
  - **晚霞（渐变）**：键盘是一道从上到下的渐变，键是半透明的白，回车键另有一道渐变。浅色、深色各一套颜色。
  - **夜湖（图片背景）**：一张图片做键盘背景，竖屏、横屏各裁一块；颜色是从图片上取的。
  - **薄荷（动效）**：按键在状态之间有 160 毫秒的过渡（松开时淡出、按 Shift 时新旧两面交叉淡），按下时缩小一点、往下沉一点。0.6.0 时它还带一块 17 键键盘，0.6.1 起 17 键是[键盘布局页](layout-maker.md)的示例，主题只管样子。
- **从内置主题开始**：Material、Pixel、Nord、Deep Blue、Monokai、AMOLED、系统取色（Nord、Deep Blue、Monokai 只在这里当起点，App 0.6.0 起不再内置）。App 里新增的简蓝、液态玻璃等内置主题是 4.0 主题包：在 App 里长按导出，再在这里打开改；改完保存前换个名字，和内置主题同名的导入 App 时会被拒绝。
- **从一张图片开始**：先选一套配色和浅色还是深色，再选图片。图片做键盘背景，颜色按图片算好；之后在 **背景** 里调裁切，在 **配色** 里还能再从图片取色。
- **打开文件…**：`.theme` 文件，4.0 的主题包、0.5 版 App 导出的 3.0 主题、更早的 2.1 主题都行，旧的会转成 4.0（页面会提示）。主题包里带自定义键盘的，提示带了哪些，保存时原样保留。别的输入法的皮肤也能打开，见下面的 [导入别的输入法的皮肤](#导入别的输入法的皮肤)。文件也可以直接拖到页面上打开。

上次没做完的，下次打开页面会问要不要 **恢复** 草稿。草稿只存在这个浏览器里；无痕窗口里没有草稿。

## 预览

- 点预览上的一个键就选中它（**按键** 页的「选中的这个键」就是它）；按住看按下的样子。
- **环境**：设备尺寸、横屏（宽 600 dp 以上的竖屏，比如平板竖拿，也按横屏画：横屏的样式、尺寸和背景切图，和 App 一样）、键盘（26 键、九键、14 键、18 键、注音、数字、符号……，或 **打开 .layout…** 看主题画在自己的布局上是什么样子，只在这次预览里用，不存进草稿；旧版布局制作页存的 .layout 里三个字母以上的分组键（显示 `{group:hjk}` 的）按大写字母画，并提示：这样的文件要在布局制作页打开、再保存一次，App 才能导入）、形态（紧凑、悬浮、单手、分体、平铺）、Shift、输入框和输入法、按键气泡、长按弹出、菜单、候选栏和面板的样例。
- 顶栏的 **浅色 / 深色** 切换看哪一版。
- 主题带了自己的键盘（`layouts/`），预览画的就是它的键盘；它读不了时，问题列表给一条警告，预览和 App 一样画 App 自己的键盘。0.6.1 起 26 键、14 键、18 键、九键、数字键盘、符号面板（`qwerty.xml` 等）不画主题带的，画 App 自带的，问题列表给一条提醒「范围内的布局在 0.6.1 起要在布局列表里选」：App 导入主题时把它们放进 **外观 → 布局**（见[主题格式 · 主题带的键盘布局](theme-format.md#主题带的键盘布局)），不再顶替。
- 主题自带的键盘里写了长按、角标、上下滑、双击、长按菜单的（`<popup>`、`alt=`、`swipe-up=` 这些），问题列表每个文件给一条提醒，列出行号：0.6.1 起主题只管样子，这些跟着键的名字，用户在 App 的 **按键 → 按键字符和快捷键** 里设；预览和 App 一样画内置的角标。写的和内置一样的不提醒。提醒不拦保存。

## 编辑

下面的标签页逐项改，每一步都能 **撤销 / 重做**（顶栏的 ↶ ↷，或 Ctrl+Z / Ctrl+Shift+Z；正在输入的框里 Ctrl+Z 撤销的是框里的字）：

| 标签页 | 改什么 |
|---|---|
| 配色 | 主题的颜色，分组列出，可以加自己的颜色；「这个主题有深色版」（只有深色版的主题这里是「这个主题有浅色版」：勾上后浅色版先用同一套颜色）；从背景图取色 |
| 背景 | 背景图片、竖横两个裁切框、亮度、模糊、键透出背景；主题有深色版时，**深色版背景图** 可以给深色版另选一张（有自己的裁切、亮度和模糊，不选时深浅两版用同一张，要 0.6.3 以上的 App）。选的图片保存时重新编码（JPEG，有透明的用 PNG）；动画 WebP 在 App 的限制内（4 MB、长边 720、300 帧、每帧至少 50 ms）时原样保留成动态背景，App 里居中铺满播放、不按裁切框，裁切框只管键盘不动时的静态图（第一帧）；超过限制的存成静态图（第一帧） |
| 按键 | 先选范围（全部键、字母、功能键、空格、回车、选中的键、某个场景），再选状态，再改填充、圆角、描边、阴影、厚度、内缩、形状、按下效果；**贴纸**：一张画在键面上、字和图标下的图（PNG 或静态 WebP，边长 512 以内、256 KB 以内，最多 120 张），贴纸画的就是字时勾 **藏起主字**（要 0.6.3 以上的 App） |
| 字和图标 | 键上的字、角标、图标：颜色、字体、大小、位置、描边、投影；换图标（SVG，或 PNG、静态 WebP 的位图图标：边长 256 以内、128 KB 以内，勾 **上色** 只用图的形状、颜色跟图标颜色走，不勾保留图自己的颜色，要 0.6.3 以上的 App；只列 App 自带的图标名，按画在哪里分组：回车键、键、快捷键的命令、栏、状态面板和编辑面板；同一个名字在几处都画的，每处都注明「也在」，换一次几处都换；换了的图标预览里照 App 的画法画出来，候选栏预览的工具栏按钮也是。新名字的图标，比如给 `space-content: icon(star)` 用的，只能在 **源码** 里写 `<icon>`） |
| 栏 | 候选栏、预编辑、工具栏 |
| 弹出 | 按键气泡、长按弹出、菜单 |
| 面板和窗口 | 悬浮窗、单手、分体、剪贴板、表情、编辑、语音、键上手写的笔迹（预览里不画笔迹） |
| 尺寸 | 键盘高度、两侧和底部边距、键缝（在 App 里自己设过这些的，App 用自己设的） |
| 动效 | 状态过渡、按下缩放和下沉；「试一下」在预览上播一遍 |
| 按键音 | 字母键、功能键、空格、回车、退格各一个声音：Ogg Vorbis、WAV（8/16 位 PCM）或 MP3，单个不超过 100 KB、1 秒，1–2 声道，8000–48000 Hz，不合格的放不进去。每行显示格式、时长、声道和采样率，可以 **试听**（浏览器自己解码，有的浏览器放不了 Ogg，App 里照样能放）、**去掉**。选 MP3 时提示：MP3 开头有约 25 ms 的空白，想按下就响用 WAV 或 Ogg。没给的类别用字母键的声音；预览上点键不出声 |
| 宠物 | 主题的小宠物：放在键盘的哪个角或候选栏右边、大小、偏移；每个动作（平时、按字母数字符号、退格、回车、空格、睡着、醒来）一张帧图，帧数、每行几帧、每秒几帧、循环不循环；**播放** 在旁边的小框里照键盘上按一下那类键之后的样子播：不循环的播一遍回到「平时」，循环的一直播，30 秒后睡着（主题有「睡着」时；睡着循环三遍后停在最后一帧）。键盘预览里不画宠物。选帧图时按图的大小猜帧数和每行几帧（一行方格、一列方格、方格网格，都不行时排成一行）；换图时原来的帧数切不出方格、图的大小也变了，就重新猜。帧图和限制见 [主题里的宠物](theme-pet.md)，要 0.6.3 以上的 App |
| 信息 | 名称、作者、版本、许可、预览图 |
| 源码 | `theme.xml` 全文，改完马上重读；表单不认识的写法原样保留 |

## 问题和保存

页面下方的 **问题** 列出主题的错误和警告，点一条跳到源码里那一行。

**文件 › 保存 .theme** 之前先在所有键盘、浅色深色两版上检查一遍，再按 App 导入时的规则查一遍（缺文件、图片太大、图标或按键音不合格、Shift 退格空格回车成了空白键……）：

- 有 **错误** 时不保存，App 会拒收；错误都列在问题里，改好再存。
- 只有 **警告** 时列出来让你看，点 **仍然保存** 照样保存（比如用了新版 App 才认的属性，这版 App 会忽略它）。
- 用了 0.6.3 才有的写法（位图图标、贴纸、深色版背景图、缺键的布局……）而主题没写最低版本，或写得更低的，打开和保存时自动把 `min-app` 设成需要的版本，问题列表最上面提示一句。旧版 App 看到它会说要升级，而不是画错。

保存下来是 `<主题名>.theme`。在手机上：打开幽默输入法 → 外观 → 主题 → 新增主题 → **导入主题文件**，选这个文件。

## 键盘布局

键怎么排（17 键、AZERTY、大按键的数字键盘……）不在主题里做，在键盘布局页 https://sraw.github.io/youmo-ime/theme-maker/layout/ （顶栏的 **键盘布局**）做成 `.layout` 文件，见[用网页做键盘布局](layout-maker.md)。

## 旧版制作页

0.6.0 之前的制作页（原来顶栏的 **旧版**）已经去掉。它做的 3.0 主题 App 照样能导入，也能在这里用 **打开文件…** 打开接着改，保存成 4.0 的 `.theme`。

## 导入别的输入法的皮肤

**文件 › 打开文件…**（或把文件拖到页面上）也能打开别的输入法的皮肤，转成幽默输入法的主题接着改，和 App 里 **导入主题文件** 转出来的一样：

- 能转的：百度（`.bds`、`.bdi`、`.bda`）、搜狗手机版（`.ssf`，加密的和不加密的都行）、讯飞（`.it`）、同文（`.trime.yaml`、`.yaml`，或带着它 include 的文件的 zip）、FlorisBoard（`.flex`）；zip 里只套着一个皮肤文件的也行。
- 不能转的会说明原因：手心（`.sxi`）、仓（`.cskin`）、Gboard / Rboard、安装包（`.apk`）里的主题、搜狗电脑版的皮肤、加密读不出来的、文件太大的（超过 64 MB，或解开后太大）。
- 转换在浏览器里做，文件不上传。超过 2 秒会显示「正在转换……」。要较新的 Chrome、Edge、Firefox 或 Safari（要用到浏览器自带的解压、解密和图片解码）。
- 转好后页面上方列出 **没转过来的部分**（比如帧动画、皮肤自己的字体、按键音的一部分），和 App 导入时的提示一样。
- 皮肤带了自己的键位（比如百度皮肤的 26 键、九键）时，这一栏会写带了哪几块，并有一个 **带上皮肤的键位** 的勾选框，默认不勾：不勾用 App 自己的布局；勾上后保存的主题包带着这些键位，导入 App 后放进 外观 → 布局，最低版本设为 0.6.3。皮肤里缺 App 需要的键（比如没有 Shift、九键没有 0）的，也在这一栏里说。
- 皮肤的图片转成 PNG；单张超过主题包限制的会缩小。图片很多、很大（加起来超过 4000 万像素）时，后面的图片不再解码，提示里会说有图片没读出来。
