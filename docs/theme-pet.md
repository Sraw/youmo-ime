# 主题里的宠物

主题可以带一只小宠物（`<pet>`，0.6.3 起），待在键盘的一个角上或候选栏右边。按字母、退格、回车、空格时它各做一个小动作，
30 秒不按键会睡着，再按键醒来。宠物只是装饰：不挡按键，点它盖住的地方就是点下面的键。

在 [网页制作页](theme-maker.md) 的「宠物」面板里可以直接加，不用手写；下面是手写 `theme.xml` 时的格式。
主题包的其余部分见 [主题格式](theme-format.md)。

## 格式

`<pet>` 放在 `theme.xml` 最后（`<sounds>` 之后），最多一个，不分浅色、深色：

```xml
<pet place="keyboard" align="top-end" size="48dp" offset-x="-4dp" offset-y="2dp">
  <state name="idle"   sheet="pet-idle.png"  frames="4" columns="4" fps="4"/>
  <state name="typing" sheet="pet-peck.png"  frames="6" columns="6" fps="12"/>
  <state name="delete" sheet="pet-shake.png" frames="5" fps="12"/>
  <state name="sleep"  sheet="pet-sleep.png" frames="4" fps="2" loop="true"/>
</pet>
```

| 属性 | 取值 | 默认 | 写错时 |
|---|---|---|---|
| `place` | `keyboard`（键盘的角上）、`bar-end`（候选栏右边，从右往左的语言是左边） | `keyboard` | 没有宠物 |
| `align` | `top-start`、`top-end`、`bottom-start`、`bottom-end`，只对 `keyboard` | `top-end` | 没有宠物 |
| `size` | 16–64 dp，宠物框的边长；帧按长边放进框里、居中。`bar-end` 时不超过候选栏高度减 4 dp | `40dp` | 夹到范围里，提醒 |
| `offset-x`、`offset-y` | −32–32 dp，从 `align` 那个角往里为正；只对 `keyboard`，`bar-end` 写了只提醒、不起作用 | `0` | 夹到范围里，提醒 |

`<pet>` 里只能放 `<state>`：

| 属性 | 取值 | 默认 | 写错时 |
|---|---|---|---|
| `name` | `idle`（必须有）、`typing`、`delete`、`enter`、`space`、`sleep`、`wake` | — | 不认识的名字只提醒，这个 `<state>` 不用；同名写两次或没有 `idle`：没有宠物 |
| `sheet` | 包里的一张 PNG 或静态 WebP，文件名不能带目录 | — | 没有宠物 |
| `frames` | 1–24，图上有几帧 | `1` | 没有宠物 |
| `columns` | 1–`frames`，一行几帧；行数 = ⌈frames ÷ columns⌉ | `frames`（排成一行） | 没有宠物 |
| `fps` | 1–30 帧/秒；`idle`、`sleep` 最多按 8 播 | `8` | 夹到范围里，提醒 |
| `loop` | `true`、`false` | `idle`、`sleep` 循环，其余播一遍 | `idle` 写 `false` 只提醒，照样循环 |

所有状态的帧加起来最多 96 帧。`<pet>` 写错时只是没有宠物（导入时提醒一句），主题其余部分照常导入。
有 `<pet>` 的主题要 0.6.3 或更新的版本，导出时 `min-app` 自动写成 0.6.3。

## 什么时候做什么

| 按了 | 状态 |
|---|---|
| 字母、数字、九键的数字键、标点和符号键、九键拼音栏上的音节 | `typing` |
| 退格（长按连删时每删一下） | `delete` |
| 回车 | `enter` |
| 空格 | `space` |
| 宠物显示着、30 秒没按上面这些键 | `sleep` |
| 睡着时按了上面这些键 | 先 `wake`，再做这个键的动作 |

- 主题没给某个状态时，按那一类键宠物不变（比如没有 `enter`，按回车时它照旧）。没有 `wake` 就直接做这个键的动作。
- 不循环的动作播一遍回到 `idle`。播的时候又按了同一类键，接着播，不从头来；按了另一类键，从头播那一个。
- `sleep` 循环三遍后停在最后一帧，`loop="false"` 时播一遍停住，直到再按键。
- 滑行输入、空格上滑动移光标（和方向键）、语音、手写、点候选、工具栏、切换键盘和面板、实体键盘都不会让宠物动。
- 换到表情、符号、剪贴板等面板时宠物藏起来；回到键盘、键盘收起后再弹出时，从 `idle` 第一帧重新开始；换到别的输入框不算收起，宠物接着刚才的动作。
- 只在 **设置 → 外观 → 大小与样式 → 键盘动效** 开着时动（系统省电模式、系统"移除动画"、**禁用动画** 打开时也不动，见 [settings.md](settings.md)）：关着时只显示 `idle` 的第一帧，按键也不变。
- 主题列表的缩略图、预览、网页的键盘预览里不画宠物。

## 帧图

每个状态一张图，帧从左到右、从上到下排，每帧一样大：帧宽 = 图宽 ÷ `columns`，帧高 = 图高 ÷ 行数，最后一行可以不满。

- 格式：PNG 或静态 WebP（动图 WebP 不行：动作由帧图排出来；带动画的 PNG 只读第一帧）。
- 单张不超过 **512 KB**，边长不超过 **2048 px**；每帧不超过 **256 × 256 px**。
- 图宽要能被 `columns` 整除、图高要能被行数整除。

图有问题（缺了、不整除、超过上面的限制）时，整个主题包导入不了，提示里写着哪个状态、哪张图、哪一条；网页制作页保存前也这样检查。

宠物只按画出来的大小留在内存里：所有状态合起来最多 6 MB，内存小的手机 3 MB。放不下时先不要 `wake`，再依次是 `sleep`、`space`、`enter`、`delete`、`typing`，
只剩 `idle` 还放不下就把它缩小；缩到每帧不足 24 px 时只显示 `idle` 的第一帧。帧比显示的小（比如 16 px 的像素画）没关系，会放大到宠物的大小照常播：放大到两倍以上时按整数倍放大、不做平滑，像素画不会糊（所以可能比宠物框略小一点）。所以帧不用画得比显示的大：48 dp 的宠物在常见手机上约 150 px。
