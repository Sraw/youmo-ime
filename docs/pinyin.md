# 拼音输入

拼音（全拼）、双拼、九键拼音用的是同一个引擎和同一套词库。你的词三者都打得出；候选的顺序各学各的（见[输入法怎样学你的词](#输入法怎样学你的词)）。

## 打字

直接按拼音，候选栏会给出整句和各个词：

- **空格**上屏第一个候选；点别的候选上屏那一个。
- 只选了前半句时，剩下的拼音留着，接着给出后半句的候选。
- **回车**把打的字母原样上屏（比如想打英文缩写时）。
- 退格删最后一个字母；在退格键上**向左滑**清空正在打的拼音。
- 还没选的拼音显示在候选栏上方（键盘顶上专门留的一行，不挡应用），不进输入框，输入框里只出现选定的字。收起键盘、转屏、点别的输入框或切到别的应用时，它直接消失，框里不会留下字母。打到一半点输入框里别的位置，也会丢掉还没选的拼音。
- 拼音打错了不用全删：点一下拼音那一行，光标就停在点的地方，接着打的字母插在那里，退格删的是光标前面的字母，候选跟着变。在空格键上左右滑动、或者实体键盘的方向键和 Home、End，也能移动光标。拼音太长时这一行跟着光标左右滚动，也可以用手指拖着看。已经选定的字不能放光标，光标最多退到它们后面；这时再退格，删掉的是最后选定的那个字的最后一个字母，这个字也退回成拼音（比如选了「你」的 `你hao`，退格后是 `n hao`）。九键一样能改：光标停在哪个数字后面，接着按的数字就插在那里；光标在中间时点左边拼音栏定下音节，光标跳到这个音节后面。u 开头的笔画查字也能点着改笔画，光标在中间时打一个别的字母，字母插在光标处、整串转回拼音。
- 音节分不清时用 **'** 分开：`xi'an`（西安），不加是 `xian`（先、现…）。`'` 在全键盘 z 键的角上，向下滑 z 键就能打出。

不用打全：

- **简拼**：只打声母，比如 `zg` → 中国，`wsm` → 为什么。
- **半截**：最后一个音节没打完也会给出候选，比如 `zhongg`。
- 简拼、半截和完整拼音是不同的键，各学各的：用全拼打得再多，也不改简拼的第一个。你的词（见下面）在简拼里一般排在第一页；要它在简拼里排第一，就在简拼里选它，或者把它固定在这串键下。

### 整句和上下文

输入法按整句来判断哪个读法最通顺，并且参考光标前面已经写的内容。比如单打 `daxue` 首选是"大学"；前面写了"昨天晚上下了一场"，再打 `daxue` 首选就是"大雪"。

在聊天应用里，消息发出去后输入框会清空，输入法会记得这个输入框刚才写了什么，接着打的回复排序时仍然有上下文。这个记忆只在内存里，不写到存储，过一阵子就忘；密码框和要求不记录的输入框完全不记。学习不看它：发出一条消息以后接着打的，学习时算没有前文（和换行一样）。

### 性能档位

在 **通用输入** 里有 **性能档位**（各中文输入法共用）：

| 档位 | 怎么排候选 |
|---|---|
| 低档 | 只按词频和词语搭配，最省电 |
| 中档 | 每次按键再用小模型按整句的通顺程度重排 |
| 高档（默认） | 在中档基础上，你停下来时再用较大的模型精挑首选，最准 |

档位越高越准，也越费电。高档在你停顿时才多算，打字不会变慢。

## 纠错

**纠正错拼和按偏的键**（默认开）：

- 常见的错拼会自动认出：`ng` 打成了 `gn`（`zhagn` → 章、张）、`ong` 漏了 g（`zhon` → 中）、j/q/x 后面的 u 打成了 v（`jv` → 句）。
- 手指按到了旁边的键（比如想按 `a` 按成了 `s`）也能认出来。
- 纠正出来的读法分数会低一些，一般不会抢掉你本来就打对的词。

常读错的词也能按错的读音打出来：比如 `jiaose` 能打出"角色"，`shuifu` 能打出"说服"，候选旁边会标出正确读音和声调（jué sè、shuō fú）。

## 模糊音

分不清某些音时，在 **通用输入** 的 **模糊音** 里打开对应的项，两种音都能打出：

| 项 | 意思 |
|---|---|
| c ↔ ch、s ↔ sh、z ↔ zh | 平舌翘舌不分 |
| l ↔ n、l ↔ r、f ↔ h | 声母不分 |
| an ↔ ang、en ↔ eng、in ↔ ing、ian ↔ iang、uan ↔ uang | 前后鼻音不分 |
| u ↔ v | `lu` 也能打"绿"（ü 一般用 v 打） |
| u ↔ ou | |

默认全部关闭。打开的越多，候选越杂，只开自己真的会混的。

## 中英混输

**中英混输**（默认开，只在全拼里有）：在拼音里直接打英文词，比如 `iphone` 给出 iPhone，`wodeiphone` 给出"我的iPhone"。
内置的是中文里常夹着用的英文词和品牌名，不是整本英文词典；要打成段英文请切到英文输入法。英文输入法里学到的词（英文词典里没有、你打出来的，比如 `youmo`，和你在英文词库里手动加的）这里也打得出，大小写照你在英文里打的（同一个词学到几种大小写，只出现手动加的或用得多的那种）；在英文词库里删掉的，这里也不再出现；关掉「用我的输入习惯」时只剩内置的。

## 笔画查字

不会读的字用笔画打：先按 **u**，再按笔画：

| 键 | 笔画 |
|---|---|
| h | 横 一 |
| s | 竖 丨 |
| p | 撇 丿 |
| n | 捺（点）丶 |
| z | 折 乛 |

比如 `uhsp` 打出"才、本、村…"，候选旁会显示读音。只有一开头按 u 才是笔画；`u` 后面跟别的字母时仍是拼音（比如 `usb`）。

## 拆字

不会读的字也可以按它的几个部分打：先按 **u**，再依次打每个部分的全拼。`uniuniuniu` 出"犇"，`ujinjinjin` 出"鑫"，
`ushuishuishui` 出"淼"，`ukoukou` 出"吕、吅"，`ushuixiang` 出"港、湘…"。这些字排在候选最前面，旁边显示读音，常用的在前。
偏旁按它代表的字读：氵读 shui、亻读 ren、扌读 shou、艹读 cao、钅读 jin；多音的部件按最常见的读音（弓长张是 `ugongchang`）。
要把整串拼音打完才出；拼法不是哪个字的部件时，照常当拼音打（`usb`）。u 后面紧跟元音时（`uanmu`）也可能是 y 按偏了，
这时第一个候选还是纠错后的拼音，拆出的字从第二个起。打出的字不会学进词库；屏蔽过的字不出。只有全拼有，双拼和九键没有；可以在拼音的设置里关掉（**拆字**）。
拆分数据来自开放词典《汉语拆字字典》（[kfcd/chaizi](https://github.com/kfcd/chaizi)，CC BY 3.0）。

## 滑行输入

全拼键盘上也能滑行：手指按在第一个字母上，不抬手依次划过一个词的拼音字母（ü 划 v），在最后一个字母上抬起，这串拼音就像一个个敲出来的一样进了输入框，候选照常给出，比如划 n-i-h-a-o 得到 ni'hao、候选 你好。一次划一个词；接着再划下一个词，它会接在后面（划 wo 再划 men 得到 我们）。

同一条线常常能读成几个拼音（划 nihao 时拐过 h 的弯不明显，也像 niao），所以从头开始的一划，第一个候选之后会跟着另外两种读法里最常用的词（你好 后面是 鸟、你到），点它就换成那种读法并上屏，和平常选词一样会学（按选出的这个词的全拼学）、会联想。

自己加的词也划得出来。

双拼和九键也能滑：双拼划每个音节的两个键（自然码划 ni-h-k 得到 你好），音节之间不用分开；九键划字母所在的数字键（你好 划 6-4-4-2-6，同一个键上连着的字母不用离开），读出的拼音按字母本身输入，不会再被读成同一串数字的其他拼音。九键一个键上有好几个字母，同一条线能读的拼音多得多，首选不如全拼准，所以九键从头开始的一划，第一个候选后面最多跟六种其他读法。微软、紫光双拼的 ing 在分号键上，含 ing 的音节划不出来，要敲。

字母键上下短划、长按照旧，只有横着划过大半个键或上下划过一行半以上才算滑行（九键的数字键上下划过大半个键就算，短划照旧打数字）。默认关闭，所有输入法（手写除外）共用一个开关：在 **通用输入** 里打开 **滑行输入**。

## 表情候选

打的词有对应的表情时，候选栏第三个起会给出至多两个表情（**表情候选**，默认开）：`haha` 出"哈哈、蛤蛤、😃、😄"，`dianzan` 出 👍，`wanan` 出 😴。点一下表情就上屏，不会学进词库。
跟着的是第一个候选：第一个候选只读了开头一部分拼音时不出表情。词和表情的对应来自 Unicode 的 CLDR 中文表情关键词，再加上本项目的校对（补了点赞、狗头、吃瓜等网络用语，去掉了加油 ⛽ 这类不对的）；单个字只在它就是表情名字时才有（猫 🐈），所以"是""你"这些常用字不会冒出表情。手机字体画不出来的表情不出。全拼、双拼（每种方案）、九键都有，规则一样（九键 `4242` 出「哈哈」和 😃）；码表输入法也有（编码只有一个字词、自己上屏时，表情出在联想栏最前，点了替换刚上屏的词），见[其他输入法](other-input-methods.md#表情候选)。手写没有。各输入法共用这个开关，可以在 **通用输入** 里关掉。

打出"日期""时间""星期"这几个词时，同样在第三个候选起给出今天的日期、现在的时间、星期几（**自带的日期时间**，在 **通用输入** 里，默认开），全拼、双拼、九键、码表都有；全拼还可以直接打 `rq`、`sj`、`xq`，两种都出时不重复。见[自带的日期时间](words.md)。

## 联想下一个词

上屏一个词以后，候选栏会接着给出可能要打的下一个词（**联想下一个词**，默认开），点一下就上屏；直接打字联想就消失。
脏话等粗俗词不会出现在联想里。可以在 **通用输入** 里关掉。

- 联想也学：前一个词就是它的"键"，不看更前面的字。点一次联想词，下次它排到没用过的前面；连着点两次，它排第一。
- 你自己打过的搭配也会联想出来：后一个词紧跟在前一个后面打过 3 次（中间打别的不要紧），写了前一个就联想出后一个（好的 → 谢谢）。全拼、双拼、九键、码表、手写打出的都算；语音原样打出的、被删掉的、还没成词的不算。
- 不想要某个联想：长按它选 **不再联想**，这个词以后不再跟在这个前词后面出现，打字照样打得出；当场能撤销，也在 **词库与短语 → 用户词库 → 不再联想的搭配**（紧挨着"屏蔽的词"，屏蔽的词页顶也有一行进去）里列出，点一下恢复。要它哪里都不出现，用同一菜单里的 **屏蔽**。

## 长按候选

长按一个候选会弹出菜单（只出现适用的项）：


| 项 | 作用 |
|---|---|
| **删除** | 只在你的词、导入的词上有。删掉这个词，它学到的一起忘掉，删了就没了 |
| **忘掉学到的** | 在词库自带的词上有。忘掉这个词学到的一切：各种键盘、各个前文一起，就像从没选过它。它不是"回到第一"：别的词学到的照旧。想让原来的第一个回来，长按现在的第一个忘掉它，或者固定原来的那个 |
| **屏蔽** | 菜单里先写明范围（以后打字、手写、语音、联想都不再出现这个词），再点 **确定屏蔽**。它在这串键下的固定也取消。在 **词库与短语 → 用户词库** 的"屏蔽的词"里一步恢复 |
| **固定首位** | 以后在这种键盘上打同样的键，这个词总排第一，不论前文；其余候选照常排，往后挪一位。只管这种键盘、这串键：全拼固定了「指导」，简拼 `zd` 和九键不受影响。同一串键再固定另一个词，新的替换旧的 |
| **取消固定** | 取消上面的固定，按学到的顺序排 |
| **从自定义词组中删除** | 只在[自定义短语](words.md#自定义短语)（包括自带的日期时间）上有。这条短语以后不再出现，没有撤销；自带的日期时间在自定义短语里变成关闭的一条，想要回来就打开它 |
| **不再联想** | 只在联想词上有：它以后不再跟在这个前词后面出现（见上面的[联想](#联想下一个词)） |
| **为什么排在这** | 写出它排在这里的原因：固定了 / 在这个前文后面连着选过两次 / 你常改选它、最近用得多 / 在这串键下用过 N 次 / 你的词 / 来自哪次导入 / 词库自带。这里还能把这串键的候选和次数复制下来发给开发者，不带你打的别的内容 |

- 删除、忘掉学到的、屏蔽、固定、取消固定、不再联想，做完会出一条提示（比如"已屏蔽「是」 撤销"）：候选栏上还有候选时（比如还在打字）它在整个键盘上方，不挡候选和按键；没有候选时在候选栏上。上方没地方放时（悬浮键盘拖到屏幕最顶，或实体键盘的候选窗贴着屏幕顶），提示在键盘或窗的下方，不盖候选；下方也放不下时（比如横屏时悬浮键盘和屏幕一样高），才退回候选栏上。提示停 6 秒（开着读屏等无障碍服务时按系统建议停得更久），接着打字（按键、上屏）就收起；提示还在时点 **撤销** 就回去，像没做过一样。只有最后做的那一下能撤销。候选已经变了（比如菜单开着时又打了字），点了菜单只提示"候选已经变了，没做"。码表里的删除，以及拼音里删掉码表也存着的词，只提示、没有撤销。
- 接了实体键盘时，选中一个候选按 Shift+Delete，等于删除 / 忘掉学到的；按住不放也只做一次。
- 英文的候选长按没有 **为什么排在这**：英文按它自己的规则排（常用程度、前一个词、改正），没有拼音那样的固定、学到的顺序这些原因可写。
- 没按学到的顺序排过的候选长按也没有 **为什么排在这**，比如码表里跟在后面、编码更长的字，滑行输入多给的另一种读法的词，滑行打出的拼音。
- **屏蔽** 的确认在菜单里换到另一行（中间隔着 **取消**），点屏蔽的手指连点两下不会直接屏蔽。
- 以前的"以自定义词组的方式置顶"变成了 **固定首位**。升级时，全拼字母下置顶的词转成固定，其余的仍留在[自定义短语](words.md#自定义短语)里。
- 在密码框等不学习的输入框里，长按不会弹出菜单。

## 输入法怎样学你的词

一句话：**选一次，下次排到前面；在同一个地方连着选两次，它就排第一。** 天天直接上屏的词，不会因为一次误选就丢掉第一。

### 同一个地方

- **同一种键盘，按同样的键。** 全拼、双拼（每种方案各算一种）、九键（每种字母布局各算一种，开着连按另算一种）、码表、手写各学各的。简拼 `dl`、完整拼音 `dianle`、打一半的 `dianl` 是三串不同的键，也各学各的。`'` 不算键，`dian'le` 就是 `dianle`。
- **同样的前文。** 前文是光标前最近的那个词：刚打的、框里原来就有的、语音打出的都算。词按联想读前面的字那样分：「他点了他」的前文是「他」，你的词（比如加过的「汪小明」）整个算一个。标点、换行、表情、号码和网址后面，算没有前文；聊天框发出一条消息以后接着打的，也算没有前文。
- 滑行选出的词，按这个词的全拼学，和点着打全拼是一回事。
- 纠错、模糊音、按偏以后选出的词，按你实际按的键学：下次同样打偏，它排前面。
- 换了双拼方案或九键的字母，按的键变了，顺序要重新学；你的词照样打得出。简体里学到的，繁体输出时也一样。

### 候选怎么排

在一串键下，从上往下：

1. **你固定的词**，永远第一。
2. **这个前文后面你连着两次选的词**：中间没用当时的第一个。按空格上屏第一个不算改选，只算用过；中间用了一次原来的第一个，就从头数；它当时被别的词顶到后面（固定的、按第 2、3 条排上来的）也一样。
3. **在你没这样改过的前文后面**：一个词在这串键下被你改选过至少两次，最近又比原来的第一个用得多，它就第一。牵涉单字时不这样：原来的第一个是单字（`xian` 的「先」）、或改选的是单字（`de` 的「得」），只在一个个前文后面按第 2 条换。
4. 否则是原来的第一个（打的是整句时，是整句）。

第一个以外：先是你在这串键下用过的词，最近用得多的在前，一样多不换；然后是你的词；再后面照词库原来的顺序。所以被换下来的老词一般排第二，选过一次的词排到没用过的词前面。

例子：

- 全拼 `dl`，前面是「他」，第一个是「带来」，你最近在 `dl` 下也常打「带来」。选一次「点了」：下次还是「带来、点了」；再选一次「点了」：变成「点了、带来」。别的前文后面仍是「带来」第一，「点了」排在没用过的词前面；等你在 `dl` 下最近用「点了」比「带来」多了，别处也是「点了」第一。
- 在「跑」「飞」后面各选过一次「得」，到「猫」后面打 `de`：第一个仍是「的」。在「跑」后面连着选两次「得」，「跑 de」才是「得」。
- 用全拼打了很多次「点了」，简拼 `dl` 的第一个照旧是「带来」。

### 你的词

- 一次上屏、词库里没有的 2～4 个字，不论怎么打出来的（一段段选出来的名字、由「点」「了」拼成的「点了」、删掉重打出来的）：同样的字上屏满两次，就成了**你的词**。
- 你的词在全拼、简拼、双拼、九键、滑行里都打得出；在一串键下还没用过时，排在没用过的词库词前面，所以一般在第一页。例如分段选出「汪小明」两次以后，`wxm` 的第一页就有它。
- 只上屏过一次的，不会冒到简拼、联想和别的键下；30 个打字日里没再上屏，就忘掉。
- 超过 4 个字的不自动成词，要的话在[用户词库](words.md#用户词库)里手动加。
- 你的词一直都在，很久不用、清空学到的也还在，除非你删掉它。

### 整句

整句按上下文定读法，你的学习里只照用三样：

1. 你固定的多字词（固定的单字只在单打它的键时排第一，整句里由整句定：固定了「得」，`wodeshu` 还是「我的书」）；
2. 在同一个前文后面连着改两次换上的多字词：在「我」后面两次把 `zhidao` 改成「指导」以后，整句打 `wozhidao` 也出「我指导」；
3. 你手动加的词，在没有别的同拼音的词时。

照用的词被整句里更长的词盖住（`wozhidaole` 里的「知道了」）时，还是由整句定。长句里改过的一段，在它自己的键和前文下学一次。

照用以后，整句原来的读法就不在候选里了：「指导」照用后打 `wozhidao`，候选里没有整句「我知道」，要的话分段选「我」再选「知道」。整串打的只是照用的那一个词时（在「我」后面单打 `zhidao`），原来的读法「知道」仍在第二个。

### 选错了

- 上屏后马上删掉，或者从末尾连着退格删掉几次上屏：删掉的不算用过。接着重打的，前文和被删那次一样、读音也对得上被删那次按的键，还算在那里改选了一次：`dl` 空格出「打了」，`ma` 空格出「吗」，退格删掉，再打 `dianlema` 出「点了吗」：「打了」不算用过，`dl` 下的「点了」算改选一次。
- 光标挪回去，删掉刚才的错词重打，也一样：要在同一个输入框里，输入法没重启，那个词后面的字没变，上屏是在最近 60 分钟或今天以内。
- 上屏之前退回重选的，不学。

### 时间

- 只数打了字的日子（打字日）。一个月没用输入法，回来一切照旧。
- 比谁用得多，只看最近 30 个打字日。学到的顺序 30 个打字日不用就忘掉；还在用就一直有效。
- 不会忘的：固定、屏蔽、你的词、自定义短语。

### 不学的

- 密码框、应用要求不记录的输入框（浏览器无痕模式等），什么都不学，见[这里不学](words.md#这里不学)。
- 号码、手机号、证件号、银行卡号、验证码、网址、邮箱：不成词，不进联想，也不当前文。网址、邮箱、数字输入框里不学前后搭配；搜索框学词和顺序，但不出联想（英文也不出下一个词），在那里打的也不进联想。
- 笔画查字、拆字、表情、自带的日期时间、计算结果、剪贴板粘贴、自定义短语。
- 本输入法自己的输入框（加词、改词、设置搜索）。

词库里的脏话等粗俗词默认排得靠后（第一页之后）、不出现在联想里；你上屏过一次的，就不再压后。

学到的、加的、固定和屏蔽的词，都在[用户词库](words.md#用户词库)里看得到、改得了；借手机、清掉刚才打的、整个清空，见[学习的开关和清除](words.md#学习的开关和清除)。

## 双拼

在 **输入法** 里添加"双拼"。在双拼的设置里选 **方案**：自然码（默认）、微软、紫光、智能 ABC、中文之星、拼音加加、小鹤、国标。
每个音节两个键：第一个是声母，第二个是韵母。零声母音节（如"安""欧"）的打法按各方案的规定。微软、紫光双拼把 ing 放在分号上，这两个方案的字母键盘第二行 L 右边多一个 **;** 键（分开的左右两半键盘上没有，用 L 的长按）。分号只在声母后面读成 ing；什么都没打、或刚打完一个整音节时，它就是标点键：先上屏第一个候选，再打出中文分号「；」（跟随标点设置），和微软拼音一样。

双拼有纠错和模糊音，也有简拼，但只在两个键连起来不成音节时：这时按各自的声母读，比如自然码的 `fx`（f 后面接 ie 不成音节）出"发现""方向"；连起来是一个音节的就按音节读，`vg` 是 zheng。双拼没有中英混输（双拼的字母组合和英文词冲突太多）。

双拼两个键的简拼和全拼一样各学各的；双拼里学到的顺序不改全拼，换方案以后顺序重新学（自然码 `dl` 读 dai，第一个是单字「带」：在一个前文后面连着选两次别的词，只在那个前文后面换）。

## 九键拼音

在 **输入法** 里添加"九键拼音"。键盘的用法见[键盘与手势 · 九键键盘](keyboard.md#九键键盘)。

- 每个数字键代表几个字母，输入法按整句判断你要的拼音，一般直接按就行：`64426` → 你好。
- 判断不对时，点左边拼音选择栏里的音节，把这一段定下来。
- 九键一般不按简拼读：几个键能拼成音节时按音节读，`94` 读成 yi、zi 这些音节，要出"中国"得把每个音节按全（`94664486`）。只有拼不成音节的键才按声母读，比如 `25` 能出"北京"。
- **连按选字母**：打开后，快速连按同一个键就是它的第几个字母，只有这一种读法（按两下 `4` 就是 h，不会是 gg、hh；三下是 i，四下回到 g）；退格把连按出来的字母整个删掉。按一下还是和平时一样，这个键上的几个字母都算，拼音行显示输入法猜的那个（单按 `4` 常显示 h）；要的就是第一个字母（比如单独的 g），点左边拼音列里的 g，或长按 `4` 选。关着时每按一次都是一个键，输入法按上下文判断。关（默认）/ 快（0.4 秒）/ 中（0.6 秒）/ 慢（0.9 秒）。
- **按键字母**：可以自定义每个数字键上的字母（每键最多五个，同一个字母可以放在几个键上）。不在任何键上的字母，含它的拼音就打不出来。
- 一串数字就是一串键，按[同样的规则](#输入法怎样学你的词)学，读得成音节的（`94`）和读不成的（`35`）都一样。点左边拼音栏定下音节后选出的词，不是这串数字的第一个时，算在这串数字下改选了一次；拼音栏里的音节也按你定过的次数排。
- 不看屏幕按第二个候选的：第二个是第一个以外你用得最多的词，一样多不换。要第二个一直不动，就把第一个固定。
- 纠错、中英混输和 u↔v 模糊音不适用于九键。
