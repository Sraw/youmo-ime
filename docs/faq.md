# 常见问题

## 隐私与权限

**输入法会上传我打的字吗？**
不会。应用没有网络权限，系统层面就不允许它联网：没有云输入、没有统计、没有崩溃上报、不检查更新。打字、纠错、排序、语音识别全部在手机上完成。

**系统启用输入法时提示"可能会收集您输入的所有文字"，是怎么回事？**
这是 Android 对所有第三方输入法都会显示的固定提示。本输入法不联网，打的字不会离开手机。

**申请了哪些权限？**
- **振动**（按键振动用）。
- **录音**：第一次用语音输入时才问，只在你说话时使用（按住空格或点了工具栏的麦克风）。没导入语音包、不用语音输入就不会问。

不申请通知、通讯录、位置、存储等其他权限。构建时会检查，多出任何权限都无法通过。导入、导出文件都通过系统的文件选择器，由你选择具体文件。

**它记住了我的哪些东西？存在哪？**
都只在手机上：
- 你打过的词、在哪串键下选了什么、选了几次、在哪一天（用来排序，只记到哪一天），你的词、导入的词、固定和屏蔽的词；只上屏过一次的词 30 个打字日不再打就忘掉；
- 自定义短语、导入的词库、主题；
- 剪贴板历史（可以关闭）；
- 每个输入框最近写的一小段文字，用来给接着打的内容提供上下文；只在内存里，不写入存储，过一阵就忘；
- 语音这一次打进来的字，改错的词时用来问要不要让语音记住；只在内存里跟着，离开输入框就丢，点「记住」才把那个词存进用户词库；问过、记住过几次两个数存在手机上（开发者页能看到）；
- 学到的东西的自动备份（最近 2 份），在输入法自己的目录里。

号码、网址、邮箱这些不学；没有云同步。

例外是 Android 12 及以上系统自带的换机迁移（新旧手机直连）：系统会把设置、学到和添加的词、自定义短语、导入的词库和主题一起搬到新手机，剪贴板历史不会。应用不使用云端备份。

**密码框里会怎样？**
密码框和应用要求不记录的输入框（比如浏览器的无痕模式）里：不读取输入框里的文字、不学习、不记上下文；应用要求不记录的输入框里长按候选只出读音和卡（读音行，点开词卡、字卡），没有菜单项。密码框里键盘自动换成英文、字母直接上屏，不能用语音输入，工具栏会显示数字行，方便打数字密码；离开密码框就回到原来的输入法。

**借手机给别人，不想让他看到我的习惯？**
工具栏 **⋯ → 不用我的输入习惯**：键盘像刚装好一样，你的词、联想、固定都不出，也不学他打的；拿回来在 **⋯** 里恢复。它防的是顺手看到，设置里的用户词库照样打得开。见[借手机](words.md#借手机不用我的输入习惯)。

**刚才打的不想被学进去？**
工具栏 **⋯ → 清掉最近**，选 10 分钟、1 小时或今天。没有"暂停学习"的开关。

## 备份与换机

**怎么备份？**
**备份与恢复 → 备份全部**，得到一个 `youmo_<时间>.zip`，里面有设置、学到和添加的词、自定义短语、导入的词库、主题和剪贴板记录。
文件**没有加密**，剪贴板里你复制过的内容（包括复制过的密码，只要应用没有把它标为敏感）也在里面，请自己保管好。

**换手机怎么办？**
在旧手机上"备份全部"，把文件传到新手机，在 **备份与恢复 → 从备份恢复** 里选它。设置、自定义短语照备份覆盖，标点用 App 自带的（0.6.1 起备份里改过的标点表不恢复）；学到的和新手机上的合并，恢复前自动存一份，后悔了可以退回，应用自动重启。
只想带走词和学到的：在用户词库里另存一份备份（或导出），在新手机上恢复，见[备份](words.md#备份)。新手机上第一次打开时，引导页里有一行"以前用过？从备份恢复"。

**卸载重装后学到的词还在吗？**
不在。卸载会删除应用的全部数据，自动备份也在里面，一起没了。卸载前请先在用户词库里另存一份备份到看得见的文件夹，或者"备份全部"。直接覆盖安装（升级）则会保留一切，资源包也在。

**想装回旧版本怎么办？**
安卓不允许在新版上直接装旧版。先在新版"备份全部"，卸载，装旧版，再在 **备份与恢复 → 从备份恢复** 里选那份备份：设置、输入法和顺序、繁体、快速输入、自定义短语都回来（0.6.1 起备份里没有改过的标点表，旧版用它自带的标点）。装回 0.6.2 及以前，剪贴板收藏显示成置顶，最近里也有的同样内容会出现两次（置顶一条、下面一条）；敏感的收藏不在备份里。学到的词装回 0.3.1 及以后的版本也在；**装回 0.3.0 会丢**，0.3.0 读不了新版备份里学到的词。并入基础词库的导入词库装回 0.3.x 后看不到、打不出；文件还在备份里，再升级回来就又有了。0.4 及更早要回到这一版，先覆盖安装 0.6.2，弹出键盘打几个字、停一下，再装这一版，直接装会丢掉码表里存的词等。

**升级到 0.3.1 后，候选顺序怎么变了？**
学习换了一套规则（见[输入法怎样学你的词](pinyin.md#输入法怎样学你的词)）。以前学到的顺序没有记你按的是哪串键，分不到全拼、简拼、九键各自名下，所以顺序从头学；你的词、加的词、屏蔽的词都还在，以前全拼的置顶转成了固定。装回旧版，看到的是升级前的学习。升级后第一次打字时，以前学到的在后台转换，学得多的要等一会儿，这段时间候选里还没有它们，打的字照常学；转换好以后，停下来不打字一秒左右（或收起、再弹出键盘）就用上，打到一半时不会换。这时打开词库页、备份、恢复或清空，会先等转换做完。

## 大小与耗电

**为什么这么大？**
安装包本身不大，大的是资源包：安装包约 21.6 MB，文字包约 297 MB，语音包约 176 MB（0.6.1）。里面是离线运行需要的数据：语言模型、两个用来按整句排序的模型、词库、手写识别模型，语音包是语音识别模型。准确率优先于体积，这是有意的取舍。资源包导入时复制进应用的目录，之后直接从那里读，导入完原文件可以删掉。资源包没有新版本时，升级只要下安装包。

**费电吗？**
大部分时间和普通输入法差不多。**通用输入** 里的**性能档位**（各中文输入法共用）决定花多少计算在排序上：高档（默认）在你停顿时（手写是一个字写完时）多算一下，最准；觉得耗电可以调到中档或低档。语音识别时会占用较多 CPU，只在语音输入进行时录音（按住空格到松开，或点麦克风到结束）。

## 用起来

**怎么切回系统键盘？**
长按地球键，在弹出的选择框里选别的输入法；或者在系统设置里改默认键盘。

**折叠屏展开、平板竖拿时，键盘为什么按横屏排、还分体了？**
屏幕宽 600 dp 以上都算横屏，竖拿也一样：用横屏那份高度、间距、候选栏高度和 **横屏键盘样式**（没设过时分体），键盘高度和转过来一样。不想分体就把 **设置 → 外观 → 大小与样式 → 横屏键盘样式** 选成普通。外屏和手机竖拿照旧按竖屏。系统的「显示大小」调到大时，展开的屏可能不到 600 dp 宽，这时按竖屏排。

**某个词老是打不出来 / 某个词老是冒出来 / 排序不对？**
见[词库与短语 · 想要什么样的效果，用哪个功能](words.md#想要什么样的效果用哪个功能)。长按候选选 **为什么排在这**，能看到它排在那里的原因。

**选了一次，为什么还不是第一个？**
有意的：选一次只排到前面，在同一个前文后面连着选两次才换第一，免得一次误选拿掉天天打的词。要立刻第一，长按它选 **固定首位**。

**我打的英文被改错了。**
上屏后马上按退格，就恢复成你打的原样，而且以后不再改这个词；过后点回这个词、换回原词也算。不小心改回的，在英文词库里能找到这个词，恢复自动改。也可以在 **输入法 → 英文 → 英文词库** 里加上这个词，或者关掉英文的"单词提示"。

**为什么有些新词打不出来？**
新词随应用版本发布，每月一版，应用不联网自动更新。数据超过半年时首页会提醒你去下载新版。急用的词可以自己加到用户词库。

**为什么在某个应用里表现不一样（不提示、不纠错、回车变成发送）？**
输入框会告诉输入法自己是什么类型：网址、邮箱、密码、搜索框、不要提示等，键盘会照着调整。在 **开发者 → 编辑器信息 (EditorInfo) 检查器** 里能看到当前输入框说了什么。

**横屏或分屏时键盘太高 / 太矮？**
**外观 → 大小与样式 → 键盘高度**，竖屏和横屏各有对应高度。横屏按每行按键的高度定（手机标准每行 48 dp，平板、折叠屏内屏 56 dp）。

**横屏选了「高」「很高」，键盘却没变高？**
横屏时键盘上方至少给应用留 120 dp，好让输入框露出来；屏幕矮、用手势导航时，「标准」已经碰到这条，再选高的档也只能到这么高，按键反而按这条压矮（每行最矮 36 dp）。换成三键导航，或在全屏视频、游戏这类全屏的应用里，空间多一些，高的档就看得出差别。

**横屏时键盘分成了两半？**
这是**分体**，方便横握时两个拇指打字。不想要就在 **外观 → 大小与样式 → 横屏键盘样式** 里选"普通"。

**为什么竖着是普通的、横过来就悬浮了（或单手了）？**
竖屏和横屏的键盘样式各记各的：横拿时在键盘上点了悬浮或单手，改的是 **横屏键盘样式**，竖过来还是原来的。两边都想要，就在 **外观 → 大小与样式** 里把 **竖屏键盘样式** 也选上。

**降级到 0.6.0 再升回来，在 0.6.0 里改的分体、单手、悬浮没有用上？**
0.6.0 的这三项和 0.6.1 的键盘样式分开存。升级到 0.6.1 时只换算一次，降级后在 0.6.0 里改的不再换算回来；升回来后到 **外观 → 大小与样式** 里重新选竖屏、横屏键盘样式就好。

**横屏时数字键盘、符号只占一边？**
分体时其他面板缩成单手宽，免得中间的键两只手都够不着。点空白处的箭头可以换到另一边；想铺满在 **外观 → 大小与样式 → 分体时其他面板** 里选"铺满"。

**怎么做自己的主题？**
App 里不能改主题；做主题在网页上做：**外观 → 主题 → 新增主题 → 在网页上制作** 用浏览器打开制作页（https://sraw.github.io/youmo-ime/theme-maker/），做好后回到这里选 **导入主题文件**。App 里能列出、使用、导入、导出和删除主题；**导入主题文件** 打开文件选择，导入制作页做的或别人导出的主题文件 `.theme`，也能导入百度（`.bds`、`.bdi`）、搜狗手机版（`.ssf`）的皮肤和同文（`.yaml`）、FlorisBoard（`.flex`）的主题，导入时转成主题（按键位置、动画等转不过来，导入时会列出；百度 `.bda`、搜狗 `.sxi`、电脑版皮肤和 AnySoftKeyboard 主题暂不支持）。0.5.0 及更早版本和 fcitx5-android 原版导出的 `.zip` 主题，改名成 `.theme` 再导入（直接导入会提示改名）。以前做的主题（用图片做的、复制的内置主题）照常能用。详见[设置 · 主题](settings.md#主题)。

**主题里的字体可以随便用吗？**
导出和分享主题时字体文件也打包在里面，别人导入就拿到了这个字体。只用允许转发的字体（比如 SIL OFL 授权的），商用字体多半不许这样分发。

**接了实体键盘，怎么切换输入法、怎么叫出屏幕键盘？**
单按 Shift 或 Ctrl+空格 切中英，Ctrl+Shift 轮流切换输入法；点光标旁小窗右端的键盘图标，屏幕键盘就回来（一般应用里点一下输入框也行，Chrome 等浏览器的网页输入框要用这个图标）。详见[键盘与手势 · 实体键盘](keyboard.md#实体键盘)。

**装过 0.6.0 测试版，升级正式版要做什么？**
直接覆盖安装，设置和导入的资源包都在；测试版里改过的长按、滑动不带过来，回到从 0.5 带过来的设置或预设，见[从旧版本换过来](getting-started.md#从旧版本换过来)。

**长按列表能加多少项？**
每个键最多 16 项，满了再加会提示。从 0.5 升级时超过 16 项的，按列表顺序留前 16 项。

## 遇到问题

**键盘不出来、没反应？**
1. 确认系统设置里幽默输入法是启用的，并且是当前键盘。
2. 在 **开发者 → 重启 Fcitx 实例** 里重启引擎。
3. 还不行就重启手机。

**清理软件清了 `Android/data`，设置会回到默认吗？**
不会。输入法设置（通用输入、各输入法的选项、标点的开关、繁体）、自定义短语、导入的词库、快速输入和主题都存在应用自己的目录里，清理软件碰不到。从旧版升级后第一次启动时会把原来放在 `Android/data` 里的这些搬过来，逐个核对、用上之后删掉旧的那份。

要装回旧版（0.4.0 及更早），得先卸载，这些会一起清掉；先在新版里"备份全部"，装好旧版后再恢复。

**为什么有个字打不出来、候选里没有？**
先看 **词库与短语 → 生僻字屏蔽** 是不是开着、这个字是不是被挡了：在页上的搜索框粘贴这个字就能看到，点一下放行，离开页面后就能打。长按候选选过 **屏蔽** 的字词在 **用户词库 → 屏蔽的词** 里。一级、二级常用字不会被生僻字屏蔽挡掉。

**提示"部分输入设置读取失败"？**
有设置文件这次没读出来（比如存储出了问题）。只有读不出来的那个文件这次按默认值打字，它的改动不会保存，原来的内容不会被默认值覆盖；别的设置照常保存。重启手机后再试。一直这样就[报告问题](#遇到问题)。

**提示"输入设置暂时无法就位"？**
升级后第一次搬设置没搬成（比如那次启动时外部存储不在）。这次打字可能用的是默认设置，改动（包括在设置页里改的）在重启前不会保存。重启手机后会再搬一次。

**提示"你添加的内容和设置这次无法就位"？**
升级后第一次搬设置和数据没搬成。这次能照常打字，但改短语、导入词库、改主题、备份和恢复都会被拒绝，以免改动存到下次启动读不到的地方。重启手机后会再搬一次。

**提示"部分你添加的内容读取失败或无法就位"？**
自定义短语、快速输入或主题这次没读出来或没搬成。读不出来的那份原样保留、不会被覆盖，这次暂时缺失或用内置的。重启手机后再试。

**键盘上方写着"没写进去：……，点一下输入框"？**
输入框收下了你打的字，却没有写进去，输入法把这些字留在键盘上，免得丢。最常见的是网页里的输入框：横屏或转屏时键盘几乎把网页盖满，网页就不再接收文字，但键盘还开着。点一下那个输入框，再点键盘上方的这一行，留着的字就写在光标处。不想要这些字，接着打别的就行：新打的字写进去以后这一行就消失；换一个输入框或收起键盘也会消失。密码框和应用要求不记录的输入框不做这项检查。个别应用的输入框本来就不收某些字（比如只收数字、已经打满），也会出现这一行，这时点它没有用。终端、远程桌面这类收下文字就清空输入框的应用，一般不会再出现这一行；个别仍出现时不用点，接着打字就行。留着的字最多保留最后 256 个。

**提示"学到的词暂时无法保存"？**
学到的词这次只记在内存里，没能写进手机存储，输入法进程被系统关掉后就没了；以前已经存下的不受影响。常见原因是存储空间满了，或者存储这次出了错。清出一些空间后，学到的词就会照常保存，不用重启；还不行就重启手机。重启后还出现，请按下面的方法报告问题并附上日志。
如果是刚开机、还没解锁时看到"手机解锁前学到的词不会保存"，不用管：解锁后照常保存。
学到的词一直存不下时，用户词库页顶上和工具栏 **⋯** 面板最上面会一直显示一行"学到的词现在没在保存"；之后哪一次存下了，这一行就自动消失，不用重启。存储坏到连学习记录都打不开时，这一行留到输入法重启。学习记录写失败后也收拾不回来（文件截不回、也重开不了，从此到输入法重启都不再接受写）时，**清掉最近** 和 **清空学到的** 会提示"没清掉：学到的词现在存不下，重启键盘后再清"，什么都不清（自动备份和"退回恢复前"那份也不动）：在系统设置的应用信息里把输入法强行停止，或者重启手机，再清。这时（或这次学习记录根本没打开）从备份恢复或退回恢复前没做成，也一样提示"没做成：学到的词现在存不下，重启键盘后再试"。长按候选 **删除** 的词（或在用户词库页删的词）这次没写进手机存储、只在内存里时，要是存不下以来没写进去的只有这一次删除，点 **撤销** 照常撤回；它之前或之后还有别的只记在内存里（比如存不下以后才学到、又删掉的词，或删掉以后又打的字），就提示"已经撤销不了了"，什么都不动，别的也不会因此丢掉。固定首位、不再联想、屏蔽不受影响：它们的撤销不用重写学习记录，存不下时也照常撤回。这次学习记录根本没打开（学到的只记在内存里）时，撤销删除也提示"已经撤销不了了"。已经写进存储的删除，撤销要把学习记录重写一遍，重写没成（记录不再接受写，或者重写时存储满了）时提示"没撤销成：学到的词现在存不下"，什么都没撤回，提示条上不再有 **撤销**。只是存储满了时没清掉、没做成，提示的是"没清掉，再试一次""没做成，再试一次"：重启没用，清出一些空间后再试就行，不用重启。学到的词照常在保存时没清掉、没做成，也是这两句；存一份备份没做成也是"没做成，再试一次"。
手动加的词、屏蔽的词没能存下时，也是这条提示：改动这次只在内存里。这两样没存下不会让上面那一行出现。

**提示"自定义短语或常用词的改动没能保存"？**
在键盘上删常用词、固定或删自定义短语后没能写进手机存储：改动这次只在内存里，输入法被系统关掉或重启手机后就没了，以前存下的不受影响。清出一些空间后，下次在键盘上再改同一样（短语或常用词）时会连这次的一起存下，不用重启；还不行就重启手机（这次的改动随之丢失），重启后仍然出现就报告问题。

**提示"学习记录有读不出来的内容"？**
手机上的学习记录有一部分坏了（比如存储出过错）。读得出的部分照常使用；坏掉的那几条跳过，原文件整份另存一份，不会丢。坏掉的那部分学到的词这次用不上；想找回，到 **学习备份** 里恢复一份以前的备份。另存的那份清空学到的（勾不勾全部清空都一样）或清掉最近时一起删掉。
