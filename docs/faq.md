# 常见问题

## 隐私与权限

**输入法会上传我打的字吗？**
不会。应用没有网络权限，系统层面就不允许它联网：没有云输入、没有统计、没有崩溃上报、不检查更新。打字、纠错、排序、语音识别全部在手机上完成。

**系统启用输入法时提示"可能会收集您输入的所有文字"，是怎么回事？**
这是 Android 对所有第三方输入法都会显示的固定提示。本输入法不联网，打的字不会离开手机。

**申请了哪些权限？**
- 文字版：只有**振动**（按键振动用）。
- 语音版：再加**录音**（只在你按住说话时使用）。

不申请通知、通讯录、位置、存储等其他权限。构建时会检查，多出任何权限都无法通过。导入、导出文件都通过系统的文件选择器，由你选择具体文件。

**它记住了我的哪些东西？存在哪？**
都只在手机上：
- 你打过的词和次数（用来把你的词排前面）、你添加和屏蔽的词；
- 自定义短语、导入的词库、主题；
- 剪贴板历史（可以关闭）；
- 每个输入框最近写的一小段文字，用来给接着打的内容提供上下文；只在内存里，不写入存储，过一阵就忘。

例外是 Android 12 及以上系统自带的换机迁移（新旧手机直连）：系统会把设置、学到和添加的词、自定义短语、导入的词库和主题一起搬到新手机，剪贴板历史不会。应用不使用云端备份。

**密码框里会怎样？**
密码框和应用要求不记录的输入框（比如浏览器的无痕模式）里：不读取输入框里的文字、不学习、不记上下文，长按候选也没有菜单。密码框里还不能用语音输入，工具栏会显示数字行，方便打数字密码。

## 备份与换机

**怎么备份？**
**高级 → 备份全部**，得到一个 `youmo_<时间>.zip`，里面有设置、学到和添加的词、自定义短语、导入的词库、主题和剪贴板记录。
文件**没有加密**，剪贴板里你复制过的内容（包括复制过的密码，只要应用没有把它标为敏感）也在里面，请自己保管好。

**换手机怎么办？**
在旧手机上"备份全部"，把文件传到新手机，在 **高级 → 从备份恢复** 里选它。恢复会覆盖新手机上的全部数据，应用自动重启。
只想带走词：**词库 → 用户词库 → 导出**，在新手机上"导入词表"。

**卸载重装后学到的词还在吗？**
不在。卸载会删除应用的全部数据，卸载前请先备份。文字版和语音版之间直接覆盖安装则会保留一切。

## 大小与耗电

**安装包为什么这么大？**
文字版约 260 MB，语音版约 440 MB。大部分是离线运行需要的数据：语言模型、两个用来按整句排序的模型、词库，语音版还有语音识别模型。准确率优先于体积，这是有意的取舍。数据直接从安装包里读，不会再复制一份占空间。

**费电吗？**
大部分时间和普通输入法差不多。拼音、手写和码表设置里的**性能档位**（几处共用）决定花多少计算在排序上：高档（默认）在你停顿时（手写是一个字写完时）多算一下，最准；觉得耗电可以调到中档或低档。语音识别时会占用较多 CPU，只在按住说话时运行。

## 用起来

**怎么切回系统键盘？**
长按地球键，在弹出的选择框里选别的输入法；或者在系统设置里改默认键盘。

**某个词老是打不出来 / 某个词老是冒出来 / 排序不对？**
见[词库与短语 · 想要什么样的效果，用哪个功能](words.md#想要什么样的效果用哪个功能)。

**我打的英文被改错了。**
上屏后马上按退格，就恢复成你打的原样，而且以后不再改这个词。也可以在 **输入法 → 英文 → 英文词库** 里加上这个词，或者关掉英文的"单词提示"。

**为什么有些新词打不出来？**
新词随应用版本发布，每月一版，应用不联网自动更新。数据超过半年时首页会提醒你去下载新版。急用的词可以自己加到用户词库。

**为什么在某个应用里表现不一样（不提示、不纠错、回车变成发送）？**
输入框会告诉输入法自己是什么类型：网址、邮箱、密码、搜索框、不要提示等，键盘会照着调整。在 **开发者 → 编辑器信息 (EditorInfo) 检查器** 里能看到当前输入框说了什么。

**横屏或分屏时键盘太高 / 太矮？**
**主题与大小 → 大小与按键 → 键盘高度**，竖屏和横屏各有对应高度。

**接了实体键盘怎么用？**
见[键盘与手势 · 实体键盘](keyboard.md#实体键盘)。

## 遇到问题

**键盘不出来、没反应？**
1. 确认系统设置里幽默输入法是启用的，并且是当前键盘。
2. 在 **开发者 → 重启 Fcitx 实例** 里重启引擎。
3. 还不行就重启手机。

**怎么报告问题？**
到 [GitHub Issues](https://github.com/Sraw/youmo-ime/issues) 提交，写明文字版还是语音版、版本号（**关于** 里有）、手机型号和 Android 版本、怎样能重现。
可以附上 **开发者 → 实时日志** 导出的日志。日志里可能有你打过的字，提交前请看一遍。
本项目由 Fcitx5 for Android 分叉而来，问题请报在这里，不要报到上游。
