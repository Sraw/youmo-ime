# 其他输入方式

## 英文

默认就有"英文"输入法，按地球键切换。打法和常见的手机英文键盘一样，一次一个词：

- 打字时候选栏最左边是按空格会上屏的词：拼对时就是你打的词；拼错时是改正后的词，你打的原样紧挨在它右边。再往右是以这几个字母开头的、可能是的其他词。
- **按空格**上屏最左边那个；如果你打的不是一个词，会自动改成最可能的那个（`teh` → the，`dont` → don't）。想要原样，点它右边你打的那个。
- 改错了就**马上按退格**：恢复成你打的原样，而且这个词以后不会再被改。
- 上屏后自动加一个空格；接着打标点，空格会移到标点后面。**连按两下空格**打出句号。
- 上屏一个词后会给出下一个词的联想。
- 句首自动大写（要输入框要求时才会，比如短信、邮件正文；用户名、网址框不会）。
- 你打过两次的词会被记住，以后不会再被改错；也可以在 **输入法 → 英文 → 英文词库** 里手动添加。粗俗词不会被当成"改正"给出。

在网址、邮箱、密码框里，以及应用要求不提示的输入框里，按键直接上屏，不提示也不改。
英文的选项见[设置逐项说明 · 英文](settings.md#英文)。

## 手写

在 **输入法** 里添加"手写"。键盘的大部分是书写板，右边是退格、"，"（长按有更多标点）和"。"，下面是符号、数字、空格、地球键和回车。

- 一次写一个字，写完一笔就开始识别。停笔约 0.7 秒，书写板清空，接着写下一个字。写得快可以在手写设置里把**停笔多久算写完一个字**调短（最短 0.3 秒），写一个字中间常停顿的可以调长。
- 写好的字先连成一句显示在输入框里（带下划线，还没上屏），像拼音一样按整句来读：用拼音的语言模型和你的用户词库挑出最通顺的读法。所以后面写的字能把前面认错的改过来，比如单写"淡"，接着写"话"就变成"谈话"。
- 候选栏是**最后一个字**的几种可能。点候选或按数字，上屏以它结尾的那一句；按空格上屏输入框里的整句；按回车、标点也是先上屏整句。
- **退格**：书写板上还有笔画时，撤掉最后一笔；没有笔画时，去掉最后一个字；什么都没写时，删除前面的字。
- 收起键盘或离开输入框时，还没上屏的字会照原样留在输入框里。
- 手写会用到你的用户词库。只有你从候选里**点选了第一个以外**的那一项，才会学进去（记次数，没有的词加进词库），下次同样写会更靠前；直接上屏的第一候选（空格、回车、点第一个）不学，因为识别还常出错，没留意的错字学进去会反复出现。密码框里什么都不学。
- 句子会接着光标前的文字来读（比如前面是"高"，写的字更可能读成"山"）。
- 和拼音一样有**性能档位**（两边共用一个设置）：中档每写一笔就按整句通顺程度重排，高档在一个字写完（停笔）时再用大模型精挑一次。档位越高，写字当时显示的那句越准。
- 上屏以后会**联想下一个词**（和拼音共用这个开关）：点一下联想词就上屏，并记进用户词库；长按联想词可以忘记它或不再显示它（和[拼音的长按候选](pinyin.md#长按候选)一样）；接着写字、按退格或别的键，联想就消失。按回车上屏时不联想。

识别全部在手机上进行。目前识别模型只用合成的笔迹训练过，单个字的准确率还不高（第一个候选约七成对）；按整句读之后，整句上屏时约九成的字是对的，之后会继续改进。

## 码表输入法：五笔、仓颉、自然码、二笔、五笔拼音

在 **输入法** 里添加。都用 26 键全键盘，按编码出字：

- 正在打的编码显示在候选栏上方，不进输入框。
- 编码打满且只有一个字时直接上屏；再按下一个键打不出东西时，也会自动上屏第一个候选（都可以在设置里关掉）。
- 空格上屏第一个候选；打出不存在的编码（空码），下一个键会把它丢掉。
- 编码打错了不用全删：点一下编码那一行，光标停在点的地方，接着打的键插在那里，退格删光标前面的键；也可以在空格键上左右滑动，或用实体键盘的方向键移动光标。光标不在末尾时打的键只插进去，不会自动上屏第一个候选；改完整个编码只有一个字时照样直接上屏。拼音反查（五笔先按 `z`）时改的是拼音，和拼音输入法一样。
- **显示编码提示**：候选旁边显示这个字还要按哪几个键，方便学编码。
- **自动造词**：一个字一个字打出来的词，会按这个码表的组词规则造成词，打过几次以后记住。
- 你在拼音里打过、加过的词，码表里也能按码表的规则打出来；码表里打的字词也会记进同一个用户词库，拼音、手写里一样排前。
- **重码按上下文排**：同一个编码有几个字词时，你自己造的词、以及在码表里选过的拼音词排在前面，其余按前面已经打的内容排，最可能的排第一（性能档位越高越准）。五笔、五笔拼音的一、二级简码顺序不动；关掉"常用的字词排前面"就严格按码表顺序，适合靠位置盲打的人。
- **联想**：上屏后在候选栏给出可能接着打的词，点一下上屏；长按联想词可以忘记它或不再显示它（和[拼音的长按候选](pinyin.md#长按候选)一样；单字和码表的候选一样不能设为不再显示，因为不再显示的字在拼音、笔画里也会一起消失）；接着打编码，联想就消失。

各码表的特殊键：

| 码表 | 特殊键 |
|---|---|
| 五笔（86 版） | `z` 是万能键（代替不会的那一码），也用来**拼音反查**：先按 `z` 再打拼音，候选旁会显示五笔编码 |
| 二笔 | `[` 开头是拼音反查，`*` 是万能键 |
| 仓颉 | `*` 是万能键 |
| 自然码 | 码表式的自然码：每个字按自然码双拼编码，词由各字双拼的前几码组成，按码表出字、没有整句。想整句打自然码双拼，用"双拼"输入法选自然码方案 |
| 五笔拼音 | 五笔和拼音混打，不用切换 |

每个码表自己的默认值不同（比如五笔默认显示提示、最多造 4 字词、打过 3 次后记住），见[设置逐项说明 · 码表](settings.md#五笔等码表)。

## 快速输入

**长按"符"键**进入快速输入，栏上显示"快速输入："，然后打关键词：

| 打 | 得到 |
|---|---|
| 英文情绪词，如 `yawn`、`happy`、`cry` | 颜文字，如 (￣□￣)、(๑´ڡ`๑) |
| `:` 加表情名，如 `:smile:`、`:yawning_face:` | 对应的 emoji 😄 🥱 |
| `\` 加 LaTeX 名，如 `\alpha`、`\pounds`、`\rightarrow` | α、£、→ |

空格上屏第一个，退格删到头就退出快速输入。

## Unicode 输入

**长按"123"键**进入 Unicode 输入，栏上显示"Unicode："：

- 打字符的英文名，比如 `smile`、`arrow`、`degree`，会列出名字里有这个词的字符。
- 也可以打十六进制编码，比如 `U+4F60`（你）、`U+00B0`（°）。

## 语音输入（语音版）

语音版能离线说话打字，识别在手机上完成，录音不保存、不上传。目前只支持**普通话和英语**，中间夹英文也行。带口音的普通话也能认：模型专门用北方各地口音的语音训练过，四川、陕西、甘肃、宁夏、山东、河南、南京等地的口音比原版认得准，标准普通话不受影响。粤语、吴语等方言暂不支持。

**两种说法**：

1. **按住空格说话**（语音版默认）：长按空格，出现"正在听…"后开始说，**松开手指上屏**；说的时候**手指上滑**再松开就取消。
2. **语音面板**：点工具栏上的**麦克风**，按住面板中间的话筒说话，松开上屏；手指滑出话筒圈再松开就取消。

识别时会做的事：

- 每次停顿识别一段，屏幕上先显示听到的内容，松开手指才真正上屏，并且只上屏到你开始说话时的那个输入框。
- 数字按习惯写：二零零二年 → 2002年，百分之五十七 → 57%，六点半到七点半 → 6点半到7点半；"一个""十分有趣"这类不是数字的不会乱改。
- 用拼音引擎的语言模型从几个识别结果里挑最通顺的；新词库里的新词和你自己的词会优先听出。
- 你屏蔽的词不会出现在语音结果里。
- 只有咳嗽、"嗯"之类的声音不会打出东西，显示"没有听清"。

第一次使用时会请求**麦克风权限**（输入法本身不能弹权限框，所以会短暂打开一个页面来请求）。
**密码框里不能用语音输入。**

不想用按住空格说话，可以在 **按键与振动 → 空格键长按行为** 里改成别的。
