# 其他输入方式

## 英文

默认就有"英文"输入法，按地球键切换。打法和常见的手机英文键盘一样，一次一个词：

- 打字时候选栏最左边是按空格会上屏的词：拼对时就是你打的词；拼错时是改正后的词，你打的原样紧挨在它右边。再往右是以这几个字母开头的、可能是的其他词，也有按偏了一两个键时可能想打的词（打 hello 也会给出 yellow）。
- **按空格**上屏最左边那个；如果你打的不是一个词，会自动改成最可能的那个（`teh` → the，`dont` → don't）。想要原样，点它右边你打的那个。
- 改错了就**马上按退格**：恢复成你打的原样，而且这个词以后不会再被改。过后再点回这个词，原词排在候选第一个，换回原词也一样。
- 上屏后自动加一个空格；接着打标点，空格会移到标点后面。**连按两下空格**打出句号。
- 上屏一个词后会给出下一个词的联想（搜索框里不给）。
- 打到一半的词显示在输入框里（带下划线）。收起键盘、离开输入框、转屏，或者改了要重建键盘的设置（换主题、系统切深色模式）时，它照原样上屏，不会被删掉、也不改正；悬浮和停靠之间切换时它还在，接着打就行。
- 单独的 `i` 和 `i'm`、`i'll` 这类以 `i'` 开头的词，上屏时自动写成 `I`、`I'm`，点按和滑行都一样。
- 句首自动大写（要输入框要求时才会，比如短信、邮件正文；用户名、网址框不会）。
- 这样改回过一次的词，以后不再被改；这些词在英文词库里能看到，也能恢复自动改。也可以在 **输入法 → 英文 → 英文词库** 里手动添加。大小写按你打的（GitHub、iOS）。英文里学到的词，全拼的中英混输里也打得出。粗俗词不会被当成"改正"给出。只是打过几次不算：没改回过、也没添加的词，照样可能被改；有改正时在候选里点原样的词，也算改回过一次。
- **屏蔽**：长按英文候选（补全、改正后的词、滑行的其他词、联想）选 **屏蔽**，这个词以后不再出现、不再补全或联想，打错时也不再被改成它（屏蔽 the 后 `thw` 不再改成 the）；大小写：屏蔽的词按它本来的写法记（句首显示的 The、全大写显示的 THE 都记成 the）；本来全是小写的词，各种大小写都不再出现（屏蔽 the，The、THE 也不出）；本来带大写的，只屏蔽这个写法（屏蔽 US，us 照旧）。英文的屏蔽和拼音里的英文词各管各的：在英文里屏蔽 app，拼音候选里的 app 照旧，在拼音里屏蔽也不影响英文。在设置里恢复后可以撤销。你原样打的那个不给屏蔽。屏蔽的英文词和拼音的屏蔽词列在同一页"屏蔽的词"里（没有拼音），点一下恢复；备份、恢复、清空时一起处理。
- **滑行输入**：手指按在一个词的第一个字母上，不抬手依次划过它的字母，在最后一个字母上抬起，这个词就连同空格上屏，键盘上会画出手指走过的线。候选栏是它可能的其他词，点一个就把刚上屏的换掉；紧接着按**退格**整个词删掉。接着再划下一个词就行，空格已经有了；划完接标点，空格会移到标点后面。不让记录的输入框（无痕模式之类）里键盘不读框里原有的文字，按键直接上屏时（不提示单词）也不记打进去的字，所以光标前的字不是键盘自己提示上屏的时，划出的词前面不会自动加空格，要自己点（键盘自己上屏的字用退格删掉几个后照样算，但删到或删剩大多数表情、单独打出的重音等组合符号或少见的回车符时就不算了）；紧接在上一个划出的词后面再划，空格是有的。Shift 开着时首字母大写，大写锁定时全大写；Shift 没开就不大写，跟点按打字一样（要求句首大写的输入框里句首 Shift 会自动开着），人名、iPhone 这类本身带大写的词照原样。正在打字时开始划，先把打着的词按空格的方式上屏。字母键上下短划打角标符号、长按出更多字母都照旧：只有横着划过大半个键，或上下划过一行半以上，才算滑行。默认关闭，在 **通用输入** 的 **在键上划** 里选 **滑行输入**；拼音和码表也能滑行（见[拼音](pinyin.md#滑行输入)和下面的码表），所有输入法是同一个设置。选了笔画筛选时英文不滑行。

英文默认是全键盘；在 **输入法 → 英文** 里把 **键盘** 选成「九键」，就是九宫格的英文，见[九键英文](keyboard.md#九键英文)。英文的键盘不跟拼音走，各选各的。

在网址、邮箱、密码框里，以及应用要求不提示的输入框里（关掉 **单词提示** 时也一样），按键直接上屏，不提示也不改。网址、邮箱和密码框里不能滑行；其余这些框里打开了滑行输入也能划词，和上面一样：光标前有字时前面自动加空格，紧接着按退格整个词删掉，接标点空格移到标点后面；划出的词会像别处一样被记住（无痕模式之类不让记录的框除外），直接打的字不会。
英文的选项见[设置逐项说明 · 英文](settings.md#英文)。

## 手写

在 **输入法** 里添加"手写"。键盘的大部分是书写板，右边是退格、"，"（长按有更多标点）、"。"和 **注**，下面是符号、数字、空格、地球键和回车。"，""。"键上显示的就是按下去会打出的标点：关了中文标点（或标点设成半角）时显示 "," "."。

- 一次写一个字，写完一笔就开始识别。停笔约 0.7 秒，书写板清空，接着写下一个字。写得快可以在手写设置里把**停笔多久算写完一个字**调短（最短 0.3 秒），写一个字中间常停顿的可以调长。
- 写好的字先连成一句显示在输入框里（带下划线，还没上屏），像拼音一样按整句来读：用拼音的语言模型和你的用户词库挑出最通顺的读法。所以后面写的字能把前面认错的改过来，比如想写"谈"却被认成"淡"，接着写"话"就变成"谈话"。写得清清楚楚、识别很有把握的字很少被改：后面的字主要在前一个字本来就拿不准时起作用。
- 候选栏是**最后一个字**的几种可能。点候选或按数字，上屏以它结尾的那一句；按空格上屏输入框里的整句；按回车、标点也是先上屏整句。
- **退格**：书写板上还有笔画时，撤掉最后一笔；没有笔画时，去掉最后一个字；什么都没写时，删除前面的字。
- 收起键盘、离开输入框、转屏，或者写到一半改了要重建键盘的设置（换主题、系统切深色模式）时，还没上屏的字会照原样上屏留在输入框里。拖着把手在悬浮和停靠之间切换不算改设置，写的字还在，接着写就行。
- 手写会用到你的用户词库，也自己学，和拼音互不改顺序：
  - 识别出的前 3 个候选是同样三个字（不论先后），就算"同样写"，不看前面写的字。
  - 点选了第一个以外的字，下次同样写，它排到前面；连着这样选两次，它排第一。中间有一次停笔自动上屏了当时的第一个，就从头数：偶尔误点一次，学不进去。
  - 用过的字（点选的、上屏的）按次数排在前面，其余照识别的顺序。
  - 上屏后马上删掉的不算用过（联想选的词也一样）；删掉后重写：重写出的字在被删那次的候选里，才算那次改选，一个字一个字重写也算；上屏前清掉重写的，不学。
  - 一次上屏的 2～4 个字、词库里没有的，同样上屏两次，成为你的词（和[拼音](pinyin.md#你的词)一样）。
  - 长按手写的候选有 **删除** / **忘掉学到的** 和 **屏蔽**（屏蔽的是候选上显示的这个字；连写几个字时，每个字写出来时都在候选里、都能这样屏蔽；屏蔽的字也不再通过含它的词出现，比如屏蔽「人」后写「天」「人」不会因为「天人」再出「人」），没有 **固定首位**（手写没有固定的编码，误点固定后错字会一直自动上屏）。
  - 密码框里什么都不学。
- **读音**：打开[候选词注音](settings.md)后，手写的候选（几乎都是单字）标出这个字的**全部读音**：多音字标前两个，用「/」隔开，还有更多就在后面加「…」（行 xíng/háng…）。前面写的字和它成词时，那个词里的读音排第一（写「银」再写「行」，标 háng/xíng…）。拼音放不下时先把字缩小（最小 7sp），再把候选加宽；注音符号一个读音一竖列，并排。每个字标它自己的声调，不标轻声（只有「的、了、吗、呢、们、么」这类只读轻声的字标轻声）。联想词和别的输入法照旧只标一个读音。
- **注** 键（右边一列最下面）：点一下在关闭和打开之间切换候选词注音，打开时用上次用的样式（第一次是拼音），打开时「注」显示成强调色；长按可以选 **关闭** / **拼音** / **注音符号**。和设置里的 **候选词注音** 是同一个开关，各中文输入法都跟着变。写到一半点「注」，先把这个字写完，再切换；写好还没上屏的字原样留着，什么都不上屏。读屏时读作「候选词注音，已开／已关」。
- **字卡**：长按手写候选里的一个单字（拼音 `u` 拆字、笔画查字出的字也一样），菜单最上面是这个字的字卡：大字；每个读音一行（拼音、注音符号、最多两个例词，读音的顺序和候选栏一样）：字卡是查字用的，列词典里的全部现代读音，包括这个字本身的轻声读音（和 huo、头 tou、着 zhe），排在其他读音后面，候选栏上照旧不标这些轻声；部首、笔画数、拆成的部件和它们的读音、笔顺。然后是 **上屏**（和点这个候选一样）和 **复制**（只把这一个字放进剪贴板，不上屏，框里写好的字不变），再下面是原来的 **删除** / **忘掉学到的** / **屏蔽**。竖屏和悬浮键盘上是一列；横屏是左右两列，部首、笔画等和上屏、复制在右边一列；读音多时读音那一块可以上下滑。字卡里不知道的项不显示（比如没有拆字的字没有「拆字」一行）。部首按康熙部首，左偏旁写成「氵、扌、艹」这样的写法；笔顺按大陆规范笔顺（本项目维护的笔顺表，最初取自 cnchar，按规范校正过），每一笔按具体笔形写出（横折钩 ㇆、竖钩 亅、竖弯钩 乚、横折弯钩 ㇈ 等，按《GB13000.1 字符集汉字折笔规范》；TalkBack 读笔形的名称）；表里没有的字（繁体字和少数生僻字）用 rime-stroke 里笔画数和 Unihan 一致的写法（没有就用第一种），这种只分横、竖、撇、点、折五类（提算横，竖钩算竖，捺算点，各种折都写成 乛）。笔画数和显示的笔顺一致（范 8 画，不是按台湾字形的 9 画）。例词只取词典里有的词。
- 句子会接着光标前的文字来读（比如前面是"高"，写的字更可能读成"山"）。
- 和拼音一样有**性能档位**（各中文输入法共用，在 **通用输入** 里）：中档每写一笔就按整句通顺程度重排，高档在一个字写完（停笔）时再用大模型精挑一次。档位越高，写字当时显示的那句越准。
- 上屏以后会**联想下一个词**（各输入法共用这个开关，在 **通用输入** 里）：点一下联想词就上屏；手写一个字一个字写下去的搭配打过 3 次，也会联想出来；常一次上屏的整段话（在哪个输入法打的都算），写出它的开头也会接着给出剩下的部分（规则和[拼音的联想](pinyin.md#联想下一个词)一样）。长按联想词可以选 **不再联想** 或 **屏蔽**；接着写字、按退格或别的键，联想就消失。按回车上屏时不联想。

识别全部在手机上进行。目前识别模型只用合成的笔迹训练过，单个字的准确率还不高（第一个候选约七成对）；按整句读之后，整句上屏时约九成的字是对的，之后会继续改进。

### 键盘手写

不用换到手写输入法，直接在拼音（全拼、双拼、九键、14 键、18 键）、码表和注音的键盘上写字：在 **通用输入** 的 **在键上划** 里选 **键盘手写**（默认关；和滑行输入、笔画筛选三个里只能选一个）。识别模型在文字包里，还没导入文字包时这一项显示为「键盘手写（需要文字包）」。

- 什么都没打时，手指在字母键上按下后移动超过半个键（任何方向，键很高时上下最多约 5 毫米），就开始写这个字。打字时手指一滚、带一点拖动的点按不到半个键，照常打出字母；刚在键盘上点过键（字母、空格、标点、⌫ 等）半秒内也不起笔，这一下还是打字，所以打完字要写字时稍停一下。写完一个字后点空格、⌫ 不算打字，接着写照常起笔。笔迹画在键上，颜色和粗细跟手写板一样，键照常显示。写字期间（停笔还没到[停笔时间](#手写)）在字母区点一下也算一笔，长按也不弹窗，第二根手指不算；停笔到时这个字写完，笔迹淡出，接着可以写下一个字。
- 写出的字和手写输入法里一样处理：连成一句带下划线显示在框里，候选栏是最后一个字的几种可能；**空格** 上屏整句，**回车** 上屏，**⌫** 先撤最后一笔、书写板上没笔画了再去掉最后一个字，点候选上屏以它结尾的那一句；写好后点一个字母，先上屏写好的句子，再打这个字母。学到的字记在手写里。
- **第一笔是点的字**（主、六、文、立）：先点一下字母键（打出了一个字母），接着在停笔时间内、在这一点附近（两个半键以内）写下一笔，刚才那一点就收回来当作第一笔，打出的字母删掉。只有这个字母是正在打的全部内容时才这样；中间点过别的键、长按过、选过候选，或者点这一下之前半秒内刚点过键（在打字），就不收回，也不删任何字。
- 打着拼音或编码时不写：这时手指的移动还是键原来的点按和滑动。联想候选显示时可以写，一写联想就收掉。
- 选了键盘手写后，还没打字时字母键上下短划打角标没有了（短划会当成一笔；打着拼音或编码时照旧打角标），长按照旧。写完一个字后在停笔时间内马上点字母，也会当成一笔：打字前稍等一下，或者把停笔时间调短。
- 英文、手写输入法本身、快速输入和 Unicode 里不写；密码框、网址和邮箱框里也不写。TalkBack 的触摸浏览开着时不写，手指是在摸索按键。
- 识别模型加载不了时不写，触摸照常是点按，提示只出一次。

## 码表输入法：五笔、仓颉、自然码、二笔、五笔拼音

在 **输入法** 里添加。都用 26 键全键盘，按编码出字：

- 正在打的编码显示在候选栏上方，不进输入框。正在打编码时回车键写「确定」，按它把编码原样上屏。
- 键盘上没有 Shift，那个位置是 **「拼」** 键：按一下打开拼音反查，键变深色，之后打的字母都按全拼找字，编码栏前面写「拼」，候选旁边是它的码表编码；选完还开着，再按一下关掉。切到别的输入法再切回来、改设置都还开着；重启输入法（比如恢复备份、手机重启）后回到关。已经打了几码再按「拼」，这几码转成拼音（编码里有万能键或 `;` 这类符号时不转，「拼」从下一个编码起作用）；反查里再按「拼」，打的拼音转回编码：已经选了前半句的字（比如 nihao 先选了「你」），这几个字上屏，剩下的拼音字母转回编码，`'` 去掉，超过最长编码的字母丢掉；转回的编码不会自动上屏，等你选，拼音字母不学。五笔的 `z`、二笔的 `[` 照旧只反查一个词。
- 码表的编码里有、键盘上又没有的符号键，会出现在 L 的右边：二笔的 `;`，仓颉字根键盘的 `*`。横屏分体时一样在右半边 L 的右边，这一行右半边多一个键，中间空隙让出位置。
- 键上显示字根或键名时，角上写的是字母，不再画下滑符号；下滑照样打出数字和符号（仓颉的 `*` 另有键）。显示全部字根时长按是字根大图，不是符号菜单。
- 编码打满且只有一个字时直接上屏；再按下一个键打不出东西时，也会自动上屏第一个候选（都可以在设置里关掉）。
- 空格上屏第一个候选；打出不存在的编码（空码），下一个键会把它丢掉。
- 编码打错了不用全删：点一下编码那一行，光标停在点的地方，接着打的键插在那里，退格删光标前面的键；也可以在空格键上左右滑动，或用实体键盘的方向键移动光标。光标不在末尾时打的键只插进去，不会自动上屏第一个候选；改完整个编码只有一个字时照样直接上屏。拼音反查时改的是拼音，和拼音输入法一样。
- **显示编码提示**：候选旁边显示这个字还要按哪几个键，方便学编码。
- 一个字一个字打的不会自动成词（以前的"自动造词"去掉了）。名字、术语用拼音反查打两次，或者在用户词库里手动加。
- 你的词（拼音里加的、学成的）和导入的词，码表里也能按码表的规则打出来，排在码表原有的同码字词后面；原本只有一个字词、打满码自动上屏的编码，不收它们，自动上屏照旧。码表里的选择只改码表里的顺序，不改拼音的。
- **调频**（新装时关；从 0.4.x 升级时用过的码表照旧开着）：开着时，码表原有的字词按你的选择排：选一次排到没用过的前面，连着选两次排第一，不看前文；中间选了一次码表原来的第一个（哪怕当时它没排第一），就从头数；重码还按前面已经打的内容排（性能档位越高越准）。关着时码表原有的字词位置不变，适合靠位置盲打的人。五笔、五笔拼音的一、二级简码顺序都不动。码表设置里的 **恢复码表顺序** 清掉调频学到的。恢复一份不带码表设置的旧设置备份时，备份里打过的码表照旧开着调频（手机上关掉的也会打开）。
- 长按码表的候选：**删除** 只对码表以外的词；**固定首位** 只在这个编码下第一，调频关着也有效；**屏蔽** 只管这个编码（菜单里写明"打这串码不再出现"），别的编码、别的输入法照旧，在用户词库"屏蔽的词"页顶的"码表里按码屏蔽的"里恢复。调频关着时，码表原有的字词没有 **忘掉学到的**。按拼音反查（五笔的 `z` 或 拼 键）出的字词长按有 **忘掉学到的** 和 **屏蔽**，屏蔽和在全拼里屏蔽一样（哪里都不再出现，确认框也这样写），没有 **固定首位**。删除、屏蔽、固定当场能撤销；只有旧版自动造的词删掉后不能撤销。**清空学到的** 留下调频的顺序和按码屏蔽；**全部清空** 连同它们和旧版自动造的词一起清掉。
- 拼音反查（「拼」键，或五笔先按 `z`）就是全拼，按全拼的规则学，不改码表的顺序；反查上屏后马上删掉，也和全拼一样不算。
- 上屏后马上删掉的不算用过（码表的字词、联想选的词都一样）；用同样的键重打算改选，换了键当新输入。
- **联想**：上屏后在候选栏给出可能接着打的词（常一次上屏的整段话，打出开头也接着给，见[拼音的联想](pinyin.md#联想下一个词)），点一下上屏；长按联想词可以选 **不再联想**（只是不再跟在这个词后面）或 **屏蔽**（和[拼音的联想](pinyin.md#联想下一个词)一样）；单字和拼音里没有的词只能 **不再联想**，不能屏蔽。接着打编码，联想就消失。
- **滑行输入**（默认关闭，和其他输入法同一个设置：**通用输入** 的 **在键上划** 选 **滑行输入**；选了笔画筛选时它是关的，码表也没有笔画筛选）：不抬手依次划过一个字词的编码键，抬手后这个编码就像敲出来的一样，候选照常给出（五笔划 w-q-i-y 得到 你）。一次划一个编码；正在打编码时再划，先上屏第一个候选。同一条线可能是几个编码，第一个候选后面会跟着另外两个编码里最常用的字词，点它就换成那个编码选上。编码里有非字母键的（二笔的 `;` `'` `,` `.` `/`）划不出这些键，这样的编码要敲。

### 表情候选

打出的字词有对应的表情时，候选里跟着给出至多两个，规则和[拼音的表情候选](pinyin.md#表情候选)一样：跟着第一个候选，排在第三个候选起。五笔 `kwkw` 出「哈哈、吩咐、😃、😄」，五笔拼音 `jqpv` 出「晚安、易安、😴」。编码打满、只有一个字词时它照旧直接上屏，表情改在联想栏最前面给出：二笔 `dazq` 上屏「点赞」后联想第一个是 👍，点它就把刚上屏的「点赞」换成 👍；自然码 `haha` 同样（😃 😄）。接着打别的键，表情和联想一起消失。仓颉的码表只有单字，几乎碰不到表情。开关是 **通用输入** 里的 **表情候选**。

各码表的特殊键：

| 码表 | 特殊键 |
|---|---|
| 五笔（86 版） | `z` 是万能键（代替不会的那一码），也用来**拼音反查**：先按 `z` 再打拼音，候选旁会显示五笔编码。设置里 **按键显示** 可以让键上显示键名（王土大木工…）或 86 版的全部字根；显示全部字根时长按一个键，弹出它的字根大字；键盘高度是紧凑时显示成键名 |
| 二笔 | `[` 开头是拼音反查（键盘上用「拼」键），`*` 是万能键 |
| 仓颉 | `*` 是万能键。默认是字根键盘：字母键上是字根（日月金木水火土…），字母小字在角上，编码栏也显示字根（打 ab 显示"日月"）；设置里可以关掉 **字根键盘** |
| 自然码 | 码表式的自然码：每个字按自然码双拼编码，词由各字双拼的前几码组成，按码表出字、没有整句。想整句打自然码双拼，用"双拼"输入法选自然码方案 |
| 五笔拼音 | 五笔和拼音混打，不用切换 |

每个码表自己的默认值不同（比如五笔默认显示编码提示，二笔、仓颉默认不显示），见[设置逐项说明 · 码表](settings.md#五笔等码表)。

## 快速输入

**长按"符"键**（26 键、14/18 键、九键、手写都一样），或点工具栏上的「快速输入」按钮进入（这个按钮默认不在栏上，要在**工具栏按钮**里勾上），栏上显示"快速输入："。也可以在 **按键 → 按键字符和快捷键** 里把某个键的快捷键设成「快速输入」，滑一下就进。

什么都不打时，候选栏列出**你自己存的条目**，最近用过的在前，最后一个是「＋添加」；还没存过时栏上提示怎么加。点一条就把整段原样上屏（多行的也一样，不做繁体、全角转换）。候选旁边的小字是这一条的**注释**，没写注释的显示关键词。打关键词则只列关键词**开头**对得上的：先是你自己的（不分大小写），再是内置的；注释和目录不参与查找。几条可以用同一个关键词，靠注释区分：比如 `#wz` 存两条，注释「百度」「新浪」，打 `#wz` 时两条都列出来，旁边分别写着百度、新浪，点要的那条。九键打数字按你设的字母找（打 44 能找到 gh），14/18 键按整个键找；手写和注音键盘（注音九键、大千）上临时换成全键盘，退出后回到原来的键盘；中途按语言键换了输入法，就和平时换输入法一样，显示新输入法的键盘，退出后也不换回来。

长按一条候选：「上屏」「复制」；你自己的还有「编辑」「删除」（删了可以在同一个菜单里撤销）。浮动键盘和实体键盘的候选列表长按没有快捷输入的编辑/删除菜单。剪贴板里长按一条，选「存为快速输入」也能存（密码类的不行）。

自己的条目在 **设置 → 词库与短语 → 快速输入** 管理：加、改、删（左右滑也能删，可撤销，撤销后放回原来的位置）、搜索关键词、注释和内容、从 `.mb` 文件导入、导出成 `.mb`（电脑上的 fcitx5 能直接用），还能分别关掉下面三份内置表。

- **关键词**必填，只能是英文字母、数字和符号（键盘上打得出来的 ASCII 字符），不能有空格，最长 30 个；打了中文或空格，框下马上提示，不让存。中文写进注释。
- **注释**可空，一行，最长 30 个字，可以是中文，显示在候选里内容旁边。
- **内容**最长 5000 字（超了点"确定"时提示，不会悄悄截掉；剪贴板里超过 5000 字的一条存不成，会提示）。
- **目录**：每条可以放进一个目录，也可以不放（「未分类」）。页面上方一排目录：「全部」「未分类」、你建的各个目录、「＋目录」（新建）；点一个只看这个目录里的，在某个目录里点 ＋ 新加的条目默认放进这个目录。编辑框里点「目录：…」换目录。长按一个目录可以 **改名** 或 **删除目录**：删目录时里面的条目移到「未分类」，不会删掉。目录只是在这一页上分类管理用的，**不影响打字时的查找和顺序**。
- 关键词（不分大小写）、注释、内容都一样的算重复，不让存；注释不同就是两条。
- **从旧版升级**（0.6.0 以前关键词能输中文，但打字时用不上）：第一次读到旧的条目时自动转换，关键词从第一个中文（或别的非 ASCII 字符）起的部分移到注释：`#wz百度` 变成关键词 `#wz`、注释「百度」。关键词一开头就是中文的（比如 `地址`）转不出关键词：条目照样保留，整个旧关键词放进注释，什么都不打时照样列出、点了照样上屏；页面上方提示有几条，并多一个「待补关键词」目录只列它们，行上写「（没有关键词）」，点开补一个英文关键词就好。
- **导入导出**：导出的 `.mb` 带目录和注释，电脑上的 fcitx5 和旧版幽默都读得懂（关键词显示成 `#wz｜百度`，目录那几行它们跳过）；导入时旧版导出的、电脑上 fcitx5 的 `.mb` 照上面升级的规则转换，带目录的放回同名目录（没有就新建），关键词开头就是中文的照样收进来、放进「待补关键词」，提示里另说几条。导入时重复的和超长的跳过，报跳过了几条。文件里一条也读不出来（比如选错了文件）时直接提示。编辑框里改了东西按返回会先问要不要放弃；转屏、切深色模式时编辑框和打了的字都还在。条目、注释、目录和顺序跟着备份走；恢复 0.6.0 以前的备份时，里面的条目照上面升级的规则转换；注意恢复 0.5.1 以前的备份（里面没有快速输入）会把这里自己加的条目清掉，关掉的自带表也会重新打开，见[从备份恢复](settings.md)。

在密码框里也能用，但不记顺序。开了「借手机」（不记录习惯）时不列你自己的条目，只有内置的。快速输入上屏的不进学习，也不出联想。

内置的三份表：

| 打 | 得到 |
|---|---|
| 英文情绪词，如 `yawn`、`happy`、`cry` | 颜文字，如 (￣□￣)、(๑´ڡ`๑) |
| `:` 加表情名，如 `:smile:`、`:yawning_face:` | 对应的 emoji 😄 🥱 |
| `\` 加 LaTeX 名，如 `\alpha`、`\pounds`、`\rightarrow` | α、£、→ |

空格上屏第一个，退格删到头就退出快速输入。

## Unicode 输入

**长按"123"键**进入 Unicode 输入，栏上显示"Unicode："：

- 打字符的英文名，比如 `smile`、`arrow`、`degree`，会列出名字里有这个词的字符。
- 也可以打十六进制编码，比如 `U+4F60`（你）、`U+00B0`（°）；不带 `U+` 也行（`4F60`，2–6 位，排在按名字找到的字前面），只要里面有数字（`face` 这样全是字母的仍按名字找）。18 键上 XC、SD、WE 打出的是前一个字母，打不出 c、d、e，带这几个字母的编码要用实体键盘。

## 语音输入

导入语音包（**设置 → 资源包**，见[导入资源包](getting-started.md#导入资源包)）后能离线说话打字，识别在手机上完成，录音不保存、不上传。目前只支持**普通话和英语**，中间夹英文也行。带口音的普通话也能认：模型专门用北方各地口音的语音（主要是合成的）训练过，各地官话口音整体比原版认得准，标准普通话基本不变。粤语、吴语等方言暂不支持。

**两种说法**：

1. **按住空格说话**（默认）：长按空格，先显示"准备中…"，等麦克风真正开始收音时变成"正在听…"并轻震一下（跟随"按键时振动"的设置和强度），这时开始说（2 秒都收不到声音时显示"麦克风没有声音"，多半是系统的麦克风开关关了或别的应用在录音；一有声音就变回"正在听…"），**松开手指上屏**；说的时候**手指上滑**再松开就取消。按住时换了输入框，已经听到的上屏到原来那个输入框，和点麦克风说话一样；手指已经上滑到取消区时换框，什么都不上屏。按住时收起键盘、转屏或键盘重建（比如换了主题），已经听到的也立刻上屏；在取消区则不上屏。
2. **点麦克风说话**：点工具栏上的**麦克风**，键盘上盖一层（工具栏还露在上面），显示跳动的声音条和状态，同样先"准备中…"、开始收音时"正在听…"并轻震，然后说话，不用一直按着。说完**再点一下麦克风**或**点这一层的任意地方**结束，剩下的上屏；这一层上没有取消按钮，不想要说过的内容就结束后自己删。这一层是毛玻璃：下面的键模糊成大致的形状和颜色，字看得清（长按空格的卡片也一样）。要发送：先点这一层或麦克风结束，等这句上屏、这一层收起后，再按键盘上的回车。60 秒没听到说话会自动结束。收起键盘也会结束：还没识别完的部分识别完后照样上屏到这个输入框（识别完以前就点了别的输入框，已经听到的上屏到原来那个）。说着的时候换了输入框，马上结束，已经听到的上屏到原来那个输入框。悬浮键盘拖动、缩小后，这一层跟着键盘走；说着时拖悬浮键盘的把手不会结束。

识别时会做的事：

- 边说边识别：说着的内容直接以带下划线的待定文字出现在输入框里，并且只上屏到你开始说话时的那个输入框；取消时待定文字会撤掉。按住空格说话时，松开手指才真正上屏。点麦克风说话时，前面已经定下来的部分（说完一段、后面又接着说了，并且语音整理不会再改的）边说边真正上屏，只有最后还会变的一段是待定文字；句末句号只在结束时加。说着的时候应用自己把输入框清空或发了出去，已经说过的不会再上屏一遍，接着说的照常进框；点了输入框别的位置，待定文字撤掉，接着说的从新位置开始。15 秒还没识别完就放弃：把最后听到的上屏，提示"最后几个字可能没识别完"；什么都没听到时提示"没有听清"。输入框里正有一个英文词没打完时，只在语音卡片或那一层上显示，结束时一起上屏（密码框里不能用语音，见下）。
- **语音整理**（总是开着，没有开关）：边说边去掉"嗯""那个"之类的口头禅、重复和说错改口的部分，加上标点，把数字写成习惯的样子；落后正在说的位置大约 16 个字的部分就定下来不再改。整理模型加载失败或出错时照识别出来的原样上屏（数字也保持汉字），语音卡片或那一层上提示一次「语音整理没有生效」。
- **句末句号**（**按键 → 语音句末句号**）：默认按输入框处理：聊天框里不加句号（问号、感叹号保留），其他地方照说的保留。也可以改成"照说的保留"或"都不加"。搜索框和单行输入框里句末不加任何标点，选哪一项都一样。
- 数字按习惯写，由语音整理按上下文判断哪些是数字、是哪一种：二零零二年 → 2002年，百分之五十七 → 57%，十点十五 → 10:15，八点五分 → 8:05，八点半 → 8点半，七点整 → 7点整，八点一刻 → 8点一刻，三十三万 → 33万，十二万三千 → 12.3万（万、亿后面还有数时写成最多两位小数，两位不够精确就写全：1234567），电话、验证码逐位写（幺三八 → 138），V一点二三 → V1.23；"一个""十分有趣""第一"这类不是数字的不改。整理只会去掉口头禅，不会删掉数字里的字（「一点一点」照说的写）；成语里的数字不改（十全十美、一心一意、七上八下）。
  - 已知问题：口语的钱数（「十二块五」）有时保持汉字，下次重训语音整理模型时改进。
- 用拼音引擎的语言模型从几个识别结果里挑最通顺的；基础词库里近几年的新词会优先听出；你的词更优先：手动加的最优先，打两次学成的其次。导入的词成为你的词以前不算，打字时的选择也不改语音。
- 名字老被认错：用拼音把整个名字打两次（成了你的词），或者在用户词库里手动加，语音就往它上面听。
- 语音打出来的字不学：不算用过，不成词，只当后面打字的前文。改错字时删掉一段、用拼音或手写重打，按拼音、手写的规则学。
- 你屏蔽、删除的词，语音里也一起生效。
- 只有咳嗽、清嗓子、喘气、"嗯"之类的声音不会打出东西，显示"没有听清"。
- 安静的屋里、或者麦克风没有声音时，不会凭空打出字。放大后的底噪常被识别成「I'm sorry.」这类很短的英文，这样的结果只有在声音明显比屋里底噪大、而且听得出是人声时才上屏；有汉字的、或者较长的结果照常上屏。代价是很小声地说英文短句（比如"OK""Thank you"，没有中文、十来个字母以内）时，基本都会显示"没有听清"：屋里有风扇、空调这样的底噪时更明显。正常音量说，哪怕只说一个"OK"，照常上屏；中文不受影响。
- 语音整理不改英文单词里的字母（以前会把 sorry 当成口吃改成 sory）。
- **说到最后一个字就松开也不丢字**：松开手指后还会再录 0.3 秒（从松开的那一刻算起），说出口的最后一个字录全了再识别。上滑取消时不续录，马上停。续录时又按了一下，就马上停，上一句照常上屏，这次按下不算。点麦克风说话也一样：点了结束后还会续录 0.3 秒，这时再点麦克风或那一层就马上停。
- **小声说也听得出**：声音小时会自动放大，最多放大 10 倍（+20 dB），正常说话基本不变，也不会放大到破音。代价是旁边有人在远处说话时，说话期间也更容易被听进去。

第一次使用时会请求**麦克风权限**（输入法本身不能弹权限框，所以会短暂打开一个页面来请求）。
**密码框里不能用语音输入。**

不想用按住空格说话，可以在 **按键 → 空格键长按行为** 里改成别的。
