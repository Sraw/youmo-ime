# 词库与短语

设置首页的 **词语** 分组里有两项：**自定义短语** 和 **词库**。

## 词库是怎么组成的

拼音（全拼、双拼、九键）一共用三层词：

| 词库 | 内容 | 能改吗 |
|---|---|---|
| **用户词库** | 你添加的词、输入法从你这里学到的词、你屏蔽的词 | 能，总是排在最前 |
| **新词库** | 近几年出现的新词（网络用语、新事物、新名字），人工挑选 | 只读，随应用更新 |
| **基础词库** | 常用词和词频 | 只读，随应用更新 |

另外还有你自己导入的词库（见下面"导入词库"）。新词随新版本发布，应用不联网，所以要拿到新词就要更新应用。

码表（五笔等）用自己的码表，但你在用户词库里的词它们也能按各自的规则打出来。英文有自己的词库，在英文的设置页里。

## 用户词库

**词库 → 用户词库**，分三个列表，各显示词数：

- **手动添加的词**：你在这里加的。
- **自动学到的词**：你打字时输入法记住的词。
- **屏蔽的词**：你不想再看到的词。

每个列表可以按"词或拼音"搜索。点一个词会弹出操作：添加的词可以**编辑**或**删除**，学到的词可以**忘掉**，屏蔽的词可以**恢复显示**；长按可以多选后一起删除。

**添加词**：右下角 **+**，填"词"和"拼音"。拼音用空格分开，比如 `you mo`；留空会自动填常用读音（多音字请自己填）。
添加的词立刻生效，排在最前。

**屏蔽词**：在"屏蔽的词"里加，或者在键盘上长按候选选 **不再显示这个词**。屏蔽的词不会出现在候选、联想和语音结果里。

**导入词表**（用户词库页下面"导入与导出"里的一行）：文本文件，一行一个词，可以带拼音（`幽默 you'mo`），也可以只写词。搜狗、QQ 等输入法导出的词库文本也能读。导入的词进"手动添加的词"；`!` 开头的词（导出的文件里屏蔽的词）回到"屏蔽的词"。

**导出**（也在"导入与导出"里）：把整个用户词库（添加的、学到的、屏蔽的）存成一个文本文件，可以在别的手机上导入。

## 导入词库

**词库 → 导入词库**，支持：

- `.txt`：一行一个词，可带拼音；
- `.dict`：Fcitx 5 的词库文件；
- `.scel`：搜狗细胞词库。

选文件后会问 **并入哪个词库？**

| 选项 | 适合 | 效果 |
|---|---|---|
| **基础** | 大而杂的词库（比如几十万词的专业词库） | 和基础词库同等对待，不会挤掉常用词 |
| **新** | 你确定都是新词的小清单 | 和新词库同等对待 |
| **用户** | 几千个以内你常用的词 | 当成你自己加的词，排在最前 |

拿不准就选"基础"。导入的词库会列在词库页对应的分组里，点它可以暂时停用、换到别的词库或删除。文件太大、损坏或读不出词时会提示原因。

## 自定义短语

**自定义短语**：打一个输入码，得到一段固定文字。比如打 `dz` 得到你的地址，打 `yx` 得到邮箱。

- 右下角 **+** 添加：
  - **输入码**：打什么，比如 `dz`；
  - **候选位置**：排在第几个，`1` 就是第一个；
  - **短语**：得到什么，可以有多行。
- 点一条可以编辑或删除。菜单里有 **导入**、**导出**。
- 在全拼和双拼里有效，按你打的字母匹配（九键打的是数字，用不了）。在键盘上长按候选选 **以自定义词组的方式置顶**，也会在这里加一条。

**日期和时间**：短语以 `#` 开头时，里面的变量会换成当前的日期时间。比如短语写成 `#$year年$month月$day日 星期$weekday_cn`，打出来是"2026年9月7日 星期一"那样。

| 变量 | 含义 | 例子 |
|---|---|---|
| `$year` / `$year_yy` | 年 / 两位年 | 2026 / 26 |
| `$month` / `$month_mm` | 月 / 两位月 | 9 / 09 |
| `$day` / `$day_dd` | 日 / 两位日 | 7 / 07 |
| `$weekday` | 星期（数字，周日是 0） | 1 |
| `$fullhour` / `$halfhour` | 24 小时制 / 12 小时制的时 | 15 / 03 |
| `$ampm` / `$ampm_cn` | 上午还是下午 | PM / 下午 |
| `$minute` / `$second` | 分 / 秒 | 07 / 30 |
| `$year_cn` / `$year_yy_cn` | 中文年 | 二〇二六 / 二六 |
| `$month_cn` / `$day_cn` | 中文月、日 | 九 / 七 |
| `$weekday_cn` | 中文星期 | 一 |
| `$fullhour_cn` / `$halfhour_cn` | 中文时 | 十五 / 三 |
| `$minute_cn` / `$second_cn` | 中文分、秒 | 零七 / 三十 |

## 想要什么样的效果，用哪个功能

| 想要 | 用 |
|---|---|
| 某个词总是打不出来 | 用户词库里添加它（写上拼音） |
| 某个词老是冒出来很烦 | 长按它选"不再显示这个词" |
| 打某个拼音时固定某个词排第一 | 长按它选"以自定义词组的方式置顶" |
| 输入法学错了某个词的位置 | 长按它选"忘记词汇" |
| 打几个字母出一大段固定文字 | 自定义短语 |
| 一大批专业词汇 | 导入词库，选"基础" |
| 换手机 | 用户词库"导出"，或者 **高级 → 备份全部** |
