# 词库与短语

设置首页的 **词库与短语** 一页里管你的词、导入的词库和自定义短语。页面最上面一句话说明候选怎么排："用户词库的词排得靠前，选得越多越靠前；还没选过的，可能排在很常用的同音词后面。拼音和码表都用这些词，英文词库在英文的设置里。"

## 词库是怎么组成的

拼音（全拼、双拼、九键）用两个词库：

| 词库 | 内容 | 能改吗 |
|---|---|---|
| **用户词库** | 你的词（你加的、打两次学成的）、从别的输入法导入的词、你固定和屏蔽的词，还有学到的顺序 | 能：添加、删除、固定、屏蔽、清理、备份 |
| **基础词库** | 内置的常用词和近几年的新词（网络用语、新事物、新名字，人工挑选），加上你并入基础词库的大词库 | 内置部分只读，随应用更新；并入的可以停用、删除 |

候选怎么按你的习惯排，见[拼音输入 · 输入法怎样学你的词](pinyin.md#输入法怎样学你的词)。简单说：选一次排到前面，在同一个地方连着选两次排第一；你的词在第一页；导入的词排在词库自带的同拼音词后面，你用过才往前。新词随新版本发布，应用不联网，所以要拿到新词就要更新应用。

码表（五笔等）用自己的码表，你的词和导入的词它们也能按各自的规则打出来（仓颉没有组词规则，不行），排在码表自己的同码词后面。码表里原本只有一个字词、打满码自动上屏的编码，不会因此多出候选，自动上屏照旧；这样的词在用户词库里标"五笔：与 X 同码"（前面是码表的名字），在拼音里照样能打。英文有自己的词库，用户词库页里单列一页，英文的设置页里也有。

## 用户词库

**词库与短语 → 用户词库**。

页顶两个开关：

| 开关 | 意思 |
|---|---|
| **用我的输入习惯**（开） | 见下面[学习的开关和清除](#学习的开关和清除)。和工具栏 **⋯** 里那一项是同一个开关 |
| **自动备份**（开） | 见下面[备份](#备份) |

下面"词"一组分几页，"文件"一组是 **学习备份** 和 **导出**（见[备份](#备份)）：

- **手动添加的词**：你手动加的。码表不能打的词（见上面的"与 X 同码"）在这里和自动学到的词里标着"五笔：与 X 同码"。
- **自动学到的词**：打两次学成的。
- **屏蔽的词**：你屏蔽的词，一步恢复。页顶一行"不再联想的搭配：N 个 ›"，点它进下一页；有码表里按码屏蔽的词时，下面再有一行"码表里按码屏蔽的：N 个 ›"，那一页里点一个就恢复显示。
- **不再联想的搭配**：长按联想选了"不再联想"的（前一个词 → 联想词），点一下再确认 **恢复联想**。
- **固定的词**：你固定在某串键下第一的，点一下再确认就取消（多问一句，免得手快点错）。
- **英文词库**：英文学到的词，单列一页；和 **输入法 → 英文 → 英文词库** 是同一页。
- **清空学到的**：见下面[清空学到的](#清空学到的)。

从别的输入法导入、还没成为你的词的，不在这里，在 **词库与短语 → 导入的词**：按导入的批次列出，每批写着还有几个词不是你的，可以整批撤掉。英文的词在上面的 **英文词库** 一页，也在 **输入法 → 英文 → 英文词库**（见[英文](other-input-methods.md#英文)）。

每页能搜索（按词或拼音）。记着最近一次用的日子的页（手动添加的词、自动学到的词）右上角菜单里能勾 **最近学到的在前**、**只看很久没用的**（打字的日子里两个月以上没用过的；不知道上次哪天用的词不算，也不会被一起选中；一个也没有时，数目那行写「没有很久没用的 · 共 N 个」）；这些页的词显示用过的次数和最近一次用的日子（只到哪一天）。点一个词就能删除。长按选几个（或全选）一起删掉：删之前显示有多少个，删后底部提示里点 **撤销** 就回来；英文词库里删了没有撤销。在加词、改词的框里打字不会被学习。

**添加词**：右下角 **+**，填"词"和"拼音"。拼音用空格分开，比如 `you mo`；留空会自动填常用读音（多音字请自己填）。
加了就是你的词，立刻就能打出来，在完整拼音和简拼下一般在第一页。没有别的同拼音的词时，它排第一，打整句时也照用；有同拼音的词时，选它两次它就第一，要一直第一可以固定。超过 4 个字的词只能这样加。

**删除**：删掉的你的词就没了，学到的一起忘掉。之后要是又打出它两次，它重新成为你的词。

**屏蔽词**：在"屏蔽的词"里加，或者在键盘上长按候选选 **屏蔽**。屏蔽的词不会出现在候选、联想、手写和语音结果里；从拼音这边屏蔽，码表里原有的字词不受影响。

## 学习的开关和清除


### 借手机：不用我的输入习惯

工具栏 **⋯** 里点 **不用我的输入习惯**（用户词库页顶的开关也是它）：

- 键盘像刚装好一样：不学，也不用你的任何记录（学到的顺序、你的词、导入的词、固定、自定义短语、学到的联想、英文补全、表情和符号面板的"最近"）。只有屏蔽照常。
- 并入基础词库、开着的词库照样用（那是设置，不是习惯），拼音和码表都一样；上面说的"导入的词"是并入用户词库的那些。
- 在 **⋯** 里关掉的那一刻键盘上方会提示 2 秒"已不用我的输入习惯，在 ⋯ 里恢复"（点一下就消失），之后键盘上不再显示什么。
- 它不会自己恢复：拿回手机后，在 **⋯** 里点 **恢复我的输入习惯**，一切照旧。
- 关着的日子不算打字日，学到的不会因此过期。

### 这里不学

密码框、浏览器无痕模式等应用要求不记录的输入框里，输入法什么都不学，排序照旧。键盘上不另外提示。

有的网页输入框（App 里的网页）带不上"不记录"的要求，这时照常学习：要么事先用"不用我的输入习惯"，要么事后清掉。

### 清掉最近一段时间

工具栏 **⋯** 里点 **清掉最近**，选 **最近 10 分钟**、**最近 1 小时** 或 **今天**，确认框里点 **清掉**：这段时间里学到的一切都忘掉，就像这段时间没打过字；之前学到的不受影响。

- 例如：3 天前选了 5 次、这 1 小时又选了 1 次的词，回到 5 次；这段时间里换上的第一个，换回原来的；这段时间里成的词，不再是你的词。
- 这段时间里你主动做的不撤：固定、屏蔽、不再联想、删除、导入、手动加词、英文里不再自动改的词；手动另存的备份文件也不动。
- 这段时间里存的自动备份一并作废，马上重存一份，以后从自动备份恢复也带不回清掉的。清掉以后不能再"退回恢复前"。

### 清空学到的

用户词库页里的 **清空学到的**，确认框里逐项写着清什么、留什么：

| 清掉 | 留下 |
|---|---|
| 各处学到的顺序、改选和使用次数，只上屏过一次的记录 | 手动加的词、固定、屏蔽、不再联想、英文里不再自动改的词 |
| 前后搭配和学到的联想 | 你的词（次数清零，仍是你的词；英文学到的词也一样） |
| 英文的次数和排序 | 导入的词（回到没用过的样子） |
| 表情和符号面板的"最近" | 码表调频学到的顺序（到码表设置里 **恢复码表顺序**） |

- 勾上默认不勾的 **全部清空（回到刚装好）**（下面写着"屏蔽的 N 个词会重新出现"），就回到刚装好：右边留下的也都清掉，屏蔽的词会重新出现；勾上后确认框改为列出这些，留下的只有自定义短语。
- 自定义短语不在这里清，到"自定义短语"里删。
- 这次安装存的自动备份、恢复前另存的那份一并删掉；自动备份开着时，马上存一份清空后的。以前装的、从别处拷来的备份不动，恢复它们会带回清掉的。清空以后不能再"退回恢复前"。
- 升级前旧版本的学习文件也一起删掉，装回旧版也看不到了。

## 备份

### 自动备份

- 装好后第一个打字日存第一份，以后每 7 个打字日一份；只留这次安装存的最近 2 份。不含剪贴板。
- 存在输入法自己的目录里，别的应用拿不到。**卸载就没了**：卸载会丢掉学到的一切，除非你另存过一份。卸载那一刻输入法提醒不了。
- 用户词库里的 **学习备份** 一行写着「从备份恢复，或另存一份」，点进去列出备份：这次安装的，和以前装的、从别的手机拷来的，都能手动删；删之前会先问一句，点取消就不删。
- **另存一份到看得见的文件夹**：自己点，存到你选的位置。另存的那份，拿到这台手机的人也能拷走，另存时会提示。存成的文件叫 `youmo-learning-日期.fxlb`。
- 装好后第一次打开，引导页里有一行"以前用过？从备份恢复"，点了就去选那个文件。

### 从备份恢复

从自己的备份恢复（自动备份、另存的、用户词库导出的、**备份与恢复 → 备份全部** 的 zip 里的那份、旧版的导出），学习部分是**合并**，不是覆盖：

- 每个词在每串键下每天的次数，两边取较大的。同一份导两次，结果不变。
- 固定、屏蔽、各前文的第一个，两边不一样时以手机上现在的为准，手机上没有的照收。手动加的词、屏蔽、不再联想、英文里不再自动改的词、码表里按码屏蔽的两边合在一起：备份里有、手机上后来取消了的，恢复后会回来。
- 恢复前，确认框写着这份备份的来源和日期；输入法先自动存一份手机上现在的。恢复错了可以在 **学习备份** 页里点 **退回恢复前**：整个换回那一份，恢复以后学到的、加的、删的、固定、屏蔽都回到恢复前。恢复好了底部提示「已恢复」，退回后提示「已退回恢复前」。选的文件不是本输入法的备份（或大于 64 MB）时不读它，直接提示「不是本输入法的备份」。清空学到的、清掉最近以后，就不能再退回。
- 备份里带着导入的词和它们来自哪次导入，恢复后照样能整批撤掉。两边都有的同一次导入（同一个文件、同一天导入、词数一样）合成一批；同一个词在两批里，算手机上那批的。恢复、全部清空、退回恢复前以后，之前撤掉的导入点 **撤销** 都放不回（会提示没能撤销），这些操作去掉的导入也一样。

**导出**（用户词库页里）：把用户词库的全部（你的词、导入的词、固定、屏蔽、学到的顺序）存成一个 `youmo-words-日期.fxlb` 文件，和学习备份页里"另存一份"存的是同一种文件。在别的手机上从 **词库与短语 → 导入词库** 选它：不问并入哪个词库，确认框写着来源和日期，确定后按上面的规则合并（在学习备份页的 **从备份恢复** 里选它也一样）。以前版本导出的文本文件（第一行是 `# youmo-words 1` 或更早的表头）照样能导回，并入用户词库。导出前会提示：这个文件用这台手机的人都能拷走，里面有你常打的字。现在不再导出纯文本词表，所以没法直接带到别的输入法。

## 导入词库

**词库与短语 → 导入词库**，支持：

- `.txt`：一行一个词，带拼音，词和拼音谁在前都行（`幽默 you'mo`）；Rime 的 `.dict.yaml`、Fcitx 5 的文本词库（比如雾凇拼音的 `frost_dict_for_fcitx5.txt`）、搜狗和 QQ 导出的词库文本也能读。拼音可以用 `'` 或空格分开，也可以连写（`nihao`，只要只有一种分法）。只写词不写拼音的行只有并入**用户词库**才读；
- `.dict`：Fcitx 5 的词库文件；
- `.scel`：搜狗细胞词库。

搜狗、百度的 `.bin` 备份暂时读不了，请先在那边导出成 txt。

选文件后，如果基础词库里已经有同名的词库，先问"基础词库里已有名为「X」的词库。改为并入用户词库吗？"：点 **并入用户词库** 就照下面读文件、并入用户词库，取消就不导入（要换掉基础词库里那个，先在词库页删掉它）。

然后输入法把整个文件读一遍，认出它的格式：编码（UTF-8、UTF-16 或 GBK）、哪一列是词、哪一列是拼音、拼音怎么写、第三列的数字是概率、词频还是对数概率（写成百分数的，如 Rime 词库常见的 `5%`，照常读进来，只是不算词频）。认出来的写在下一步的确认框标题下面，比如"词库文本 · 拼音用 ' 分开 · 第三列是概率 · 1914461 个词"。这里的词数只算带拼音的词；有的行只写了词、没有拼音，另写一项"N 个词没有拼音（只能并入用户词库）"。读的时候有进度条（"正在分析格式… 45%"），可以取消；上百万词的大文件要读十几秒到半分钟。

拿不准的文件不并入基础词库，提示 **格式不支持** 和原因，一个词也不进词库。编码认不出、二进制文件、一行词和拼音都没有的，读完就提示，哪个词库都不收；别的仍会问并入哪个词库，选"基础词库"才提示，选"用户词库"就像以前一样逐行导入、读不懂的行跳过：

| 提示 | 原因 |
|---|---|
| 文件不是 UTF-8 或 GBK 文本 | 编码认不出来 |
| 这不是文本文件 | 文件里有二进制内容 |
| 里面没有一行是词和拼音 | 空文件，或者没有一行认得出词 |
| 文件里混有不同格式的行 | 比如一部分行词在前、一部分拼音在前 |
| 只有声母，无法确定读音 | 拼音只写了声母（`nh 你好`） |
| 太多行读不出词和拼音 | 超过 2% 的行读不懂（少于 2% 的照常导入，确认框里写着几行读不懂） |
| 第三列的数字不是同一种 | 有的像概率、有的像词频 |
| 词太多，超过输入法能放下的 | 超过 400 万词（开着的基础词库加在一起算；打开一个停用的词库会超过时，也不让打开） |
| 字和读音大多对不上（读音不是普通话拼音，或者文件编码不对） | 只查按 GBK 读的文件：Big5 等编码被当成 GBK 读了，用 UTF-8 存一份再导入（UTF-8 的文件不因为字和读音对不上被拒绝） |
| 有些行没有拼音…… | 超过 2% 的行只写了词；只写词的词库只能并入用户词库 |

接着会问 **并入哪个词库？**

| 选项 | 适合 | 效果 |
|---|---|---|
| **基础词库（推荐）** | 大而杂的词库，比如几十万词的专业词库、上百万词的雾凇拼音 | 词能打出来，按文件里的词频在这些词之间排先后，不会挤掉常用词；可以整个停用或删除 |
| **用户词库** | 从别的输入法带过来的、你常用的词 | 成为**导入的词**：完整拼音和简拼下都打得出，排在词库自带的同拼音词后面；文件里带的词频只决定导入的词之间的先后。你在这台手机上用过它，它就往前排；上屏两次，它就是你的词。在那以前，整句、语音和联想都不用它，所以导再多也不会让整句和语音变差。文件里本来就是词库词或你的词的，照旧 |

拿不准就选"基础词库"。用户词库里导入的词一共最多 10 万个：这次的词加上以前导入、还留着的词超过 10 万，选用户词库就不导入：单这个文件就超过 10 万词时提示"这个词库太大，请并入基础词库"，加上以前导入的才超过时提示"用户词库里导入的词已近上限，放不下这些词；请并入基础词库，或先删掉以前导入的词"（导入的词放在内存里，太多会拖慢键盘）。按文件里的词数算，不管其中多少词用户词库里已经有；只有自己导出的词库不算，再导入从不因此被拒。格式不支持、只能并入用户词库的文件也这样算，按它非空、非注释的行数。以前版本导出的文本文件、含 `!` 开头的行（屏蔽的词）的文件默认选好"用户词库"；扩展名不是 `.txt`、`.dict`、`.scel`（或 Rime 的 `.dict.yaml`）的文本文件和名字以 `.` 开头的文件，基础词库收不了，只给"用户词库"一项。自己的导出和备份按[从备份恢复](#从备份恢复)合并。10 万以内的词并入用户词库不会提示改放：导入的词不进整句和语音。导入完成会告诉你导入、添加、屏蔽了几个词，几行没读懂。

并入基础词库的词库会列在词库页"基础词库"一节里（内置词库下面），写着词数，点它可以暂时停用或删除。导入、停用、启用、删除以后，输入法在后台把开着的词库合成一个文件（雾凇拼音这么大的约要一分钟），合好以后键盘自动重新载入；这期间照常打字，只是还没有新导入的词（停用、删除的词也还在）。导入时对话框显示进度（正在保存词库、正在整理词条、正在和其他词库合并、正在写入），任何时候点 **取消** 就不导入：原来的词库照旧，临时文件删掉；导入失败也一样，不留半个词库。停用、启用、删除以后，行的状态马上变，"基础词库"一节显示"正在更新 N%"，合好以后词数才更新。没合成（比如手机空间不够）会提示"词库没能更新"，打字仍用原来的词库；重新打开词库页会再试。文件太大、损坏或读不出词时会提示原因。

从 0.3.1 升级：以前导入的词库照样在，第一次启动时在后台合成一次：键盘的空闲栏显示"正在升级词库格式 N%"和一条细进度线，词库页这些词库的行上也写着进度；合好以后提示"词库格式已升级"，没合成提示"词库格式升级失败"。合好之前打不出这些词，键盘不受影响（0.3.1 导入雾凇拼音这样的大词库后键盘会崩，升级后就好了）。合的时候手机没空间了，打开设置里的词库页再合。降回 0.3.1 前先停用大词库，否则 0.3.1 的键盘会崩。备份不带合成的文件，恢复以后会重新合。

**撤掉一次导入**：**词库与短语 → 导入的词** 按时间倒序列出每次导入（文件名、导入的日子、还有几个词不是你的）；词已经全成了你的词（或都删了）的那次导入不再列出。点一次导入 → **撤掉这批**，确认后这次导入里还不是你的词都删掉；页底提示条上点 **撤销** 能放回（放不回时会提示，比如这期间清空过学到的）。已经成了你的词的留下。撤掉以后再导入同一个文件，撤掉的词照样导得进来。

升级前从用户词库导入的词，分不出是导入的还是你加的，都算你手动加的词；不想要可以在用户词库里批量删。以前的版本导入时还有一个"新"的选项；那样导入的词库，更新后都并到基础词库里，词照样能打。

## 自定义短语

**词库与短语 → 自定义短语**：打一个输入码，得到一段固定文字。比如打 `dz` 得到你的地址，打 `yx` 得到邮箱。手机号、邮箱这些输入法不学的内容，可以靠它打。

- 右下角 **+** 添加：
  - **输入码**：打什么，比如 `dz`；
  - **候选位置**：排在第几个，`1` 就是第一个；
  - **短语**：得到什么，可以有多行。
- 点一条可以编辑或删除。菜单里有 **导入**、**导出**。
- 在全拼和双拼里有效，按你打的字母匹配（九键打的是数字，用不了）。
- 短语不参与学习：只在设定的输入码下出现，不会被学习挪动，也不挪动别的候选。短语的字和某个候选一样时，同样的字只出现一次：那个候选本来就排在短语前面，就留在原处，照常学习；否则由短语代替它。清空学到的不清它；"不用我的输入习惯"时不出现。

**自带的日期时间**：不用自己加。全拼里打 `rq` 出今天的日期（2026年10月17日、2026-10-17、二〇二六年十月十七日），`sj` 出现在的时间（09:05、09时05分），`xq` 出星期几（星期六、周六），都排在第一个候选后面，所以 `rq` 加空格还是"日期"。不想要哪一条，在键盘上长按它选 **从自定义词组中删除**，它在这里变成一条关闭的短语，想要回来就打开它。每个中文输入法（全拼、双拼、九键、码表）打出"日期""时间""星期"这几个词本身时，也在它后面（第三个候选起，和[表情](pinyin.md#表情候选)一样）给出这几条：双拼 `riqi`、九键 `7474`、五笔 `jfuj`（时间）都行；码表里编码只有这一个词、它自己上屏了，这几条出在联想最前面，点了就把刚上屏的词换掉。删掉的那条在哪里都不出。一条都不想要，在 **通用输入** 里关掉 **自带的日期时间**，你自己加的短语照常；再打开就回来（单独删掉的那条仍然是关闭的）。你在这一页给 `rq`、`sj`、`xq` 加了短语，自带的那几条就不出现了。

**日期和时间**：短语以 `#` 开头时，里面的变量会换成当前的日期时间。比如短语写成 `#$year年$month月$day日 星期$weekday_cn`，打出来是"2026年9月7日 星期一"那样。

| 变量 | 含义 | 例子 |
|---|---|---|
| `$year` / `$year_yy` | 年 / 两位年 | 2026 / 26 |
| `$month` / `$month_mm` | 月 / 两位月 | 9 / 09 |
| `$day` / `$day_dd` | 日 / 两位日 | 7 / 07 |
| `$weekday` | 星期（数字，周日是 0） | 1 |
| `$fullhour` / `$halfhour` | 24 小时制 / 12 小时制的时 | 15 / 03 |
| `$ampm` / `$ampm_cn` | 上午还是下午 | PM / 下午 |
| `$minute` / `$second` | 分 / 秒 | 07 / 30 |
| `$year_cn` / `$year_yy_cn` | 中文年 | 二〇二六 / 二六 |
| `$month_cn` / `$day_cn` | 中文月、日 | 九 / 七 |
| `$weekday_cn` | 中文星期 | 一 |
| `$fullhour_cn` / `$halfhour_cn` | 中文时 | 十五 / 三 |
| `$minute_cn` / `$second_cn` | 中文分、秒 | 零七 / 三十 |

## 想要什么样的效果，用哪个功能

| 想要 | 用 |
|---|---|
| 某个词总是打不出来 | 用户词库里添加它（写上拼音） |
| 某个词老是冒出来很烦 | 长按它选 **屏蔽** |
| 某个联想老是冒出来 | 长按它选 **不再联想** |
| 打某串键时某个词总排第一 | 长按它选 **固定首位** |
| 某个词排第一，但我要的是另一个 | 在这个前文后面连着选两次要的那个；急着换就长按现在的第一个选 **忘掉学到的**，或固定要的那个 |
| 学错了一个词 | 长按它选 **删除**（你的词、导入的词）或 **忘掉学到的**（词库自带的词） |
| 不想让刚才打的被学进去 | 工具栏 **⋯ → 清掉最近** |
| 借手机给别人 | 工具栏 **⋯ → 不用我的输入习惯**，拿回来再恢复 |
| 学到的全不要了 | 用户词库里 **清空学到的** |
| 打几个字母出一大段固定文字 | 自定义短语 |
| 一大批专业词汇 | 导入词库，选"基础词库" |
| 换手机 | 用户词库里另存一份备份，在新手机上恢复；或者 **备份与恢复 → 备份全部** |
