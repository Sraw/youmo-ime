# 词库与短语

设置首页的 **词库与短语** 一页里管你的词、导入的词库和自定义短语。页面最上面一句话说明候选怎么排。

## 词库是怎么组成的

拼音（全拼、双拼、九键）用两个词库：

| 词库 | 内容 | 能改吗 |
|---|---|---|
| **用户词库** | 你添加的词、输入法从你这里学到的词、你屏蔽的词 | 能：添加、编辑、删除、导出 |
| **基础词库** | 内置的常用词和近几年的新词（网络用语、新事物、新名字，人工挑选），加上你导入的词库 | 内置部分只读，随应用更新；导入的可以停用、删除 |

用户词库的词排得靠前，选得越多越靠前；还没选过的，可能排在很常用的同音词后面；基础词库的词按常用程度和前后文排。新词随新版本发布，应用不联网，所以要拿到新词就要更新应用。

码表（五笔等）用自己的码表，但你在用户词库里的词和你导入的词库的词，它们也能按各自的规则打出来（仓颉没有组词规则，不行），排在码表自己的词后面。导入的词库很大时，有些原来只有一个字词的编码会多出候选，打满码后不再自动上屏。英文有自己的词库，在英文的设置页里。

## 用户词库

**词库与短语 → 用户词库**，分三个列表，各显示词数：

- **手动添加的词**：你在这里加的。
- **自动学到的词**：你打字时输入法记住的词。
- **屏蔽的词**：你不想再看到的词。

每个列表可以按"词或拼音"搜索。点一个词会弹出操作：添加的词可以**编辑**或**删除**，学到的词可以**忘掉**，屏蔽的词可以**恢复显示**；长按可以多选后一起删除。在加词、改词的框里打字不会被学习，删掉一个词以后不会留下打它时的记忆。

**添加词**：右下角 **+**，填"词"和"拼音"。拼音用空格分开，比如 `you mo`；留空会自动填常用读音（多音字请自己填）。
添加的词立刻就能打出来，排得靠前；同音的很常用的词可能还排在它前面，选它一次它就往前排，选得越多越靠前。

**屏蔽词**：在"屏蔽的词"里加，或者在键盘上长按候选选 **不再显示这个词**。屏蔽的词不会出现在候选、联想和语音结果里。

**导出**（用户词库页下面"文件"里的一行）：把整个用户词库（添加的、学到的、屏蔽的）存成一个文本文件。要导回来或在别的手机上用，在 **词库与短语 → 导入词库** 里选这个文件，再选 **用户词库**。导出的文件第一行是 `# youmo-words 1`，靠这一行认出它是导出的文件，改掉或删掉这一行，导回时学到的词就丢了。文件里学到的词前面有 `~ `、后面带着用过的次数，导回后还是学到的词，排位也照旧；`~` 只在有这第一行的文件里认，别的词表里这样的行读不懂、不导入。以前版本导出的文件没有 `~`，学到的词导回后算作添加的词；新文件导进旧版本时，学到的词那几行读不懂、不导入。

## 导入词库

**词库与短语 → 导入词库**，支持：

- `.txt`：一行一个词，带拼音，词和拼音谁在前都行（`幽默 you'mo`）；搜狗、QQ 等输入法导出的词库文本也能读。只写词不写拼音的行和 `!` 开头的行只有并入**用户词库**才读；并入基础词库时每行都要有拼音，否则那一行不导入；
- `.dict`：Fcitx 5 的词库文件；
- `.scel`：搜狗细胞词库。

三种文件都可以并入基础词库或用户词库；`.dict` 和 `.scel` 并入用户词库时会先转成词表。

选文件后会问 **并入哪个词库？** 从用户词库导出的文件、含 `!` 开头的行（屏蔽的词）的文件，以及扩展名不是 `.txt`、`.dict`、`.scel` 的文本文件，默认选好"用户词库"（基础词库只收这三种），别的文件默认"基础词库（推荐）"。并入用户词库时任何文本词表都能读，只写词的行会自动配上拼音。

| 选项 | 适合 | 效果 |
|---|---|---|
| **基础词库（推荐）** | 大而杂的词库，比如几十万词的专业词库 | 词能打出来，按常用程度排，不会挤掉常用词 |
| **用户词库** | 几千个以内你常用的词 | 当成你自己加的词，排得靠前，选过就更靠前，可以编辑、导出。用户词库导出的文件也从这里导回：`!` 开头的词（导出的文件里屏蔽的词）回到"屏蔽的词"，`~` 开头的（学到的词）回到"自动学到的词" |

拿不准就选"基础词库"。选了用户词库而文件超过 1000 个词时（用户词库自己导出的文件不提示），会提示改放基础词库，并说明原因：用户词库的词在候选里排得靠前、语音输入优先往这些词上听、码表也会收进去，放得太多会让候选里多出很多排得靠前的词、常打的词可能被挤到后面，语音最多照顾 3000 个词（多出来的照顾不到，说话也更容易被听成列表里的词），码表重码变多，你自己加的词也被埋在里面；基础词库按常用程度和前后文排，不挤掉常用词，还能整个停用或删除。可以改放基础词库（文件是 `.txt`、`.dict`、`.scel` 时），也可以仍放用户词库。并入基础词库的词库会列在词库页"基础词库"一节里（内置词库下面），点它可以暂时停用或删除。并入用户词库的不单独列出，词进"手动添加的词"。文件太大、损坏或读不出词时会提示原因。

以前的版本导入时还有一个"新"的选项；那样导入的词库，更新后也都并到基础词库里，词照样能打。

## 自定义短语

**词库与短语 → 自定义短语**：打一个输入码，得到一段固定文字。比如打 `dz` 得到你的地址，打 `yx` 得到邮箱。

- 右下角 **+** 添加：
  - **输入码**：打什么，比如 `dz`；
  - **候选位置**：排在第几个，`1` 就是第一个；
  - **短语**：得到什么，可以有多行。
- 点一条可以编辑或删除。菜单里有 **导入**、**导出**。
- 在全拼和双拼里有效，按你打的字母匹配（九键打的是数字，用不了）。在键盘上长按候选选 **以自定义词组的方式置顶**，也会在这里加一条。

**自带的日期时间**：不用自己加。全拼里打 `rq` 出今天的日期（2026年10月17日、2026-10-17、二〇二六年十月十七日），`sj` 出现在的时间（09:05、09时05分），`xq` 出星期几（星期六、周六），都排在第一个候选后面，所以 `rq` 加空格还是"日期"。不想要哪一条，在键盘上长按它选 **从自定义词组中删除**，它在这里变成一条关闭的短语，想要回来就打开它。每个中文输入法（全拼、双拼、九键、码表）打出"日期""时间""星期"这几个词本身时，也在它后面（第三个候选起，和[表情](pinyin.md#表情候选)一样）给出这几条：双拼 `riqi`、九键 `7474`、五笔 `jfuj`（时间）都行；码表里编码只有这一个词、它自己上屏了，这几条出在联想最前面，点了就把刚上屏的词换掉。删掉的那条在哪里都不出。一条都不想要，在 **通用输入** 里关掉 **自带的日期时间**，你自己加的短语照常；再打开就回来（单独删掉的那条仍然是关闭的）。你在这一页给 `rq`、`sj`、`xq` 加了短语，自带的那几条就不出现了。在键盘上把一个词置顶到这几个输入码下，或删掉其中一条，这个输入码下自带的几条会先作为普通短语复制到这里，所以置顶以后日期还在。

**日期和时间**：短语以 `#` 开头时，里面的变量会换成当前的日期时间。比如短语写成 `#$year年$month月$day日 星期$weekday_cn`，打出来是"2026年9月7日 星期一"那样。

| 变量 | 含义 | 例子 |
|---|---|---|
| `$year` / `$year_yy` | 年 / 两位年 | 2026 / 26 |
| `$month` / `$month_mm` | 月 / 两位月 | 9 / 09 |
| `$day` / `$day_dd` | 日 / 两位日 | 7 / 07 |
| `$weekday` | 星期（数字，周日是 0） | 1 |
| `$fullhour` / `$halfhour` | 24 小时制 / 12 小时制的时 | 15 / 03 |
| `$ampm` / `$ampm_cn` | 上午还是下午 | PM / 下午 |
| `$minute` / `$second` | 分 / 秒 | 07 / 30 |
| `$year_cn` / `$year_yy_cn` | 中文年 | 二〇二六 / 二六 |
| `$month_cn` / `$day_cn` | 中文月、日 | 九 / 七 |
| `$weekday_cn` | 中文星期 | 一 |
| `$fullhour_cn` / `$halfhour_cn` | 中文时 | 十五 / 三 |
| `$minute_cn` / `$second_cn` | 中文分、秒 | 零七 / 三十 |

## 想要什么样的效果，用哪个功能

| 想要 | 用 |
|---|---|
| 某个词总是打不出来 | 用户词库里添加它（写上拼音） |
| 某个词老是冒出来很烦 | 长按它选"不再显示这个词" |
| 打某个拼音时固定某个词排第一 | 长按它选"以自定义词组的方式置顶" |
| 输入法学错了某个词的位置 | 长按它选"忘记词汇" |
| 打几个字母出一大段固定文字 | 自定义短语 |
| 一大批专业词汇 | 导入词库，选"基础词库" |
| 换手机 | 用户词库"导出"，或者 **备份与恢复 → 备份全部** |
