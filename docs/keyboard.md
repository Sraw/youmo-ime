# 键盘与手势

## 全键盘（26 键）

拼音、双拼、英文和各种码表都用这个键盘（图里键角的小字是英文里的样子；打中文、用中文标点时，有中文标点的会显示成中文标点，比如 m 的 `\` 是 `、`，v 的 `?` 是 `？`）。

```
 q1  w2  e3  r4  t5  y6  u7  i8  o9  p0
  a@  s*  d+  f-  g=  h/  j#  k(  l)
 ⇧   z'  x:  c"  v?  b!  n~  m\   ⌫
 符  123  ，      空格       。  🌐  ↵
```

### 横屏分体键盘

横屏时（屏幕够宽）这个键盘会分成左右两半，方便两个拇指打字，G、V 两边各有一个：

```
 q  w  e  r  t          y  u  i  o  p
 a  s  d  f  g          g  h  j  k  l
 ⇧  z  x  c  v          v  b  n  m  ⌫
 符 123 ，        空格         。 🌐 ↵
```

分开时，其他面板（数字键盘、九键、手写板、符号、表情、剪贴板）连同上面的工具栏会缩成单手宽，默认靠右，拇指够得着；另一边空白处有一个箭头，点一下就移到另一边。

不想分开见[设置 · 大小与按键](settings.md#大小与按键)里的 **分体键盘**；其他面板想铺满整个宽度，把同一节的 **分体时其他面板** 选成"铺满"。

### 字母键

- **点**：打出这个字母。
- **键角上的小字**（数字和符号）有两种打法：
  - **向下滑**这个键（默认方向，可以在"按键与振动"里改成上滑或关掉）；
  - **长按**后直接松手。
- **长按**会弹出这个键的更多字符（比如 `q` 有 `1` 和 `Q`），手指滑到想要的那个再松开。
- 长按弹出哪些字符、键角显示哪个，都可以在 **按键与振动 → 按键字符** 里改：第一个字符同时就是键角小字和滑动打出的字符。

### 功能键

| 键 | 点 | 长按 / 滑动 |
|---|---|---|
| **⇧** Shift | 下一个字母大写 | 双击或长按：大写锁定 |
| **⌫** 退格 | 删除一个字（表情等整个删除） | 按住连续删除；**向左滑**：选中光标前的文字，松手删除。正在打拼音时向左滑是清空正在打的拼音 |
| **符** | 打开符号面板 | 长按：[快速输入](other-input-methods.md#快速输入)（颜文字、LaTeX 符号、表情代码） |
| **123** | 数字键盘 | 长按：[Unicode 输入](other-input-methods.md#unicode-输入) |
| **，** / **。** | 逗号、句号（打中文时是中文标点，跟在字母或数字后面也是；小数点用数字键盘的 `.`） | 长按弹出更多标点 |
| **空格** | 空格；有候选时上屏第一个候选 | **左右滑**：移动光标；长按：见"空格键长按行为"（语音版默认是按住说话） |
| **🌐** 地球键 | 切到下一个输入法 | 长按：系统的输入法选择框 |
| **↵** 回车 | 换行；在搜索框、聊天框等是"搜索""发送""下一项""完成"，图标会跟着变 | 正在打拼音时，回车把打的字母原样上屏 |

### 网址和邮箱输入框

在输入网址的框里，逗号和句号的位置换成 **/**、**.** 和 **.com**；在邮箱框里换成 **@**、**.** 和 **.com**。
长按 **.com** 还有 `.cn`、`.net`、`.org`。这些键直接打出原样的字符，不经过中文标点转换。
在这两种框里，数字和其他符号（123 页、长按和滑动打的）也原样打出；正在打的拼音先原样上屏，比如全键盘打 `xiaoming` 再按 **@** 得到 `xiaoming@`。九键的数字、双拼里当键用的符号（比如微软双拼、紫光双拼的 `;`）还是打字用的键。正在打拼音时，分词的 `'`（Z 键上滑）也照常分词。用五笔、仓颉、二笔等打字时，正在打的编码里当键用的符号（比如二笔的 `;`、仓颉的 `*`）也照常打编码。

### 括号成对

打左括号或左引号时会自动补上右边的，光标停在中间；接着打右括号会跳过已有的那个，而不是再加一个；
紧接着退格会把一对一起删掉。只在后面是空白或标点的地方才补，不会在一个词中间乱加。可以在"按键与振动"里关掉。

## 九键键盘

添加"九键拼音"后，切到它时用九宫格：

```
 ，   ，。?!  ABC   DEF    ⌫
 。   GHI    JKL   MNO   重输
 ？   PQRS   TUV   WXYZ    0
 ！
 符   123      空格      🌐  ↵
```

- **左边一列**：没打字时是常用标点；打字时是**拼音选择栏**，列出前面几个数字可能是哪些音节（`64` 可能是 ni、mi、o…），点一个就把它定下来，候选只按这个音节找。
- **1 键**：打字时是**分词**（像全拼里的 `'`）；没打字时打标点 `，。？！`，快速连按换成下一个（关掉"连按选字母"后不换，每按一次都是 `，`，其他标点从候选栏或长按选），长按有更多。
- **2–9**：每个键代表它上面的几个字母，输入法根据整句判断你要的是哪个。
  - **连按选字母**：快速连按同一个键，也可以表示它的第二个、第三个字母（按两下 `4` 可以是 h）；输入法同时按两种读法判断，正常快打不受影响。快慢在九键拼音的设置里调。
  - **长按**：弹出这个数字和它的几个字母，选一个字母会按这个字母本身打出来。
  - **滑动**数字键（1 也一样）：打出数字本身。
- **重输**：清空正在打的内容。
- 选过音节以后退格，会先把选过的音节退回成数字（最后选的先退）。
- 每个键打哪些字母可以自定义，见[设置逐项说明](settings.md#九键拼音)。

## 数字键盘

点 **123** 打开：

```
 +   1   2   3   /
 -   4   5   6   空格
 *   7   8   9   ⌫
 ABC ,  !?#  0   =  .  ↵
```

**ABC** 回到字母键盘，**!?#** 打开符号面板。

## 键盘上方的栏

没打字时，这一栏是工具栏；打字时显示候选。

### 工具栏

- 最左边的 **>**：展开工具栏，依次是：
  - **撤销**、**重做**
  - **文本编辑**（光标图标）：见下面的文本编辑面板
  - **剪贴板**
  - **…**：更多，见"状态面板"
- 右边：**表情**按钮（语音版旁边还有**麦克风**，打开语音面板），**⌄** 收起键盘。
- **剪贴板提示**：刚复制了东西时（30 秒内），栏上会直接显示复制的内容，点一下就粘贴。
- **计算结果**：打一个算式再打 `=`，比如 `12*3.5=`，栏上显示"= 42"，点一下就把结果填在等号后面（想让结果替换整个算式，打开设置 **按键与振动 → 点算式结果时替换整个算式**）；光标一移开就不显示了。用哪个键盘打都行（数字键盘、长按字母打出的数字和符号也算），支持加减乘除（`+ - * /`，也认 `× ÷ x`）、括号、乘方 `^` 和百分号 `%`（`200*15%=` 得 30），小数按十进制算（`0.1+0.2=` 得 0.3）。密码框里不算。
- 在密码框里，键盘自动换成英文（空格键上显示"英文"），字母直接打进去，不出候选；这一栏显示一排数字键，方便输入数字密码。离开密码框就回到原来的输入法。
- 应用要求不记录输入时（比如浏览器的无痕模式），左边的图标会变成一个隐私图标，表示这次输入不会被学习。

### 候选

- 点一个候选上屏；候选栏可以左右滑看更多。
- 右边的 **⌄** 展开所有候选，以表格显示，可以上下翻。
- **长按候选**：弹出菜单，见[拼音输入 · 长按候选](pinyin.md#长按候选)。手写的候选（最后一个字的几种可能）长按没有菜单，手写和码表的联想词有。

## 状态面板（工具栏的 …）

| 按钮 | 作用 |
|---|---|
| 主题 | 打开"主题与大小"设置 |
| 输入法设置 | 打开当前输入法的设置页 |
| 按键与振动 | 打开"按键与振动"设置 |
| 简 / 繁 | 切换简体 / 繁体输出 |
| 中文标点 / 英文标点 | 打中文时标点用全角中文标点还是英文标点 |
| 半角 / 全角 | 字母和数字用半角还是全角 |
| 右上角齿轮 | 打开设置首页 |

简 / 繁、中文标点 / 英文标点、半角 / 全角只在中文输入法里有；英文里字母、数字和标点都按原样打出，中文里开着的全角不影响英文。

## 文本编辑面板

工具栏的光标图标打开，适合精确移动光标和选择文字：

- **↑ ↓ ← →**：移动光标。
- **选择**：打开后再按方向键就是扩大选区。
- **|<**、**>|**：移到开头、结尾。
- **全选**、**剪切**（有选区时）、**复制**、**粘贴**、**⌫**。
- 右上角是剪贴板。左上角 **←** 返回键盘。

## 剪贴板

开启"记录剪贴板历史"后（默认开启），复制过的内容会出现在剪贴板面板里：

- 点一条：粘贴。
- 长按一条：**置顶**（置顶的不会被自动清掉）/ 取消置顶、**编辑**、**分享**、**删除**。
- 右上角的垃圾桶：删除所有未置顶的条目。
- 密码等敏感内容（应用标为敏感的）显示为圆点。
- 复制的链接存进历史前会去掉跟踪参数（比如 `utm_source`），系统剪贴板里的原样不动。

最多保留多少条、是否显示剪贴板提示等，在 **剪贴板** 设置里调。

## 符号面板

点 **符** 打开。左边是分类：最近、常用、中文、英文、括号、箭头、数学（含希腊字母）、序号、图形、全角。
点一个符号就打出来并回到键盘。点下面的**锁**锁上后，选完符号会留在面板里，方便连续选几个；**返回**回到键盘；
**12/34** 打开数字键盘。面板会记住上次看的分类。

## 表情面板

点工具栏右边的笑脸打开。上面的标签是分类（最近使用、笑脸、人物、动物与自然、食物与饮料、旅行与地点、活动、物品、符号、旗帜），
整个列表可以上下滑。默认肤色在 **表情和符号** 设置里选；系统字体不支持的表情不显示。
表情和分类按 Unicode 的表情列表（Emoji 17.0）排；打字时的[表情候选](pinyin.md#表情候选)也来自同一份数据。

点下面的**放大镜**按拼音搜表情：打全拼（`xiao` 找“笑”）、开头几个音节（`xiaol` 找“笑脸”）或每个字的首字母（`dz` 找“点赞”），
上面一排就列出对应的表情，点一个打出来，也会记进最近使用。拼音删完后再按退格，删的是输入框里的字。**返回**回到表情列表。

## 实体键盘

接上蓝牙或 USB 键盘时，一按键盘上的字，屏幕键盘就收起，正在打的拼音和候选显示在光标附近的小窗里（可以在 **高级 → 实体键盘的候选窗** 里调）。

按键和全键盘一样：字母打拼音，空格和数字选候选，回车原样上屏，Esc 取消正在打的字。

| 按键 | 作用 |
|---|---|
| **单按 Shift**（左右都行，按下马上松开） | 中文和英文之间切换：中文输入法切到英文，英文切回刚才那个中文输入法。正在打的拼音按原样上屏。按住 Shift 打大写字母不会切换。 |
| **Ctrl + 空格** | 同上，中英切换。没有可切换的输入法时（比如只添加了英文），这个组合键照常交给应用。 |
| **Ctrl + Shift** | 轮流切换已添加的输入法（拼音、英文、五笔……）。用实体键盘时跳过手写和九键，它们是给触屏用的。按住 Ctrl 或 Shift 中的一个不放，每轻按一下另一个，就再往下切一个。 |
| **`-` / `=`** | 打字时往前、往后翻候选页（也可以用 PageUp / PageDown）。没在打字时照常打出 `-` 和 `=`。 |

切换后光标旁会短暂显示输入法的名字（"拼""En""五"……），状态栏也有图标。这三个快捷键可以在设置里一起关掉（**实体键盘快捷键**，见[设置](settings.md)）。

**在手写或九键里按实体键盘**：手写和九键是给触屏用的，实体键盘上的字改用拼音来打（列表里的全拼或双拼，哪个在前用哪个；都没添加时用列表里第一个能用键盘打的中文输入法），比如手写时按 `ni` 空格得到"你"。等屏幕键盘回来时，又是原来的手写或九键。

**想用屏幕键盘**（比如要发表情、手写）：点光标旁小窗右端的键盘图标，屏幕键盘就回来；再按实体键盘上的字，它又收起。没在打字时小窗只剩这个图标，停在光标右边。有的应用不告诉输入法光标在哪里，在这些应用里这个图标放在屏幕右上角。图标可以按住拖到别处：不告诉光标的应用里拖到哪里，以后（换输入框、重启后）都放在那里；在一般输入框里拖动只管当前这个框，换一个框它又回到光标旁。在一般应用的输入框里，点一下输入框也能叫回屏幕键盘；Chrome 等浏览器里的网页输入框点了不会通知输入法，要用这个图标。拔掉或关掉实体键盘后，屏幕键盘自动回来。

## 振动和按键音

默认跟随系统设置。在 **按键与振动 → 声音与振动** 里可以单独打开或关掉，并选振动强度（轻、中、强）和按键音音量（小、中、大）。
