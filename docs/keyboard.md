# 键盘与手势

## 全键盘（26 键）

拼音、双拼、英文和各种码表都用这个键盘（图里键角的小字是英文里的样子；打中文、用中文标点时，有中文标点的会显示成中文标点，比如 m 的 `\` 是 `、`，v 的 `?` 是 `？`）。

```
 q1  w2  e3  r4  t5  y6  u7  i8  o9  p0
  a@  s*  d+  f-  g=  h/  j#  k(  l)
 ⇧   z'  x:  c"  v?  b!  n~  m\   ⌫
 符  123  ，      空格       。  🌐  ↵
```

### 横屏分体键盘

横屏时（屏幕够宽）这个键盘会分成左右两半（设置里选"总是"的话竖屏也分），方便两个拇指打字，G、V 两边各有一个：

```
 q  w  e  r  t          y  u  i  o  p
 a  s  d  f  g          g  h  j  k  l
 ⇧  z  x  c  v          v  b  n  m  ⌫
 符 123 ，        空格         。 🌐 ↵
```

分开时，其他面板（数字键盘、九键、手写板、符号、表情、剪贴板）连同上面的工具栏会缩成单手宽，默认靠右，拇指够得着；另一边空白处有一个箭头，点一下就移到另一边。

不想分开见[设置 · 大小与样式](settings.md#大小与样式)里的 **分体键盘**；其他面板想铺满整个宽度，把同一节的 **分体时其他面板** 选成"铺满"。

### 单手模式

手大屏也大、只用一只手打字时，在工具栏 **⋯** 里点 **单手模式**：整个键盘（连同工具栏、符号和表情面板、剪贴板）缩到屏幕宽度的八成，
靠右放（平板竖屏时最宽一个手机宽）；换过边的话，下次打开还在上次那一边。旁边空出的地方有两个按钮：箭头把键盘换到另一边（键盘滑过去），斜箭头恢复全宽（键盘从一边展开）。再点一次 **单手模式** 也恢复全宽。
打字时浮在键盘上方的编码行跟着键盘，贴在键盘左上角外面，换边时一起滑过去。
分体键盘分开时（横屏）不用单手模式。也可以在[设置 · 大小与样式](settings.md#大小与样式)里的 **单手模式** 选靠右、靠左或关。

### 悬浮键盘

在工具栏 **⋯** 里点 **悬浮键盘**：键盘变小（屏幕宽度的七成，最宽一个手机宽，平板上好用），浮在应用上面，带一点阴影，四角跟按键一样圆（主题的 **圆角** 是直角，或 [大小与样式](settings.md#大小与样式) 的 **按键圆角** 选直角时，就是直角），应用不再被顶起；
键盘外面的地方照常点应用。键盘上的字比平常小一点（键也矮一点），工具栏的按钮挨得近一些，图标和平常一样大。键盘最下面一条中间有一根短横条，按住这一条拖到哪里就停在哪里，下次打开还在那里，屏幕转过来也停在同一个角。
想放在顶上的话，把设置里的 **悬浮键盘拖动条** 改成"上面"，那时这一条比下面的工具栏深一点（深色主题是浅一点），好分清。
悬浮键盘最低停在屏幕底部一条空位的上方（导航栏上方，手机底部有切换键盘、收起键盘那一栏时在它上方）。拖到最低处，这条空位里会从下往上展开一条蓝框（主题的强调色）并振一下（跟随"按键振动"设置），这时松手键盘就放回底部（只有手指抬起才算，拖动被打断或多按一根手指都不放回，键盘就停在拖到的地方；放回底部后下次悬浮，回到这次拖之前停的位置）；往回拖离开最低处，框缩回去，松手照常悬浮。
打字时浮在键盘上方的编码行贴在悬浮键盘左上角外面（拖动条在上面时在拖动条上面），跟着键盘走；键盘拖到屏幕最上面、上面放不下时，换到键盘下边外面。拖动、缩放的过程中这一条先藏起来，停下后再出现。
拖动条右边的斜箭头也把键盘放回底部，再点一次 **悬浮键盘** 也一样；放回时键盘先滑到屏幕底部再变回原来的样子。打开悬浮键盘时，键盘从原来的大小缩到悬浮的大小和位置。悬浮时字母键不分体，也不用单手模式。

不想每次都去 **⋯** 里点的话，打开设置里的 **始终显示悬浮条**：键盘停在底部时也有这一条（上面还是下面同样跟 **悬浮键盘拖动条** 走），按键行高度不变，整个键盘高出这一条（横屏等键盘已顶到约屏幕七成的上限时，按键行矮一点让出这一条）；停在底部时条的右边没有按钮；单手模式（或分体时面板缩到一边）时，这一条也跟着缩到键盘那一边，短横在键盘中间。
长按条中间的短横，振一下（跟随"按键振动"设置），键盘就从原来的大小缩成悬浮键盘，停在手指下面，手指不松可以接着拖到想放的地方；长按错了的话，接着往下拖进底部那条空位松手，就又放回底部，下次悬浮还在原来停的位置。

### 字母键

- **点**：打出这个字母。
- **键角上的小字**（数字和符号）有两种打法：
  - **向下滑**这个键（默认，见下面的 **滑动**）；
  - **长按**后直接松手。
- **上滑**是这个键的**快捷键**（默认）：a 全选、c 复制、x 剪切、v 粘贴、z 撤销、y 重做。有快捷键的键在 **按键 → 快捷键图标位置** 选的地方画着它的图标（文字快捷键缩小显示），键角的小字和数字在 **按键 → 标点位置** 选的地方。两项是同一组选项：右上 / 右下 / 左上 / 左下 / 底部 / 无，默认标点右上、快捷键左上；所有键都画在选的那一处，不管滑动设成哪个方向、往哪边滑打出它。「底部」对快捷键是键的下边中间，对小字是字母下面；横屏、键盘高度选紧凑时键太矮，「底部」改画在角上：标点的画在右上（快捷键在右上时画在右下）；快捷键的画在第一个空着的角，按左上、右上、左下、右下的顺序，跳过标点占着的角（标点默认右上时画在左上，标点在左上时画在右上）。「无」是不画，滑动照常能用。两项不能选同一个位置（都选「无」可以）：选一项时，另一项占着的位置在列表里是灰的、点不了，后面注着「快捷键图标在这里」或「标点在这里」；导入或恢复的设置里两项是同一个位置时，按小字让开读：右上↔右下、左上↔左下（同一侧上下对调），底部→右上。退格、空格这类功能键：上滑的快捷键在选的地方，下滑的在它上下对称的地方（选左上则下滑的在左下，选右上则在右下，选底部则在上边中间）。第一次打开和改过设置后摆法一样。键盘高度选 **紧凑** 时也照样画，标记小一号。五笔「按键显示」选**全部字根**时，字根从键的左上角排满整个键，字母键上不画快捷键，照样能滑；键盘高度是紧凑时显示成键名，照键名画。键上的字和标记、标记和标记，在哪种键盘、哪种高度、悬浮单手横屏下都不叠在一起，碰上时按这个次序让开：⓪ 两个标记互相碰上（窄键上左上的图标和右上的小字，或左上的图标和左下的小字），两个一起往各自的角缩小，缩到分开为止；① 标记往自己的角里挪（角上的往旁边或往外，取挪得少的；边中间的只往外）；② 字或图标挪开（字母键的字母不挪，一行字母总在同一条基线上）；③ 标记缩小（小字最小约 6 dp，图标约 7 dp，再小认不出）；④ 字缩小：字母整个键盘按同一个比例缩小，最多四分之一；别的键的字或图标单独缩小，最多五分之一；⑤ 快捷键标记换到这个键上第一个空着的角（按左上、右上、左下、右下，跳过小字占着的；功能键上滑、下滑的两个一起换，仍上下对称，上滑的仍在原来那一侧（选底部时上滑的换到下面的角）），在那里同样挪、缩小；⑥ 哪个角都放不下才**不画**快捷键图标（功能键先省下滑的那个），滑动照常能用；键角小字从不省，真放不下时字缩到最小、小字照画（实际哪个键盘都没有这种情况）。实际上哪种键盘、哪种高度、哪种组合下都没有不画的；换了角的只有少数键：紧凑又单手时选左下、右下，五笔最下一行的几个键（右下时还有全键盘的 a c v x y z）；悬浮键盘选「底部」时大千、手写、注音九键的退格；悬浮时全键盘的 a 偶尔。复制、剪切在没选中文字时对整个输入框做，光标留在原处；剪切错了可以撤销。正在打拼音时先上屏首选再执行。密码框里复制、剪切不响应。
- **滑动**（**按键 → 滑动**）选上滑、下滑各到哪一层：上滑快捷键下滑符号（默认）/ 上滑符号下滑快捷键 / 只下滑打符号 / 只上滑打符号 / 只上滑用快捷键 / 只下滑用快捷键 / 关。滑向关着的方向，或滑向这个键没有东西的一层（没有快捷键、没有小字），当作点了这个键，打出字母；滑过之后又滑回原处松手是取消。设成"关"时，所有键都不滑，退格、空格这类功能键也一样：滑出这个键什么也不打（就是把这次按键取消），滑出又滑回原处松手照样算点了这个键。开着 **按键时弹出显示字符** 时，滑过阈值后键上方的小框换成这一层的内容：符号照字母的大小显示（紧凑、悬浮时和普通按键时的字母一样跟着键上的字缩小）；快捷键显示它的名字（「全选」「快速输入」）或设的文字，字小一号（和底排「符」「123」差不多，紧凑、悬浮时跟着键上的字一起缩小），框最宽五个字（键更宽时和键一样宽），放不下先把字缩小，最小再小一号，还放不下就截掉后面、末尾显示「…」（比如「我的邮箱是 s…」）；文字里的换行显示成空格；只有一个字（如「你」、一个表情、国旗、带肤色或一家人的表情、带声调的字母）的文字照符号的大小，截断时也不会把这样的一个字切开。滑过阈值时轻振一下。
- **长按**会弹出这个键的更多字符（比如 `q` 有 `1` 和 `Q`），浮在键的上方，手指往左右上下稍微挪一点就换一个（不用挪到那个字符的正上方），换的时候轻振一下（跟随"按键振动"设置），选好松开。挪过了头停在那一行的头尾；上面一行短，挪到空位上就选这一行最近的那个。往下滑出这个键再松开是不选。九键、数字键盘和底排键的长按也是这样。
- 每个键的快捷键可以在 **按键 → 按键字符和快捷键** 里改成别的命令（全选、复制、剪切、粘贴、撤销、重做、清除、恢复刚删除的、光标到开头 / 结尾、编辑菜单、剪贴板、快速输入、表情、语音输入、切简繁、切键盘、收起键盘）或一段文字（最多 200 字，键角上整段缩小显示），也可以不设。
- 长按弹出哪些字符、键角显示哪个，都可以在 **按键 → 按键字符和快捷键** 里改：第一个字符同时就是键角小字和滑动打出的字符。键盘自己内部用的键码（拼音 14 键、双拼键盘的内部字符）不能单独设成长按字符：输入框会提示，对话框不关。
- **在键上划**：在 **通用输入** 里打开 **滑行输入** 或 **笔画筛选**，两个只能开一个。滑行输入是划过一个词的字母打出它（见[拼音](pinyin.md#滑行输入)、[英文](other-input-methods.md#英文)）；笔画筛选是打着拼音时画一笔筛候选（见[拼音](pinyin.md#笔画筛选)）。滑行要横着划过大半个键或上下划过一行半以上，短划照旧打角标；笔画在打着拼音时划出小半个键就算，这时短划也是画笔画。
- 微软双拼用 `;` 打 ing，这个方案的字母键盘第二行 L 右边多一个 **;** 键（和实体键盘上一样的位置）。分体键盘上没有这个键，就用 `l` 长按弹出里的 `;`。全拼里 `l` 长按的 `;` 是分号。

### 编辑菜单和清空

- **空格上滑**（默认）弹出编辑菜单：全选、剪切、复制、粘贴、撤销五格一排，弹在键盘上方、平时"已复制"这类提示出现的地方（不在手指底下），粘贴对着空格。悬浮键盘时跟提示一样在键盘朝屏幕中间的一侧（上面放不下就在下面，贴边时在旁边）。不松手往左右挪选一格（按挪了多远算，不用把手指挪到菜单那里；每格轻振一下），松开执行；往下滑回键上松开是取消。所以空格上滑直接松手是粘贴，左挪一格是复制，右挪一格是撤销。菜单弹出时，和菜单位置重叠的提示先收起；按键出错时的提示（比如「词库没装上」）不收起，先藏到菜单后面、暂停计时，菜单收起后再出现，重新显示满时长。菜单开着时新来的提示也先藏着，菜单收起后再出现、再开始计时。不和菜单重叠的提示（比如候选栏上「记住了」的撤销）不受影响。密码框里复制、剪切是灰的。别的键的快捷键设成 **编辑菜单** 也一样，粘贴对着那个键。
- **退格上滑**是 **清除**：正在打拼音（码表编码、英文单词）时只清掉这串，不上屏；有选中的字时删掉选中的；否则删光标前的全部文字，光标前没有字时删光标后的全部文字（光标在中间时连滑两次就清掉整个框）。有的应用一次只给输入法一部分光标前的文字，这时清除只删它给出的那部分（再滑一次接着删），撤销放回的也正是这部分，放回光标处。键盘上提示"已清除"，点 **撤销** 放回。
- **退格下滑**是 **恢复**：放回最近一次删掉的，放回原处，光标回到删之前的位置。删掉的一次是一次清除，或者**连着按退格删掉的一段**：一下一下按、按住连删、左滑选中删除，中间没打字、没挪光标、没换输入框或输入法，都算同一段，下滑一次整段放回（删的是选中的字，放回后光标在它后面，不再选中）；中间点一下输入框、复制、转屏都不打断这一段，点一下输入框以后再删的另起一段（有些网页里的框和部分应用不告诉输入法点了框，这时点到别处再删，下滑就恢复不了）；正打着拼音时退格删的是拼音串，不算。再下滑放回再前一次（清除和连删按倒序一次放回一段，拼音串放回后接着打）。只在同一个框、删了以后框里没有别的改动时有效（没打字、光标没被挪走；正打着拼音时也不恢复，先清掉或打完），否则提示"没有可恢复的内容"。删掉的内容只放在内存里，换个输入框（哪怕看起来是同一个框，比如聊天软件换了对话；应用自己让输入重新开始的，比如有些网页里的框，也算换了框）、离开这个框就没了，转屏不算；最多记 16 次；密码框和不让记输入习惯的框（比如浏览器的无痕模式）能清除、能删，但不记内容，不能恢复；终端这类只收按键的框里连删也不记。连删一段最长约 1000 字，再长就不能恢复；自动配对的空括号或引号被退格整对删掉（右边那个跟着删掉）后，这一整段连删都不能恢复，不只是那对括号。拼音串里已经选过一部分字（点候选、按数字键选的、九键、14 键、18 键在音节栏选了音节的都算）、或长按候选做过操作（置顶、不再显示等）后再清除的，不能恢复；换了输入法或键盘（比如全键盘换成 14 键）后也恢复不了。读不到选中文字的应用里，清除只删选中的部分，不能恢复。
- 清除和恢复设在别的键上也是这样。
- 空格先横着滑是移光标，先竖着滑是上滑 / 下滑，一次只认一个方向；退格左滑选中删除也一样照旧。
- 功能键的上滑、下滑也能在 **按键字符和快捷键 → 功能键** 里设；滑向关着的方向或没设的方向，键照旧。

### 功能键

| 键 | 点 | 长按 / 滑动 |
|---|---|---|
| **⇧** Shift | 下一个字母大写 | 双击或长按：大写锁定 |
| **⌫** 退格 | 删除一个字（表情等整个删除） | 按住连续删除；**向左滑**：选中光标前的文字，松手删除。正在打拼音时向左滑是清空正在打的拼音 |
| **符** | 打开符号面板 | 长按：[快速输入](other-input-methods.md#快速输入)（你存的常用语，颜文字、LaTeX 符号、表情代码）；九键、手写上也一样 |
| **123** | 数字键盘 | 长按：[Unicode 输入](other-input-methods.md#unicode-输入) |
| **，** / **。** | 逗号、句号（打中文时是中文标点，跟在字母或数字后面也是；小数点用数字键盘的 `.`） | 长按弹出更多标点 |
| **空格** | 空格；有候选时上屏第一个候选 | **左右滑**：移动光标；长按：见"空格键长按行为"（语音版默认是按住说话；设为"无"时，或语音输入在密码框里，按住再松开就是一个空格，按住后照样能左右滑） |
| **🌐** 地球键 | 切到下一个输入法 | 长按：系统的输入法选择框 |
| **↵** 回车 | 换行；在搜索框、聊天框等是"搜索""发送""下一项""完成"，图标会跟着变 | 正在打拼音时，回车把打的字母原样上屏 |

### 网址和邮箱输入框

在输入网址的框里，逗号和句号的位置换成 **/**、**.** 和 **.com**；在邮箱框里换成 **@**、**.** 和 **.com**。
长按 **.com** 还有 `.cn`、`.net`、`.org`。这些键直接打出原样的字符，不经过中文标点转换。
没在打字时，键盘上方的栏给出地址的建议，点一下填进去：

- **邮箱框**：空框给 @qq.com、@163.com、@gmail.com、@outlook.com、@126.com、@foxmail.com、@icloud.com，点了光标留在 @ 前面，接着打名字；打了名字再点，后缀接在后面，光标到末尾；打了 `@` 以后只留下和后面字母对得上的（`@g` 只剩 gmail.com）。打过的完整邮箱地址会记住，按已经打的开头给出，排在后缀前面，点了整个地址替换已经打的。
- **网址框**：空框给 `https://` 和 `www.`；打了主机名（比如 `www.example`）给 .com、.cn、.com.cn、.net、.org，补在光标处；后缀打了一半（`baidu.c`）只给对得上的（.com、.cn、.com.cn），点了补完（`baidu.com`），不会重复；主机名已经有这些后缀的就不给，已带后缀又打了一半（`sina.com.c`）只补全更长的后缀（.com.cn）。汉字等不是地址的字后面不给后缀（邮箱名字里可以有 `+`）。
- 用得多的后缀排前面。只记后缀用了几次和完整的邮箱地址，不记网址；离开这个框、点到别的框时才记（换成别的输入法时也记下最后这个框），收起键盘、转屏、框自己重新开始都不算离开，但同一个界面里内容不一样的另一个框算（网页、Compose 界面的几个框系统看来是同一个）；框里原来就有、自己没改过的不记（比如应用自动填好的地址，选没选中都一样）；无痕模式这类不记录输入的框和密码框里什么都不记（建议照样给），关掉 ⋯ 菜单的「用我的输入习惯」时也不记、不给记住的地址。只看输入框自己说的类型，不猜。
- 只读光标前后各 256 个字以内的内容来给建议，什么也不留；一个地址超过这个长度就不给、不记。
- 两个后缀列表、要不要记住邮箱地址、记住的地址在 [通用输入 → 网址和邮箱](settings.md#网址和邮箱) 里改。

九键在这两种框里把这些放在左边那一列，见[九键键盘](#九键键盘)。在这两种框里，数字和其他符号（123 页、长按和滑动打的）也原样打出；正在打的拼音先原样上屏，比如全键盘打 `xiaoming` 再按 **@** 得到 `xiaoming@`。九键的数字、双拼里当键用的符号（比如微软双拼的 `;`）还是打字用的键。正在打拼音时，分词的 `'`（向下滑 Z 键）也照常分词。用五笔、仓颉、二笔等打字时，正在打的编码里当键用的符号（比如二笔的 `;`、仓颉的 `*`）也照常打编码。

### 括号成对

打左括号或左引号时会自动补上右边的，光标停在中间；接着打右括号会跳过已有的那个，而不是再加一个；
紧接着退格会把一对一起删掉。只在后面是空白或标点的地方才补，不会在一个词中间乱加。可以在"通用输入"里关掉。

|---|---|
| 拼音 | 全键盘（默认）、18 键、14 键、九键、注音九键、注音全键盘 |
| 双拼 | 全键盘（默认）、18 键、14 键（微软没有，选着时换成 18 键）、九键 |

## 九键键盘

在 **输入法 → 拼音** 里把 **键盘** 选成「九键」（或者 **⋯ → 键盘** 里选），拼音就用九宫格：

```
 ，   ，。?!  ABC   DEF    ⌫
 。   GHI    JKL   MNO   重输
 ？   PQRS   TUV   WXYZ    0
 ！
 符   123     拼音     🌐  ↵
```

- **🌐**：和别的键盘一样换到输入法列表里的下一个，拼音后面是英文时就是英文（英文的键盘选了九键就是[九键英文](#九键英文)）。九键上没有中/英键。
- **左边一列**：没打字时是常用标点；打字时是**拼音选择栏**，列出前面几个数字可能是哪些音节（`64` 可能是 ni、mi、o…），点一个就把它定下来，候选只按这个音节找。
- **1 键**：打字时是**分词**（像全拼里的 `'`）；没打字时打标点 `，。？！`，打开"连按选字母"时快速连按换成下一个（默认关，不换：每按一次都是 `，`，其他标点从候选栏或长按选），长按有更多（原样打出，可以在 **按键长按** 里改）。
- **2–9**：每个键代表它上面的几个字母，输入法根据整句判断你要的是哪个。
  - **连按选字母**（默认关）：打开后，快速连按同一个键就是它的第二个、第三个字母（按两下 `4` 就是 h，不会再当成两个键）；按一下仍是这个键的几个字母都算，要单独的第一个字母（g）就点左边拼音列；关着时每按一次都是一个键，由输入法按上下文判断。快慢在 **输入法 → 拼音**（或英文）的「九键」一栏里调，见[设置逐项说明](settings.md#九键)。
  - **长按**：弹出一行，左边是这个键字母的大写，中间是数字，右边是小写（2 键是 `A B C 2 a b c`），手指一开始在数字上；选哪个就直接上屏哪个，正在打字时先把第一个候选上屏，再打出它。上面几行是这个键的**符号**，默认是它几个字母在全键盘上的角标（2 键 `@ ! "`、5 键 `# ( )`…），开着中文标点时打出中文的（`！`、`（`）；正在打字时同样先把第一个候选上屏，再打出符号（和全键盘一样，`'` 在打字时是分词）。一行放不下时键会变窄、字跟着变小。每个键的符号可以改，见[设置逐项说明](settings.md#九键)的 **按键长按**。
  - **滑动**数字键（1 也一样）：按 **按键 → 滑动** 的符号方向（默认下滑）滑，打出数字本身（正在打字时和数字键盘一样，选对应的候选：滑 1 选第一个、滑 2 选第二个……）；快捷键方向（默认上滑）是这个键的快捷键（默认 2 全选、3 复制，照键上字母里最常用的那个：v 在 8、z 在 9……），没有快捷键时当作点；设成关时滑动打不出数字。
- **0 键**：没打字时打 `0`；打字时先把第一个候选上屏，再打 `0`（不会去选第十个候选）。字母被清空的键在打字时也一样。
- **重输**：清空正在打的内容。
- 选过音节以后退格，会先把选过的音节退回成数字（最后选的先退）。
- 每个键打哪些字母可以自定义，见[设置逐项说明](settings.md#九键)。
- 在网址、邮箱输入框里，左边那一列的标点换成网址、邮箱用的：网址框是 `/ . .com : - _ ? = & #`，邮箱框是 `@ . .com - _ +`，后面还有 `.cn .net .org`（一次显示四个，上下滑看更多），都原样打出。底排和平常一样（空格、地球键都在）。打拼音时这一列照常是拼音，上屏后回到这些。九键英文也一样。

### 九键英文

在 **输入法 → 英文** 里把 **键盘** 选成「九键」，用 🌐 切到英文时就是九宫格的英文：

```
 ,   .,?!   abc   def    ⌫
 .   ghi    jkl   mno    ⇧
 ?   pqrs   tuv   wxyz   0
 !
 符   123     英文     🌐  ↵
```

- **打词**（预测，默认）：每个键代表它上面的几个字母，按完一个词的键，输入法猜是哪个词：`4663` 给出 good、home、gone……和键数一样长的词排在前面，后面是以它开头的长词。拼音行显示第一个候选，按**空格**上屏它和一个空格，按标点、回车、方向键也是先上屏它；点别的候选就上屏那个。退格删掉最后一个键。打过的词会记住，上屏后也给出下一个词的联想，和全键盘英文一样。没有词对得上这几个键时，拼音行显示每个键的第一个字母（`9675` 是 wmpj），空格照样上屏，不会打出数字；这样的猜测不记住。
- **1 键**：打词时是撇号，`366` `1` `8` 是 don't；没打字时打 `. , ? ! ' -`，快速连按换下一个。长按是 `: ; " ( ) @ & / * ~`，都是半角，原样打出（**输入法 → 拼音**（或英文、双拼）的「九键」一栏里 **按键长按** 改的 1 键不管这里）。
- **0**：没打字时打 0；打词时先上屏第一个候选，再打 0。
- **⇧**：在原来"重输"的位置。按一下下一个字母大写，快速按两下或长按是大写锁定，再按一下取消；句首会自己亮（和全键盘一样，要输入框要求）。
- **长按**数字键：和拼音的九键一样弹出 `A B C 2 a b c` 这一行。打词时选的字母**定进正在打的词**，那一位就是它，其余键照样猜；词库里没有的词（人名、新词）可以这样一个个字母长按出来，空格上屏后记住，下次按这几个键就有它。选数字直接上屏。连按打法里字母也是直接上屏。
- **左边一列**是英文标点 `, . ? ! ' - : ; @`，打词时点一个，先上屏词，再打出标点（`'` 例外：打词时是词里的撇号）。
- **连按**：在 **输入法 → 英文** 里把 **九键英文打法** 改成连按（英文的键盘是九键时才有这一项），就像老式手机：快速连按同一个键换成它的下一个字母，每个字母直接上屏，没有候选。网址、邮箱框，以及应用要求不提示的输入框里，总是连按（密码框里键盘自己换成全键盘英文，见下面）。
- 九键英文不能滑行。
- 英文的键盘选了九键，用地球键、空格长按等切到英文时，不管从哪里切过去都是九键英文；选全键盘时都是全键盘。在九键英文里点地球键，切到英文后面的那个输入法。
- 转屏、改设置让键盘重建时，九键英文还是九键英文。

## 14 键键盘

在 **输入法 → 拼音** 里把 **键盘** 选成「14 键」（或者 **⋯ → 键盘** 里选），拼音就用这个键盘（和讯飞的「拼音双键」一样）。两个字母一个键，键比全键盘大一倍：

```
 QW¹  ER²  TY³  UI⁴  OP⁵
 AS⁶  DF⁷  GH⁸  JK⁹  L⁰
 分词  ZX~  CV!  BN@  M?   ⌫
 符   123   ，   空格   。  🌐  ↵
```

- **点**一个键就是它上面的两个字母，输入法按整句判断你要的是哪个：BN UI GH AS OP → 你好。点在键的左半边或右半边，会优先读成那一边的字母（比如 nihao 点在 n、i、h、a、o 各自那一半，先出「你好」）；点在中间时两个字母一样。
- **编码行的音节条**：打字时编码行右边列出最前面还没定的几个键可能读成的音节（BN UI 可能是 ni、bu…），点一个就把它定下来，候选只按它找，音节条接着列下一段。只能从左往右一个一个定；点编码行左边的读音只是移光标。光标在末尾时退格先把最后定下的音节退回成键（最后定的先退）；光标不在末尾时退格照常删光标前的键。没打字时没有音节条。
- **分词**（ZX 左边）：打字时分开两个音节（`xi'an` 西安）；没打字时和全键盘的 `'` 一样，开着中文标点时打出 `‘’`。
- **滑动**：按 **按键 → 滑动** 的符号方向滑，打出键上的角标；打字时滑数字选第几个候选（滑 ER 选第二个），第三行的角标和全键盘的一样，开着中文标点时显示并打出中文的（`～ ！ @ ？`），滑它们先上屏第一个候选再打出符号；快捷键方向是这个键的快捷键（默认照键上的字母：CV 粘贴、ZX 撤销……），没有时等于点这个键。
- **长按**：弹出一行，左边是两个字母的大写，中间是角标，右边是小写（QW 是 `Q W 1 q w`），手指一开始在角标上；上面几行是这两个字母在全键盘上长按出的符号。选中的原样上屏，打字时先上屏第一个候选。
- **到英文**：14 键上没有中/英键（空格因此更宽）。按 🌐 换到输入法列表里的下一个，拼音后面是英文时就是英文；在英文上再按 🌐 接着往下换，回到拼音又是 14 键。长按 🌐 选输入法；实体键盘的 Shift、Ctrl+空格照旧。关掉了地球键时，要把 **空格键长按行为** 设成轮换或切换输入法，或者用实体键盘，才能到英文。
- 没有 ⇧，打大写字母先按 🌐 到英文。14 键不滑行，但能[笔画筛选](pinyin.md#笔画筛选)：打着拼音时在键上画一笔，从 GH 往下划一点是竖；这时滑数字选候选也成了画笔画，用点候选或空格选。键面的字母总是大写（**字母保持大写** 不管它）。
- 打字时按回车、或换到别的输入法，上屏的是编码行上显示的拼音；读不出来的键按每个键的第一个字母：只按 UI 再按回车，框里是 `u`。网址、邮箱框里也一样。
- 编码行默认浮在键盘上方（[设置 · 编码行](settings.md#大小与样式)），音节条和拼音在同一条里，换输入法时键盘高度不变。编码行嵌在键盘里时：用 14 键打拼音时，编码行从 18dp 变成 32dp，好点音节条；换到别的输入法（英文、五笔……）或拼音换成全键盘、九键又是 18dp，所以换输入法时键盘会高矮变一点（14dp）；键本身的高度不变，打字中也不变。横屏又把键盘调得很高、碰到占屏七成的上限时，整个键盘不变高，改成键区矮 14dp。
- 横屏分体时 14 键和九键一样整块靠一边；单手、悬浮照常。
- 用法和哪些功能用不了，见[拼音 · 14 键](pinyin.md#14-键)。
- **双拼 14 键**：在 **输入法 → 双拼** 里把 **键盘** 选成「14 键」，分组和上面一样，按方案每两键一个字；音节条、角标、滑动、长按也一样。微软的 `;` 是韵母，这个方案没有 14 键：选项不显示；选着 14 键时改成微软，键盘马上换成 18 键，设置也改成 18 键。

## 注音键盘

拼音的 **键盘** 里还有两种注音键盘，打的是拼音的词库，用注音符号输入；学到的词和拼音键盘分开记。

- **注音全键盘**：大千排列，和台湾键盘上印的位置一样（`1` ㄅ、`q` ㄆ、`a` ㄇ、`z` ㄈ……），数字行上有声调 ˊ ˇ ˋ ˙。
- **注音九键**：37 个符号分在 11 个键上，一行三个（和台湾元書输入法的注音九宫格一样）。左边一列是四个声调键 ˉ ˊ ˇ ˋ，各点一下；轻声 ˙ 在 ˉ 上长按或上滑。ㄖㄥㄩ 右边的键打字时是 **分词**，没打字时是逗号（长按选别的标点）。长按一个符号键单独选其中的符号。右边一列是删除和标点。
  注音九键上**多打声调更准**：声调既筛字，又标出一个字到哪里为止。实测聊天句子不打声调首选比九键拼音低约 3 个百分点，打声调反而高 1.5 个。
- **声调可打可不打**：不打按音节找词；打了声调，和这个声调对不上的字排到后面，但不会被去掉。注音全键盘和台湾习惯一样：声调在 3 ˇ、4 ˋ、6 ˊ、7 ˙，音节后面按空格就是一声，再按空格才选第一个候选。
- 正在打的字在码行上显示成注音和声调（`ㄋㄧˇ ㄏㄠˇ`），注音九键码行右边可选的音节也是注音（ㄋㄧ、ㄇㄧ）。ㄓ ㄔ ㄕ ㄖ ㄗ ㄘ ㄙ 既是声母也是整个音节（ㄓ 是 zhi），条上只出现一次：点了就定下这个声母，后面接着打韵母（ㄓ 再打 ㄨㄥ 是「中」），不接就是 zhi；按回车把注音原样上屏。没打字时点声调键什么也不打。
- **上滑快捷键**和别的键盘一样（**按键 → 滑动**）：注音全键盘按键位套用全键盘的，ㄇ（a 的位置）全选、ㄏ（c）复制、ㄌ（x）剪切、ㄒ（v）粘贴、ㄈ（z）撤销、ㄗ（y）重做；注音九键的组键默认没有快捷键，可以在 **按键 → 按键字符和快捷键** 的「注音九键」页给每个组键设（声调键和分词键没有）。注音键上没有键角小字，下滑当作点了这个键。空格、退格的上滑下滑也和别的键盘一样；注音九键的组键按下时和九键一样弹出预览。
- 第一次换到注音键盘时，如果拼音还是简体，会提示一次：注音一般配繁体字，可以在 **⋯** 里点 **简体** 切到繁体（按钮显示的是现在的状态）。已经是繁体就不提示。

## 18 键和九键双拼

在 **输入法 → 双拼** 里把 **键盘** 选成「18 键」或「九键」，双拼就用分组的键盘，每个方案都能用。拼音也能选「18 键」，分组一样（L; 键在拼音里就是 L），用法和下面的 18 键一样，按整句判断。

```
 Q¹  WE²  RT³  Y⁴  U⁵  IO⁶  P⁷
 A⁸  SD⁹  FG⁰  H(  JK)  L;-
 分词  Z~  XC!  V@  BN?  M:   ⌫
 符   123   ，   空格   。  🌐  ↵
```

- **18 键**：点一个键是它上面的一个或两个字母，按方案每两键一个字，输入法按整句判断。只有微软的键是 L;（也打 ing 的 `;`），别的方案用不到 `;`，这个键只写 L，长按也没有 `;` `:`。角标、滑动、长按和 [14 键](#14-键键盘)一样：滑出角标，打字时滑数字选第几个候选；长按是一行大写、角标、小写，`;` 的大写是 `:`。编码行右边有音节条，从左往右一个一个定；双拼里点声母就定下这个字的声母，下一个键算它的韵母。到英文和 14 键一样按 🌐。没有 ⇧，不滑行。
- **九键双拼**：2 键 ABC 到 9 键 WXYZ，微软的 `;` 在 5 键 JKL 上（别的方案用不到 `;`，5 键只写 JKL）；可能的音节在左边一列，点一个定下。1 键在打字时分开两个音节，没打字时是标点。空格宽一些；连按和自定义的按键字母不用，长按的符号和拼音的九键一样用 **输入法 → 拼音**（或英文、双拼）的「九键」一栏里 **按键长按** 设的（见[设置逐项说明](settings.md#九键)）。重码很多，见[双拼 · 18 键和九键](pinyin.md#18-键和九键)。
- 打字时按回车或换输入法，上屏的是编码行上显示的拼音，不会出现键的符号；网址、邮箱框里也一样。长按或符号面板里的 `;` 是标点：打了「你」再点 `;` 是「你；」。
- 编码行嵌在键盘里时，用 18 键或九键打双拼、用 18 键打拼音时，编码行和 14 键一样是 32dp；别的输入法里是 18dp。浮在键盘上方时，音节条在浮条里，键盘高度不变。横屏分体时两种键盘都整块靠一边；单手、悬浮照常。

## 数字键盘

点 **123** 打开：

```
 +   1   2   3   /
 -   4   5   6   空格
 *   7   8   9   ⌫
 ABC ,  !?#  0   =  .  ↵
```

**ABC** 回到字母键盘，**!?#** 打开符号面板。

数字、电话、日期时间框直接打开数字键盘，旁边的键按框要的换掉（数字的位置不变，用不上的键是空白的）：

| 框 | 左边一列 | 右上 | 底排 |
|---|---|---|---|
| 只说是数字的 | 和上面完整的一样 | | |
| 数字密码 | 空白 | 空白 | 空白 |
| 小数 / 能填负数 / 两样都能 | 空白 | 空白 | `.` / `-` / `-` 和 `.` |
| 电话 | `+ * #` | `-` | `( ) ,` |
| 日期、时间 | `- / :` | 空白 | `.` |

在这种框里点 ABC 再点 123，回到这个框的数字键盘；离开这个框回到原来的键盘。在普通框里点 123 是上面完整的数字键盘。这里的数字总是数字，用九键或编码里有数字的输入法时也一样（不当作九键的 ABC、DEF 键）：没在打字时直接打出；正在打字时和全拼一样，点 1–9、0 选对应的候选。长按、滑动字母键打出的数字也是这样。**空格** 也能左右滑动移动光标，和字母键盘一样（**按键 → 划动空格键以移动光标** 同样管这里）。

## 键盘上方的栏

没打字时，这一栏是工具栏；打字时显示候选。

### 工具栏

- 最左边的 **>**：展开工具栏，依次是：
  - **撤销**、**重做**
  - **文本编辑**（光标图标）：见下面的文本编辑面板
  - **剪贴板**
  - **快速输入**：和长按"符"一样，见[快速输入](other-input-methods.md#快速输入)。可选项，默认不在栏上：要用去**工具栏按钮**里勾上
  - **…**：更多，见"状态面板"
- 右边：**表情**按钮（语音版旁边还有**麦克风**，打开语音面板；密码框里没有），**⌄** 收起键盘。
- 这些按钮可以改：**设置 → 按键 → 工具栏按钮**。拖动排顺序，勾选的才显示；「以下一直显示在栏的右边」那一行上面的在展开的工具栏里，下面的不用展开就在栏的右边（右边放不下的，比如悬浮键盘窄，挪进展开的工具栏，按原来的顺序）。除了上面这些，状态面板里的 **简繁**（输入法有简繁切换时才出现）、**悬浮键盘**、**单手模式**（悬浮或分体时不出现）、**不用我的输入习惯**、**清掉最近**、**主题**、**输入法设置**、**键盘**（输入法有几种键盘可选时才出现，点了弹出和 … → 键盘 一样的列表） 也能放上来，点了和在面板里点一样，开着的按钮会亮起。最左边的菜单键和工具栏最后的 **…** 一直在，去不掉（设置和标点、全角等开关都在 … 里）。去掉 **⌄** 后，收起键盘用系统的返回，或长按候选栏右边的 ⌄。页面右上角菜单里有 **恢复默认**。
- **剪贴板提示**：刚复制了东西时（30 秒内），栏上会直接显示复制的内容，点一下就粘贴。
- **计算结果**：打一个算式再打 `=`，比如 `12*3.5=`，栏上显示"= 42"，点一下就把结果填在等号后面（想让结果替换整个算式，打开设置 **通用输入 → 点算式结果时替换整个算式**）；光标一移开就不显示了。屏幕上哪个键盘打都行（数字键盘、长按字母打出的数字和符号也算；实体键盘按的 `=` 不出结果），支持加减乘除（`+ - * /`，也认 `× ÷ x`）、括号、乘方 `^` 和百分号 `%`（`200*15%=` 得 30），小数按十进制算（`0.1+0.2=` 得 0.3）。密码框和无痕模式这类不记录输入的输入框里不算。
- 密码管理器等自动填充应用（Android 11 起）的建议，会显示在这一栏上，点一下就填入。
- 在密码框里，键盘自动换成英文（空格键上显示"英文"），字母直接打进去，不出候选；这一栏显示一排数字键，方便输入数字密码。离开密码框就回到原来的输入法。
- 应用要求不记录输入时（比如浏览器的无痕模式、密码框），这次输入不会被学习（见[这里不学](words.md#这里不学)）。本输入法自己的输入框（加词、改词、自定义词组、设置搜索）也当作这样的框：不学习，不记最近用过的表情和符号，也不读框里的字（所以那里不算算式结果，滑行出的词前面不自动加空格）。

### 候选

- 点一个候选上屏；候选栏可以左右滑看更多。
- 右边的 **⌄** 展开所有候选，以表格显示，可以上下翻。**长按 ⌄**（或在它上面往下滑）收起键盘：有候选或联想时栏上没有单独的收起键。
- **长按候选**：弹出菜单，见[拼音输入 · 长按候选](pinyin.md#长按候选)。手写的候选（最后一个字的几种可能）长按先是这个字的**字卡**（读音、例词、部首、笔画、拆字、笔顺，下面有 **上屏** 和 **复制**；拼音 `u` 拆字、笔画查字出的字也有），再是 **删除**（你的词）或 **忘掉学到的**（学到过才有）和 **屏蔽**，没有固定首位；联想词长按有 **不再联想**，能屏蔽的词还有 **屏蔽**（码表的联想里，单字和拼音里没有的词只能不再联想）。见[其他输入方式](other-input-methods.md)。

## 文本编辑面板

工具栏的光标图标打开，适合精确移动光标和选择文字：

- **↑ ↓ ← →**：移动光标。
- **选择**：打开后再按方向键就是扩大选区。
- **|<**、**>|**：移到整个输入框的开头、结尾（不只是当前这一行；终端这类直接收按键的输入框里是行首、行尾）。
- **全选**、**剪切**（有选区时）、**复制**、**粘贴**、**⌫**。
- **复制**后选择就关了：光标停在选中部分的末尾，再按 **>|** 只移动光标，**粘贴** 插在光标处。**剪切** 也一样不留选区。有选中内容时，复制或剪切后键盘上方会短暂提示「已复制」「已剪切」（字符隐藏的密码框里不提示，应用不让从那里复制；显示明文的密码框照常提示）。
- 右上角是剪贴板。左上角 **←** 返回键盘。

## 剪贴板

开启"记录剪贴板历史"后（默认开启），复制过的内容会出现在剪贴板面板里：

- 点一条：粘贴，并回到键盘（**剪贴板与表情** 里的"粘贴后回到键盘"关掉时留在剪贴板面板）。点过的条目在关掉剪贴板面板后移到最前（有置顶条目时排在置顶的下面；面板开着时不挪，免得手指下换了一条；连点几条，最后点的排最前），和刚复制的一样算最近用过；置顶的条目点了位置不变。条目按最近用过的先后排，超过上限时先清掉最久没用过的。
- 长按一条：**置顶**（置顶的不会被自动清掉）/ 取消置顶、**切词**、**编辑**、**分享**、**删除**。
- **切词**：把这一条切成一块块的格子，点一块选中（再点取消），选中的块按点的先后显示 1、2、3；点栏上的 **上屏** 按这个顺序拼起来输入并回到键盘，点 **重选** 清空所选，什么都没选时 **上屏** 不能点。按住一块横着滑，经过的块一起选中（按原文顺序排在已选的后面）；从已选的块开始滑就一起取消；往回滑，退出的块恢复原样；往上或往下拖到面板边缘会自动滚动（沿最上、最下一行横着滑不会）。拼接时，原文里紧挨着的两块保留原文中间的内容（比如空格），不挨着的两块两边都是英文字母或数字时加一个空格，否则直接相连。邮箱切成名字、`@`、域名；链接（只认英文字母的网址）切成 `https://`、网址、每一段 `/路径`、`?` 后的参数、`#` 后的部分；中文按词切（「北京大学」切成「北京」「大学」）；英文按单词切，数字、标点、表情各成一块（组合表情、国旗不会被拆开）；空格不算。很长的条目只切前 5000 个字，末尾会注明。显示为圆点的敏感条目没有这一项。左上角的返回回到剪贴板列表。
- 右上角的垃圾桶：删除所有未置顶的条目（会先确认）；只剩置顶的条目时，改为问要不要删除所有置顶条目。删除（滑掉一条、长按删除、垃圾桶）后键盘上方提示「已删除 N 项」，6 秒内点 **撤销** 能找回；提示还在时接着删，数目累加，撤销时一起找回。
- 密码等敏感内容（应用标为敏感的）显示为圆点。
- 复制的链接存进历史前会去掉跟踪参数（比如 `utm_source`），系统剪贴板里的原样不动。

最多保留多少条（或无上限）、是否显示剪贴板提示等，在 **剪贴板与表情** 设置里调。

点工具栏右边的笑脸打开。上面的标签是分类（最近使用、笑脸、人物、动物与自然、食物与饮料、旅行与地点、活动、物品、符号、旗帜），
整个列表可以上下滑。长按一个表情选肤色，默认肤色在 **剪贴板与表情** 设置里选；系统字体不支持的表情不显示。
表情和分类按 Unicode 的表情列表（Emoji 17.0）排；打字时的[表情候选](pinyin.md#表情候选)也来自同一份数据。

点下面的**放大镜**按拼音搜表情：打全拼（`xiao` 找“笑”）、开头几个音节（`xiaol` 找“笑脸”）或每个字的首字母（`dz` 找“点赞”），
上面一排就列出对应的表情，点一个打出来，也会记进最近使用。拼音删完后再按退格，删的是输入框里的字。**返回**回到表情列表。

## 提示条

键盘做了一件结果不在键盘上的事，或者没做成时，会弹出一个小提示条说一声：复制、剪切、删了剪贴板条目、长按候选删词或屏蔽、清掉最近、在 **⋯** 里关掉或打开"不用我的输入习惯"（「已不用我的输入习惯，在 ⋯ 里恢复」「已恢复用我的输入习惯」）、词库读不出来等。键盘本身看得出的变化（单手、悬浮、换主题、换输入法）不提示。

- 从键盘边上滑出来、淡入，收起时滑回键盘、淡出。键盘在底部时在键盘上方（长按候选的提示在没有候选时盖在候选栏上，见[长按候选](pinyin.md)）；悬浮时在键盘朝屏幕中间的那一侧：键盘贴着屏幕顶就在它下面，贴着左边就在它右边，贴着右边就在左边，其余都在上面；那一边放不下就换一边。
- 能撤销的带 **撤销** 按钮，停 6 秒；只说一句的停 2 秒（开着读屏等无障碍服务时按系统建议停得更久）。点提示条就收起（不撤销；点在 **撤销** 旁边那条细线上也算撤销），接着打字也收起，只有说"没做成"的（比如词库读不出来）不因打字收起，并且和带撤销的一样停 6 秒。
- 同一时间只有一条：新的提示在原来的框里直接换字，旧的那件事就此作数。
- 颜色跟主题走：底色是主题的弹出框颜色，**撤销** 是强调色的文字按钮（强调色在底色上看不清时往文字颜色靠，保证看得清），和说明之间隔一条细线。
- 关掉动画（设置 **外观** 里的 **禁用动画**，或系统开发者选项里的"移除动画"）时直接出现、直接消失。

## 实体键盘

接上蓝牙或 USB 键盘时，一按键盘上的字，屏幕键盘就收起，正在打的拼音和候选显示在光标附近的小窗里（可以在 **实体键盘** 设置里调）。

按键和全键盘一样：字母打拼音，空格和数字选候选，回车原样上屏，Esc 取消正在打的字。拼音选了 [14 键](#14-键键盘) 时，实体键盘仍按全拼打；打字中途点屏幕上的键，之前打的字母原样留下，从屏幕键盘接着打。双拼选了 [18 键或九键](#18-键和九键双拼) 时也一样：实体键盘按全键盘双拼打（微软的 `;` 是 ing），在屏幕键盘打字中途按实体键盘的字母，前面打的按编码行上的拼音留下；数字、空格、Esc 照常对屏幕键盘打的字起作用。

| 按键 | 作用 |
|---|---|
| **单按 Shift**（左右都行，按下马上松开） | 中文和英文之间切换：中文输入法切到英文，英文切回刚才那个中文输入法。正在打的拼音按原样上屏。按住 Shift 打大写字母不会切换。 |
| **Ctrl + 空格** | 同上，中英切换。没有可切换的输入法时（比如只添加了英文），这个组合键照常交给应用。 |
| **Ctrl + Shift** | 轮流切换已添加的输入法（拼音、英文、五笔……）。用实体键盘时跳过手写和九键，它们是给触屏用的。按住 Ctrl 或 Shift 中的一个不放，每轻按一下另一个，就再往下切一个。 |
| **`-` / `=`** | 打字时往前、往后翻候选页（也可以用 PageUp / PageDown）。没在打字时照常打出 `-` 和 `=`。 |

切换后光标旁会短暂显示输入法的名字（"拼""En""五"……），状态栏也有图标。这三个快捷键可以在设置里一起关掉（**实体键盘快捷键**，见[设置](settings.md)）。

下面这些快捷键一直有效，不受这个开关影响。标点和简繁只在中文输入法里起作用：

| 按键 | 作用 |
|---|---|
| **Ctrl + .** | 中文标点和英文标点之间切换，光标旁提示切到了哪种。 |
| **Ctrl + Shift + F** | 简体和繁體之间切换（之后打出的字和候选都转成繁體），光标旁有提示。 |
| **Super + `** 或 **Super + ;** | 进入快速输入（和长按「符」一样）：打关键词，用数字选候选。 |
| **Ctrl + Alt + Shift + U** | 进入 Unicode 输入（和长按「123」一样）：打字符的英文名字或 `U+编码` 找字符，用 Alt + 数字选。 |
| **Ctrl + Shift + U** | 直接打十六进制编码：打 `4f60` 再按空格或回车，打出「你」。 |

在快速输入和 Unicode 输入的候选里，↑ / ↓ 翻页，Tab / Shift + Tab 移动高亮，Esc 退出。

**在手写或九键里按实体键盘**：手写和九键是给触屏用的，实体键盘上的字改用拼音来打（列表里的全拼或双拼，哪个在前用哪个；都没添加时用列表里第一个能用键盘打的中文输入法），比如手写时按 `ni` 空格得到"你"。等屏幕键盘回来时，又是原来的手写或九键。

**想用屏幕键盘**（比如要发表情、手写）：点光标旁小窗右端的键盘图标，屏幕键盘就回来；再按实体键盘上的字，它又收起。没在打字时小窗只剩这个图标，停在光标右边。有的应用不告诉输入法光标在哪里，在这些应用里这个图标放在屏幕右上角。图标可以按住拖到别处：不告诉光标的应用里拖到哪里，以后（换输入框、重启后）都放在那里；在一般输入框里拖动只管当前这个框，换一个框它又回到光标旁。在一般应用的输入框里，点一下输入框也能叫回屏幕键盘；Chrome 等浏览器里的网页输入框点了不会通知输入法，要用这个图标。拔掉或关掉实体键盘后，屏幕键盘自动回来。

## 振动和按键音

默认跟随系统设置。在 **声音与振动** 设置里可以单独打开或关掉，并选振动强度（轻、中、强）和按键音音量（小、中、大）。
