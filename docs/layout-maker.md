# 用网页做键盘布局

0.6.1 起可以换掉 App 自带的字母键盘、数字键盘和符号面板，换成自己排的：比如把 18 键的 H 和 JK 并成一个键做成 17 键，26 键换成法语的 AZERTY，或者一块键更大的数字键盘。布局在网页上做：键盘布局页 https://sraw.github.io/youmo-ime/theme-maker/layout/ （主题制作页顶栏的 **键盘布局** 也能进）。做好存成 `.layout` 文件，导入 App（[设置 · 布局](settings.md#布局)）。

页面在浏览器里运行，什么都不上传。手机、电脑都能用：电脑上拖键换位置、拖边缘改宽；手机上同样的事在 **键** 页里用按钮和滑块做（也可以长按 0.3 秒再拖）。

布局文件每个元素、每个属性的说明在[布局格式参考](layout-format.md)；这一页讲怎么用这个页面。

## 开始

打开页面时会弹出 **新建键盘布局**（之后在 **文件 › 新建…** 再打开）：

- **从内置键盘开始**：26 键、14 键、18 键、九键、数字键盘、符号面板，照 App 现在的样子起步。
- **从示例开始**：三个做好的布局，照着改。
  - **17 键**：18 键上把 H 和 JK 并成一个键（HJK），其余照旧。打拼音用。
  - **AZERTY**：法语的字母排法（A Z E R T Y 在第一行，M 在第二行末尾，W X C V B N 在第三行），N 后面多一个 `'` 键（打拼音时是分词，英文里打 `'`）。拼音、双拼、英文、码表都能用：双拼方案要 `;` 键时、码表要 `;` 或 `*` 键时，这两个键出现在 `'` 后面。
  - **大按键数字键盘**：一行四个键，数字更大；⌫ 在右上，回车竖着占两行，左下是 **符**、**返回**。管点 123 进的数字键盘、只有数字的输入框和带小数的输入框，别的输入框照旧用 App 自带的。
- **打开文件…**：一个 `.layout` 文件，自己存的或别人给的，接着改。

从内置键盘或示例开始时要给它起 **名字**（App 里显示「名字（自定义）」，最多 24 个字）和 **id**（布局的身份：小写字母、数字和连字符，不能和 App 自带的键盘同名）。同一个 id 再导入 App 是更新，不是多一块；改别人的布局想留两份的，换个 id。从示例开始时页面先填好「我的 17 键」「my-k17」这样的，示例自己的作者、版本、说明不带过来。

上次没做完的，下次打开页面会问要不要 **恢复** 草稿。草稿只存在这个浏览器里；无痕窗口里没有草稿。

## 预览

- 上面（电脑上是左边）是预览，按顶栏选的 **主题** 画（App 自带的主题，**浅色 / 深色** 切换）。
- 预览下面的环境栏：**设备**（几种常见的屏幕宽度）和 **方向**，由这两样算出按竖屏还是横屏排（宽屏手机竖着拿也按横屏排，和 App 一样，栏里显示结果）；**形态**（正常、紧凑、悬浮、单手、分体）；**输入法**（拼音、双拼各方案、英文、码表：影响写了 `when=` 的键，比如 AZERTY 的 `;`、`*`）；**Shift**；**输入框**（普通、网址、邮箱）；数字键盘还有 **数字键盘**（切换它管的几种输入框）；**上滑图标**、**下滑图标** 画在哪。
- 点一个键选中它，Shift 或 Ctrl 点多选；预览有焦点时方向键换键，Delete 删除选中的键，Esc 不选。

## 编辑

下面的标签页逐项改，每一步都能 **撤销 / 重做**（顶栏的 ↶ ↷，或 Ctrl+Z / Ctrl+Shift+Z）：

| 标签页 | 改什么 |
|---|---|
| 键 | 加键（字母键、分组键、打一段文字的字符键、功能键、空位），删键，左移右移、移到上一行下一行；显示的字（文字，或随 Shift 大小写、按标点转换）、图标、读屏念什么（图标键必填）、宽度（单位或占满）、跨几行、种类（字母键、功能键、空格、回车：主题按它画）、分组字母；点按、长按、上滑、下滑、双击各做什么。选两个以上的字母键可以 **合并成一个分组键**（键盘随之变成分组键盘，只有拼音能用） |
| 行 | 换行序（拖 ☰ 或 ↑↓）、加行、删行、行高、缩进；26 键的行可以设成分体时分成两半 |
| 整块 | 名字、底稿（从哪块 App 自带的键盘改来）、列数、分体时怎么排（分成两半、放在一边）；数字键盘还有它管哪几种输入框 |
| 信息 | 作者、版本、许可（如 CC-BY-4.0）、说明；最低 App 版本保存时自动写 |
| 源码 | 布局文件全文，改完马上重读；表单不管的写法（比如 `when=` 条件）在这里写，原样保留 |

几点要知道的：

- **按键名**：从底稿留下的键保留 App 的按键名（`full/a`、`g18/we`、`num/5`），长按、上下滑、角标和 App 自带的同名键一样，用户在 App 的 **按键 → 按键字符和快捷键** 里改，改一处两块键盘都变；这些键的长按、滑动在页面上只读。新加的键叫「布局 id/键 id」，这里写的长按列表、上滑、角标是它的默认值，用户在 App 里改过的以用户的为准。
- **底行**：14 键、18 键（和 17 键示例）的最下面一行引用 App 的底行，App 以后改底行（比如加键）这里跟着变。动了底行的键时页面问一次 **改成自己的**：同意就把底行抄进这块布局，以后不跟着 App 变。
- **分体**：26 键横屏分体时，标了「分成两半」的行要有 9 或 10 个键（`split="after"` 的键和空位不算），不然分体时那一行按比例缩小。AZERTY 第三行就是这样凑的。

## 问题和保存

页面下方的 **问题** 列出布局的错误和警告（App 导入时同一套检查），点一条跳到那一行。

**文件 › 保存 .layout** 之前再检查一遍：

- 有 **错误** 时不保存，App 会拒收（缺必需的键，比如字母键盘缺字母、数字键盘缺 0–9 或 ⌫；某种形态或输入法下排不下；id 不合规……）。
- 只有 **警告** 时列出来，点 **仍然保存** 照样保存（比如键太窄、新键没写名字、预览主题下某个键什么都不显示）。

保存下来是 `<名字>.layout`。在手机上：打开幽默输入法 → 外观 → 布局 → ＋ → **导入布局文件**，选这个文件；确认后在 **布局** 页或输入法的 **键盘** 设置里选它（数字键盘、符号面板是全局一个选择，见[设置 · 布局](settings.md#布局)）。

## 和主题的关系

布局只管键怎么排，样子由主题定：主题对 App 自带键盘写的样式，对按键名、种类、角色写的样式，在自己的布局上照样生效；主题也可以按布局的 id 专门写（`k17/hjk`）。想看一个主题在自己的布局上是什么样子，在[主题制作页](theme-maker.md)环境栏的 **键盘** 里选 **打开 .layout…**。
