## 输入法

列出你在用的输入法，顺序就是在键盘上按地球键切换的顺序。

- 拖动左边的 **═** 调整顺序；右上角的笔进入编辑，可以删除；右下角 **+** 添加。
- 点一行右边的齿轮进入这个输入法的设置。
- 默认有拼音和英文；可以添加五笔、二笔、仓颉、自然码、双拼、五笔拼音、手写。九键不是单独的输入法，是拼音、双拼、英文的一种 **键盘**（见[换键盘](keyboard.md#换键盘)）。

每个输入法的设置页只有它自己的选项；最上面一行写着"通用输入设置"，点它进入[通用输入](#通用输入)，联想、表情、滑行、档位这些各输入法共用的设置都在那里。

### 拼音

| 选项 | 意思 |
|---|---|
| **键盘**（全键盘） | 屏幕上打拼音用的键盘：**全键盘**（26 键）、**18 键**（一个或两个字母一个键，见[18 键和九键双拼](keyboard.md#18-键和九键双拼)）、**14 键**（两个字母一个键，键大好按，见[14 键键盘](keyboard.md#14-键键盘)）或 **九键**（九宫格，见[九键键盘](keyboard.md#九键键盘)）。打字时也能在工具栏 **⋯ → 键盘** 里换。改了回到输入框马上生效。实体键盘不管这里选什么，都按全拼打。编码行嵌在键盘里时（[编码行](#大小与样式)），用 18 键或 14 键打拼音时编码行从 18dp 变成 32dp 高（放音节条；九键的音节在自己左边那一列）；别的输入法仍是 18dp，所以换输入法时键盘高度会变一点。编码行浮在键盘上方时键盘高度不变，只是浮条高一点。 |
| **九键**（一栏） | **键盘** 选九键时，**键盘** 下面就多出一栏「九键」：连按选字母、按键字母、按键长按，见[九键](#九键)；换回别的键盘这一栏马上不见。 |
| **拆字**（开） | 先按 u 再打字的各部分的拼音，打出不会读的字：`uniuniuniu` 犇。只有全拼有。见[拆字](pinyin.md#拆字)。不适用：拼音 · 九键、拼音 · 18 键、拼音 · 14 键（实体键盘照常有）。 |
| **中英混输**（开） | 拼音里直接打英文单词，比如 iphone 出 iPhone。只有全拼有。不适用：拼音 · 九键、拼音 · 18 键、拼音 · 14 键（实体键盘照常有）。 |

### 双拼

| 选项 | 意思 |
|---|---|
| **双拼方案**（新装是小鹤；从 0.4 升级的、没改过的是自然码） | 用哪种双拼：自然码、微软、小鹤。0.4 的紫光、智能ABC、中文之星、拼音加加、国标不再提供，升级时改成小鹤，并提示一次。 |
| **键盘**（全键盘） | 屏幕上打双拼用的键盘：**全键盘**（26 键）、**18 键**（有的键两个字母，见[双拼 · 18 键和九键](pinyin.md#18-键和九键)）、**14 键**（两个字母一个键）或 **九键**（九宫格，重码很多，要多选几次）。微软没有 14 键（它的 `;` 是韵母）：选项不显示；选着 14 键时改成微软，键盘马上换成 18 键，设置也改成 18 键（换回别的方案仍是 18 键）；其他键盘每个方案都能用。打字时也能在工具栏 **⋯ → 键盘** 里换。改了回到输入框马上生效。实体键盘不管这里选什么，都按全键盘双拼打。编码行嵌在键盘里时，用 18 键、14 键或九键打双拼时编码行从 18dp 变成 32dp 高（放音节条；九键的音节在自己左边那一列，123 页上才在编码行）；别的输入法仍是 18dp。编码行浮在键盘上方时键盘高度不变，只是浮条高一点。 |
| **九键**（一栏） | **键盘** 选九键时才有，只有 **按键长按**（九键双拼的字母按方案定，也不连按），见[九键](#九键)。 |

### 五笔等码表

五笔、二笔、仓颉、自然码、五笔拼音各有一页，选项大多相同，默认值不同：

| 选项 | 意思 |
|---|---|
| **只有一个候选时直接上屏** | 编码打满且只有一个字时直接上屏，不用按空格；再按下一个键打不出东西时，也直接上屏第一个候选。 |
| **显示编码提示** | 在每个候选旁显示还要按的键，方便学编码。 |
| **调频**（新装时关） | 码表里原有的字词按你的选择调整顺序：选一次排到没用过的前面，连着选两次排第一；不看前面打的字，只数码表里的选择，不影响拼音。重码照旧按前面打的内容排。关着时码表原有的字词位置不变（你固定的除外），适合靠位置盲打的人。升级前用过的码表保持原来的设置，没用过的也是关。五笔、五笔拼音的一、二级简码不受影响。 |
| **恢复码表顺序** | 清掉调频学到的顺序，回到码表本来的顺序。"清空学到的"默认不清它。 |
| **字根键盘**（只有仓颉，开） | 字母键上显示字根（日月金…），字母小字在角上；编码栏也显示字根。 |
| **按键显示**（只有五笔、五笔拼音，字母） | **字母**；**键名**（王土大木工…）；**全部字根**：每个键显示 86 版的全部字根，长按一个键弹出它的字根大字；这时字根从键的左上角排满整个键，字母键上不画快捷键（快捷键标记会压在字根上；快捷键照样能滑）。**键盘高度** 是 **紧凑** 时键太矮，全部字根照 **键名** 显示（快捷键标记、长按也和键名一样），离开紧凑又是全部字根，设置不变；选项上写着这一句。 |

各码表的默认值：

| 码表 | 编码提示 | 调频 |
|---|---|---|
| 五笔 | 开 | 关 |
| 五笔拼音 | 开 | 关 |
| 二笔 | 关 | 关 |
| 自然码 | 开 | 关 |
| 仓颉 | 关 | 关 |

"只有一个候选时直接上屏"默认都开。以前的"自动造词"两项去掉了：码表里一个字一个字打的不再自动成词，名字、术语用拼音反查打两次，或在用户词库里手动加；以前造出的词都还在，算你的词。

### 手写

怎么写见[手写](other-input-methods.md#手写)。

| 选项 | 意思 |
|---|---|
| **停笔多久算写完一个字**（中） | 停笔超过这个时间，就算写完一个字、开始写下一个。很短（0.3 秒）/ 短（0.5 秒）/ 中（0.7 秒）/ 长（1 秒）/ 很长（1.5 秒）：写得快调短，写一个字中间常停顿的调长。 |

### 英文

| 选项 | 意思 |
|---|---|
| **键盘**（全键盘） | 屏幕上打英文用的键盘：**全键盘** 或 **九键**（见[九键英文](keyboard.md#九键英文)），不跟拼音的走。打字时也能在工具栏 **⋯ → 键盘** 里换。实体键盘仍按字母打。 |
| **九键**（一栏） | **键盘** 选九键时，**键盘** 下面多出一栏「九键」：先是 **九键英文打法**，再是和拼音共用的连按选字母、按键字母、按键长按，见[九键](#九键)。 |
| **九键英文打法**（预测） | 预测：每个键可以是它的任一个字母，输入法猜出整个词（4663 是 good、home、gone）；连按：快速连按同一个键是它的下一个字母，直接上屏。网址、邮箱和不要提示的输入框里总是连按（密码框里键盘自己换成全键盘英文）；关掉英文的 **单词提示** 时也是连按。在「九键」一栏里，英文的 **键盘** 是九键时才有，见[九键英文](keyboard.md#九键英文)。 |
| **单词提示**（开） | 显示以已打字母开头的单词，以及拼错时的改正；关闭后按键直接上屏。 |
| **句首自动大写**（开） | 在句子开头自动打开 Shift（应用的输入框要求时）。 |
| **英文词库** | 打过或添加的英文词，打的时候会给出；添加的词，和被自动改过一次、你又改回去的词，不会再被改。可以搜索、添加、删除；不再自动改的词在这里能看到、能恢复。用户词库页里也有一行通到这一页。 |

### 九键

拼音、英文、双拼的 **键盘** 选九键时，设置页里 **键盘** 下面多出的一栏「九键」。拼音和英文的九键共用同一份设置，在哪一页改都一样；九键双拼只有 **按键长按**。

| 选项 | 意思 |
|---|---|
| **连按选字母**（关） | 打开后，快速连按同一个键就是它的第几个字母（按两下是第二个，再按下去轮回第一个），不再当成几个键；按一下仍由输入法判断是哪个字母；关着时每按一次都是一个键，输入法按上下文判断。关 / 快（0.4 秒）/ 中（0.6 秒）/ 慢（0.9 秒）：两次按键间隔在这个时间以内才算连按。1 键连按换标点也按这个设置，关掉就不换（九键英文的 1 键和连按打法总是连按，关着时按 0.6 秒算）。 |
| **按键字母** | 自定义每个数字键打出哪些字母，每键最多五个，可以重复。不在任何键上的字母，含它的拼音就打不出来。 |
| **按键长按** | 自定义长按 1–9 时多出的符号，每键最多十个，用空格分开，单个的数字或字母不能填（2–9 的长按已经有这个键的数字和大小写字母）。2–9 的符号排在数字和字母上面，默认是这个键几个字母在全键盘上的角标，开着中文标点时打出中文的；1 键的标点原样打出。清空就是这个键不加符号；改过的键可以点「恢复此键默认」。和全键盘的 **按键字符** 互不影响。 |

## 通用输入

各输入法共用的设置，改一次所有输入法都生效。从首页进，也可以从任何一个输入法设置页最上面那行"通用输入设置"进。某一项对哪些输入法不起作用，它的说明最后一句会写"不适用：……"。

### 所有输入法

| 选项 | 意思 |
|---|---|
| **滑行输入**（关） | 手指不离开键盘，依次划过一个词的键即可输入：英文、全拼、双拼划字母，九键划字母所在的数字键，码表划编码；拼音 18 键和 14 键、双拼 18 键和 14 键、九键双拼上没有。见[英文](other-input-methods.md#英文)、[拼音](pinyin.md#滑行输入)、[码表](other-input-methods.md#码表输入法五笔仓颉自然码二笔五笔拼音)。<br>和 **笔画筛选** 都是在键上划，只能开一个：打开这个，笔画筛选当场跟着关掉。网址、邮箱和密码框里不滑行：这些框里的内容不是词，滑行只会猜出错的词，密码框里也看不见滑错了什么。0.4 里打开过的，升级后还开着。不适用：手写。 |
| **笔画筛选**（关） | 打了拼音（全拼、双拼，各种键盘都行）后在键盘上画一笔，候选里只留第一个字这样起笔的，见[拼音](pinyin.md#笔画筛选)。<br>和 **滑行输入** 只能开一个：打开这个，滑行输入当场跟着关掉，所以英文、码表这时不滑行。网址、邮箱和密码框里不能画。不适用：各个码表、手写、英文。 |
| **括号和引号成对输入，光标停在中间**（开） | 见[括号成对](keyboard.md#括号成对)。 |
| **点算式结果时替换整个算式**（关） | 打完算式和 `=` 后，栏上会显示结果（见[计算结果](keyboard.md#工具栏)）。关着时点结果，结果接在等号后面（`1+2*2=5`）；打开后点结果，整个算式连同等号换成结果（`5`）。 |
| **网址和邮箱** | 网址框、邮箱框里栏上给的建议（见[网址和邮箱输入框](keyboard.md#网址和邮箱输入框)），一页，见下面的[网址和邮箱](#网址和邮箱)。 |

#### 网址和邮箱

| 选项 | 意思 |
|---|---|
| **邮箱后缀** | 邮箱框里给的后缀，默认 qq.com、163.com、gmail.com、outlook.com、126.com、foxmail.com、icloud.com。点 + 添加（打 `@Work.CN` 或 `work.cn` 都存成 work.cn，不是域名的、已有的加不进去），向左滑删掉，拖动调顺序，菜单里「重置」恢复默认。 |
| **网址后缀** | 网址框里主机名后面给的后缀，默认 .com、.cn、.com.cn、.net、.org；打 `io` 存成 .io。改法同上。 |
| **记住打过的邮箱地址**（开） | 在邮箱框里打的完整地址记下来，下次按开头给出，排在后缀前面。最多记 50 个，最近用的在前。无痕框、密码框里不记。关掉后不给也不记，已经记住的留着，再打开就回来；要删掉用下面的「全部清空」。 |
| **记住的邮箱地址** | 点一个删掉它；「全部清空」删掉所有的。后缀用了几次不跟着清，它只管排序。 |

两个列表的顺序是建议的顺序，用得多的再往前排。这些都在「备份全部」里；后缀用了几次和记住的地址也跟着学习备份走（自动备份、复制的备份都带上），恢复时和手机上已有的合在一起：次数取大的，地址两边都留、手机上的排前，最多 50 个；「退回恢复前」把它们也退回去。从「备份全部」的文件恢复也一样合并（文件里带着学习备份时）。0.4 做的学习备份里没有这些，恢复时不动手机上的。「全部清空」以后，正在打的框里原来的内容也不再记。

### 中文输入法

| 选项 | 意思 |
|---|---|
| **联想下一个词**（开） | 打完（写完）一个词，接着给出可能要打的下一个词。|
| **表情候选**（开） | 打的词有对应的表情时一并给出：哈哈 😄、点赞 👍；排在第三个候选起，码表里编码只有这个词、自己上屏时出在联想最前，点了替换这个词。见[表情候选](pinyin.md#表情候选)。不适用：手写。 |
| **自带的日期时间**（开） | 打出"日期""时间""星期"这几个词时，后面给出今天的日期、现在的时间、星期几（排法和表情一样）；全拼、九键、拼音 14 键里打 `rq`、`sj`、`xq` 也出。关掉后这几条都不出，你自己加的自定义短语不受影响。不适用：手写。见[自带的日期时间](words.md)。 |
| **性能档位**（高档） | 低档：只按词频和搭配，最省电。中档：每次按键（手写是每写一笔）按整句通顺程度重排。高档：停顿时（手写是一个字写完时）再用大模型精挑首选，最准。档位越高越准，也越费电。|
| **候选词注音**（关闭） | 在每个中文候选词的字上标出读音和声调：**拼音** 标在字的上方（候选栏为此高一行），**注音符号** 竖排在字的右边（候选变宽，栏高不变）。各中文输入法都标，码表和手写也标；读音按你打的拼音定，码表按词典里最常见的读法；手写的单字标全部读音（多音字标前两个加「…」，前面写的字和它成词时那个读音在前，见[手写](other-input-methods.md#手写)），手写键盘上的 **注** 键也能开关这一项。一、不标本调（yī、bù）；也不标轻声，每个字都标它自己的声调（东西 dōng xī、桌子 zhuō zǐ），只有「的、吗、们」这类本来就读轻声的字标轻声。关闭时，常读错的词、拆字、笔画查字的读音提示也标在字的上方，样子和拼音注音一样，只是字小一些、放在候选栏原有的高度里，栏不变高；打开时这些提示被注音代替，只有一个字有几个读音的提示（如拆字出的多音字「行」`xing/hang`）仍留在候选右边。码表的编码提示一直在候选旁边。英文不标。 |
| **中文标点** | 打中文时每个英文标点键对应哪个中文标点，可以编辑。"交替"指连按时轮换（比如引号左右交替），"可选"指同一个键还可以选的其他标点。|

### 拼音（全拼、双拼、九键）

| 选项 | 意思 |
|---|---|
| **纠正错拼和按偏的键**（开） | 比如把 gn 当成 ng，或按到了旁边的键。见[纠错](pinyin.md#纠错)。不适用：拼音 · 九键、拼音 · 18 键、拼音 · 14 键、双拼 · 九键。 |
| **模糊音**（未开启） | 勾选分不清的音：u↔v、an↔ang、en↔eng、ian↔iang、in↔ing、u↔ou、uan↔uang、c↔ch、f↔h、l↔n、l↔r、s↔sh、z↔zh。u↔v 对拼音 · 九键和双拼 · 九键不起作用（u、v 在同一个键上），勾选框里也这样注明。见[模糊音](pinyin.md#模糊音)。 |

### 主题

点一个主题使用。有浅色、深色两版的内置主题（Material、Pixel、Nord、动态取色）是一张卡片，缩略图右上角的 **浅**/**深** 点一下换成另一版，点卡片用的就是显示的那一版；正在用的、夜间模式两个主题选的那一版显示在卡片上，标记也只在那一版显示时出现。选 **亮色模式主题**、**暗色模式主题** 时卡片先显示对应的那一版。从老版本升级，用的内置主题自动换成对应的那一版，样子不变。App 里能列出、使用、导入、导出和删除主题；这一版不能做主题，也不能改主题，以后的版本再提供。**新增主题** 直接打开文件选择，导入别人导出的主题文件 `.theme`（0.5.0 及更早版本导出的 `.zip` 主题改名成 `.theme` 再导入）。缩略图画出主题的底色或主题图、按键的颜色和形状（分块还是平铺、圆角、间距、边框）；4.0 主题的缩略图按旧的画法画，只有它的颜色和主题图，不是它自己的按键形状。

自己加的主题（导入的，以及更早版本用图片做的、复制的内置主题）：长按选 **信息** 看作者、版本、许可和主题格式，选 **导出** 存成文件，或 **删除**（问一次，主题图、按键图片、字体一起删掉）。内置的动态取色主题也能长按导出，导出的是它此刻的一份固定颜色的副本（连同下面说的从老版本带来的按键样式），导入后不再跟壁纸变。以前做的主题（用图片做的、复制的内置主题）照常能用。导入和已有主题同名的，替换它；导入 4.0 主题时和自己的旧主题同名，也替换那个旧主题（用着它的地方改用这个 4.0 主题），反过来导入和 4.0 主题同名的旧主题会被拒绝。开着 **跟随系统夜间模式**（默认开）时点主题不会换，而是提示不能手动更换，点 **禁用它** 就关掉跟随，同时换上点的那个主题。

导出的主题是一个 `.theme` 主题文件（里面是 zip）：主题的设置和它用到的所有文件（主题图、按键图片、字体）。这一版起导出的都是 **4.0 格式** 的主题（最外层一个 `theme.xml`，还可以带预览图、图标和 `layouts/` 里的布局），自己的旧主题导出时转成 4.0，样子不变；动态取色主题导出的是此刻的颜色。导入 4.0 主题时先显示它的预览图、名字、作者、版本、许可，以及要注意的地方（这一版不认识、会忽略的内容，按键上的字可能看不清），点 **导入** 才装上，点 **取消** 什么都不留。有浅色、深色两版的 4.0 主题和内置主题一样是一张卡片。4.0 主题里的图标这一版先存着，还不画在键上。导入只认 `.theme`：选别的文件会提示只能导入主题文件，不导入。0.5.0 及更早版本导出的 `.zip` 主题，改名成 `.theme` 再导入。这一版起主题文件是新的格式（3.0）：更早版本的幽默输入法导入不了这一版导出的主题（报格式版本不认识）；用更早的版本恢复这一版的备份，这些主题也看不到，换回默认主题。反过来，更早版本的备份这一版都能读；更早版本导出的主题改名成 `.theme` 后也都能导入。

导入时这些情况会被拒绝，并说明原因，拒绝时什么都不留下：主题文件里超过 300 个文件（文件夹也算）、单个文件超过 32 MB、合计超过 64 MB（以前版本导出的主题也一样：原图是超过 32 MB 的照片时，先在旧版里换一张小些的图再导出）；主题图（竖屏和横屏裁好的那两张）边长超过 4096 像素，原图不限（4.0 主题的原图也限 4096 像素；自己的旧主题原图超过时，导出的 4.0 主题拿竖屏裁好的那张当原图）；按键图片边长超过 1024 像素或超过 2 MB；单独设置的按键超过 400 个；缺它用到的文件；图片或字体读不了；有文件和另一个主题的文件重名；主题是更新版本的幽默输入法做的；手机上已有同名主题而它是更新版本做的或读不了（这一版不替换它）。4.0 主题另外还会因为这些被拒绝：`theme.xml` 读不了（列出前几处错在哪一行）或超过 1 MB；要求更新版本的输入法（说明要哪个版本）；把 Shift、退格、空格或回车上的字隐藏了；名字和内置主题冲突，或以 `#light`/`#dark` 结尾；文件夹除了 `layouts/` 还有别的，或 `layouts/` 里还有文件夹；`theme.xml` 不在 zip 最外层（整个文件夹压进去的，提示 theme.xml 要放在最外层）；手机上已有 100 个 4.0 主题（先删掉一个；替换同名的不算）；用到主题文件夹以外的文件；样式超过 4100 条（单独设置了 400 个按键的旧主题导出后也能再导入）、字体超过 4 个、图标超过 200 个；图标超过 64 KB 或不是只有填充路径的简单 SVG；布局超过 16 个、单个超过 64 KB 或不是 `.xml`；预览图超过 512 KB 或边长超过 2048 像素。主题的文件要放在 zip 最外层，文件夹里的不算（Mac 压缩时带上的 `__MACOSX` 文件夹不影响导入）。手机上的 4.0 主题（比如恢复备份带来的）不合这些规则的（读不了、和内置主题同名、隐藏了必需按键上的字、缺文件）不列出，提示一次；4.0 主题用着时文件坏了，按内置主题画并提示。某个 4.0 主题第一次显示就让键盘崩溃的，下次启动时用到它的设置换回默认主题并提示，主题本身留着，可以删掉。

### 大小与样式

**大小**

| 选项 | 意思 |
|---|---|
| **键盘高度**（跟随主题） | 跟随主题 / 紧凑 / 矮 / 标准 / 高 / 很高。**跟随主题** 用主题里定的高度；主题没定（内置主题和 0.5 及以前做的主题都没定）就是标准。竖屏和横屏各有对应的高度（紧凑是竖屏 20%、横屏 34%，标准是 30%、49%）。键盘连同上面的候选栏最多占屏幕高度的约 70%，横屏选"很高"在矮的屏幕上也会留出输入框。**紧凑** 给小屏或想多看内容时用：键上的字小一号（九成；悬浮键盘本来就小的，取两者中小的；注音全键盘的符号再小一成，不然小屏上会被切掉），小字照样在 **标点位置** 选的地方，选"底部"时画在右上（快捷键在右上时画在右下），快捷键照样画在 **快捷键图标位置** 选的地方（选"底部"时画在第一个空着的角：左上、右上、左下、右下里标点没占的第一个），退格这类功能键上滑、下滑的都画，标记都小一号（某个键上放不下时先在自己的角里挪、再缩小，最后才不画，不换角，见[字母键](keyboard.md#字母键)）。在紧凑和其他高度之间切换时键盘重新生成一次（和换主题一样：打到一半的拼音清掉、不上屏，英文、手写打到一半的照原样上屏），其他高度之间切换只改大小。旧版本拖出来的高度不改，按最近的一档显示和生效。主题定的高度离紧凑最近时也算紧凑。 |
| **键盘两侧边距**（跟随主题） | 跟随主题 / 无 / 窄 / 宽。手大屏小时加宽能减少按到边上的键。跟随主题：主题定了就用主题的，没定就是无。 |
| **键盘底部边距**（跟随主题） | 跟随主题 / 贴底 / 无 / 少 / 多。全面屏手势条挡键时加一点。有的手机隐藏了手势条，键盘下面却还空着一条，选"贴底"让键盘贴到屏幕最下面；手势条或三键导航栏还在时，选"贴底"它会盖住最下一排键。跟随主题：主题定了就用主题的（加在导航栏上面，不算贴底），没定就是无。 |
| **编码行**（浮在键盘上方） | 打字时拼音（码表是编码，还有英文、拆字的提示）显示在哪。**浮在键盘上方**：打字时才出现一小条，贴在候选栏左上角外面，宽度跟着字变（最宽到键盘宽，再长就在条里横向滚动），盖在应用上，九成不透明；键盘本身少了这一行，比以前矮一点，按键高度不变；14 键、18 键、九键双拼的音节条也在这一条里，拼音左、音节右，所以换这些键盘时键盘高度不变。点条上的拼音照样移光标；条盖住的那一小块应用打字期间点不到，条外面照常能点。悬浮键盘、单手模式时条跟着键盘走；悬浮键盘拖到最上面放不下时条在键盘下面。**嵌在键盘里**：和 0.5.0 一样，候选栏上面固定留一行。实体键盘打字时用自己的浮动候选窗，不受这一项影响。改了马上生效。 |
| **候选字号**（20 sp） | 键盘上候选栏里字的大小，14–28 sp；联想词和展开的候选（⌄）跟着变；候选之间的空隙也跟着字号变，每个候选按字本身的宽度排，字小时一页放得下更多候选（单个字仍不窄于 32 dp，便于点）。字大了候选栏也跟着变高，按键不变，整个键盘跟着高一点；键盘已到屏幕高度的约 70% 封顶时，按键改为压矮。实体键盘的浮动候选窗另有 **浮动候选窗字号**。 |
| **分体键盘**（横屏且屏幕够宽时） | 字母键分成左右两半，每边 5 列，方便两个拇指打字，中间留空（和 Gboard 一样）；G、V 两边各有一个，哪只手都能按；空格横跨中间。屏幕越宽，中间留得越多，字母键宽度不变；中间最多留到键盘宽度的四成，屏幕再宽（多数手机横过来、平板），字母键就跟着屏幕变宽。默认手机横屏、平板横屏时分开，竖屏不分；也可以选总是或关。只影响全键盘（拼音、双拼、英文、码表），九键、拼音 18 键、拼音 14 键、双拼 18 键、双拼 14 键、九键双拼和手写不分（双拼 18 键和九键双拼整块靠一边）。 |
| **分体时其他面板**（靠右） | 分体时，数字键盘、九键、拼音 18 键、拼音 14 键、双拼 18 键、双拼 14 键、九键双拼、手写板、符号、表情、剪贴板这些面板连同工具栏缩成单手宽，靠右 / 靠左放，拇指够得着；选"铺满"就和不分体时一样占满整个宽度。屏幕太窄、键盘旁边放不下时（比如竖屏手机选了"总是"），面板也铺满。面板旁边的空白处有个箭头，点一下移到另一边，等于改这个设置。分体键盘选"关"时这一项不可用。 |
| **单手模式**（关） | 键盘不分体时，整个键盘缩到屏幕宽度的八成，靠右 / 靠左放，单手好按；旁边的箭头换边、斜箭头恢复全宽。工具栏 **⋯** 里也能开关。见[单手模式](keyboard.md#单手模式)。 |
| **悬浮键盘**（关） | 键盘缩小、浮在应用上面，按住拖动条拖到任意位置，拖到屏幕最下面再往下拖一点、松手就放回底部；应用不被顶起。工具栏 **⋯** 里也能开关。见[悬浮键盘](keyboard.md#悬浮键盘)。 |
| **悬浮键盘拖动条**（下面） | 悬浮键盘的拖动条放在键盘下面还是上面。没开悬浮键盘时也能先改好。 |
| **始终显示悬浮条**（关） | 键盘停在底部时也有那条拖动条（上面还是下面跟 **悬浮键盘拖动条** 走），按键行高度不变，整个键盘高出这一条（24 dp）；横屏等键盘已经顶到高度上限（约屏幕七成）时，按键行矮一点让出这一条，好让输入框还露得出来。长按条中间的短横，振一下，键盘就变成悬浮键盘停在手指下面，手指不松可以接着拖（拖进底部那条空位松手就又放回底部）。停在底部时条的右边没有按钮；单手或分体面板靠边时，条跟着键盘在那一边。见[悬浮键盘](keyboard.md#悬浮键盘)。 |

**按键样式**

按键的圆角、边框、间距默认跟随主题（见[主题](#主题)）；这里每项选别的就盖过主题里的，主题本身不变（导出的还是主题自己的样子，主题列表的缩略图也照主题画）。按下效果、描边、阴影、字体、各类键的颜色和图片只跟主题。键角小字的位置是[按键](#按键)里的 **标点位置**。

| 设置（默认） | 说明 |
|---|---|
| **按键边框**（跟随主题） | 有边框：键画成一块块的；无边框：平铺，没有键面（空格是一条、回车是个圆）；主题原本分块、候选栏是透明的，候选栏改成栏色（栏是主题图的照旧）。 |
| **按键间距**（跟随主题） | 紧凑 / 标准 / 宽松：键和键之间留多宽（横向 2 / 3 / 5 dp，纵向竖屏 5 / 7 / 9 dp、横屏 3 / 4 / 6 dp）。 |
| **按键圆角**（跟随主题） | 直角 / 圆角 / 大圆角（0 / 4 / 10 dp）。 |

从更早的版本升级时，原来的 **启用按键边框**、**按键间距**、**按键圆角** 第一次启动时存进正在用的主题（内置主题先复制成一个自己的主题再存，提示一次），这里三项是跟随主题，所以样子不变；动态取色主题不复制，这些样式存成它自己的，颜色照样跟壁纸变；换别的主题再换回来、重启都还在，长按导出时也带上。没能存进去的（存储满了等）下次启动再试，原来的设置一直留到存成为止。

## 按键

| 选项 | 意思 |
|---|---|
| **按键时弹出显示字符**（开） | 按下时在手指上方放大显示这个字符。 |
| **拼音键字母大小写**（跟随 Shift） | 中文输入法（全拼、双拼、九键、14/18 键、五笔等码表）键上字母画成大写还是小写：**总是小写** / **跟随 Shift** / **总是大写**。只改键面和按下时的气泡，打出的内容和 Shift 本身都不变；「总是小写」时 Shift 开着字母也是小写，看 Shift 键自己的样子知道开没开。跟随 Shift 时，全键盘按 Shift 变，九键和 14/18 键没有 Shift，字母照旧大写。英文输入法不受影响，总是跟着 Shift（那里大小写就是打出的字）。键角小字不受影响。读屏读的仍是原来的读法。改了马上生效（键盘重新生成一次），**按键字符和快捷键**、九键 **按键字母** 页和主题预览的键也跟着变。 |
| **滑动**（上滑快捷键，下滑符号） | 上滑、下滑各到哪一层：键角的小字（符号）还是这个键的快捷键，七种选法，也可以只开一个方向或全关。功能键（空格、退格……）的快捷键跟着开着的方向。见[字母键](keyboard.md#字母键)。从旧版升级时按原来的"划动输入标点符号及数字"换过来：下划 → 默认，上划 → 上滑符号下滑快捷键，禁用 → 关。 |
| **标点位置**（右上） | 键角小字（滑动打出的符号、数字）画在哪：右上 / 右下 / 左上 / 左下 / 底部（字母下面）/ 无（不画，滑动照样打出它）。所有键都画在这一处，和往哪边滑无关。「底部」在横屏、键盘高度选紧凑时键太矮，画在右上（**快捷键图标位置** 是右上时画在右下）。原来在 **外观 → 大小与样式**，升级后照原来的值（右上、底部、无）。 |
| **快捷键图标位置**（左上） | 键上画快捷键图标（文字快捷键缩小显示）的地方，和 **标点位置** 同一组选项：右上 / 右下 / 左上 / 左下 / 底部（键的下边中间；横屏、紧凑时键太矮，画在第一个空着的角：按左上、右上、左下、右下的顺序，跳过标点占着的）/ 无（不画，快捷键照样能滑）。所有键都画在这一处，和往哪边滑无关；功能键下滑的快捷键画在与它上下对称的地方（左上↔左下、右上↔右下、底部↔上边中间）。两项不能选同一个位置（都选「无」可以）：选一项时，另一项占着的位置是灰的、点不了，后面注「标点在这里」或「快捷键图标在这里」；另一项占着默认值时没有 **默认** 按钮。导入或恢复的设置里两项是同一个位置时，按标点让开读：同一侧上下对调（右上↔右下、左上↔左下），底部→右上；重启后就这样存下，设置页显示的和键盘上画的始终一致。字和标记碰上时怎么让、某个键上放不下时换到哪个角，见[字母键](keyboard.md#字母键)。两项改了马上生效（键盘重新生成一次），**按键字符和快捷键** 页的键也跟着变。 |
| **长按延迟**（中） | 按住多久算长按：短（0.2 秒）/ 中（0.3 秒）/ 长（0.45 秒）。 |
| **空格键长按行为** | 默认"语音输入"（按住说话；没导入语音包时长按空格什么都不做，导入后才能用，不用改这一项）。其他：轮换输入法 / 在当前输入法和第一个输入法之间切换 / 显示输入法选择对话框。 |
| **语音句末句号** | 默认"按输入框"：聊天里不加句号，搜索框和单行输入框里句末不加标点，其他照说的保留。其他：照说的保留 / 都不加。 |
| **划动空格键以移动光标**（开） | 在空格键上左右滑动来移动光标；字母键盘和数字键盘的空格都算。 |
| **显示语言切换键**（开） | 底排是否显示地球键。关掉后可以用空格长按切换输入法。 |
| **按键字符和快捷键** | 自定义每个键长按弹出的字符（第一个就是滑动打出的字符，也就是键上的小字），和滑动的快捷键。 |
| **工具栏按钮** | 键盘上方那一栏的按钮：拖动排顺序，勾选的才显示，分隔线下面的不用展开就在栏的右边；菜单键和 **…** 固定。默认就是原来的样子，右上角菜单可 **恢复默认**。见[工具栏](keyboard.md#工具栏)。 |

**按键字符和快捷键**的编辑：顶上一排分页（全键盘、九键、14 键、18 键、注音九键、注音全键盘、数字键盘、功能键），键上照键盘的样子显示键角符号和快捷键（命令是图标，文字快捷键缩小显示；小字在 **标点位置** 选的地方、快捷键在 **快捷键图标位置** 选的地方，选「无」的那个不显示，功能键下滑的快捷键在与它上下对称的地方；键盘高度是紧凑时小字不放字母下面）；每个键就是键盘上那个键按比例缩小的样子（字、标记一起缩），哪个标记留着、哪个放不下省掉都和键盘上一样，改过的描边；变淡的键长按不弹出字符，往符号那层滑等于点这个键，快捷键照常。全键盘页点一个键，弹出它的字符列表，可以 **设为首选**（放到第一个，成为键上的小字）、**左移**、**右移**、**删除**，或 **添加字符**（多个用空格分开）；下面一段是它的快捷键：不设、命令（点 **换** 选）或文字。别的分页点一个键只改快捷键，功能键页一个键有上滑、下滑两个。滑动设置把那一层关着时，段标题会说。**套用编辑快捷键** 把这一页的预设套回去（注音九键、数字键盘页没有预设，没有这个按钮），**清除这一页的快捷键** 把这一页全设成不设（两个都会先问一句）。数字键盘的键没有键角符号，快捷键标记的位置和键盘上一样；14 键、18 键的键角数字和符号也照键盘显示。**全部恢复默认** 只恢复长按字符，不动快捷键。改过的键可以恢复默认。

## 剪贴板与表情

### 剪贴板

| 选项 | 意思 |
|---|---|
| **记录剪贴板历史**（开） | 复制过的内容保存在键盘的剪贴板面板里。关掉后面板里不再增加新条目。 |
| **剪贴板历史记录上限**（10） | 最多保留多少条（置顶的不算）。超过的旧条目自动删除；调低后要删掉条目时先确认删几条，取消就不改。对话框里的 **无上限** 不删任何条目。条数设得太大可能会影响性能。 |
| **显示剪贴板提示**（开） | 刚复制了东西时，在键盘上方的栏里显示出来，点一下就粘贴。30 秒后消失。 |
| **粘贴后回到键盘**（开） | 在剪贴板面板里点一条粘贴后，面板收起，回到键盘。关掉后留在面板里，可以接着粘贴别的。 |
| **隐藏敏感信息（如密码）**（开） | 应用标为敏感的内容（密码管理器复制的密码等）在面板和提示里显示为圆点。 |
| **去除链接中的跟踪参数**（开） | 复制的链接存入剪贴板历史前，按 ClearURLs 规则清理。不改动系统剪贴板。 |

剪贴板历史只存在手机上。标为敏感的条目不会进备份文件。

## 备份与恢复

| 选项 | 意思 |
|---|---|
| **备份全部** | 把设置、用户词库（你的词、导入的词、固定、屏蔽、学到的顺序）、自定义短语、导入的词库、主题和剪贴板记录（复制过的密码也在内，但应用标为敏感的不在）存成一个文件 `youmo_<时间>.zip`。文件不加密，请自己保管好。 |
| **从备份恢复** | 选一个备份文件，确认后应用会自动重启。设置、自定义短语、快速输入、标点和剪贴板照备份覆盖（备份里没有的，手机上的也删掉：0.5.1 以前的备份没有快速输入，恢复它会删掉自己加的快速输入条目和使用顺序，关掉的自带表重新打开，恢复前的确认框里也这样说）；主题和导入的词库与手机上的合并；用户词库和学到的和手机上现在的**合并**，不覆盖，恢复前自动存一份现在的，可以退回，见[从备份恢复](words.md#从备份恢复)。 |

这一版备份里的主题是新格式：拿到更早的版本恢复，主题看不到，换回默认主题（见[主题](#主题)）。 4.0 主题也在备份里，恢复时备份里有的 4.0 主题整个换掉手机上同名的那个，手机上其他的 4.0 主题留着；更早的版本恢复后看不到它们。

学到的东西另有自动备份（每 7 个打字日一份），在 **词库与短语 → 用户词库** 里，见[备份](words.md#备份)。
