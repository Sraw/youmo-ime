打开"幽默输入法"应用就是设置首页；在键盘上点工具栏的 **…** 再点右上角齿轮也能进来。

首页右上角：

- **🔍 搜索**：按名字搜任何一个设置，点结果直接跳过去。
- **? 使用说明**：打开这份说明（在 GitHub 上，用浏览器打开）。
- **⋮ 菜单**：开发者、关于。

## 输入法

列出你在用的输入法，顺序就是在键盘上按地球键切换的顺序。

- 拖动左边的 **═** 调整顺序；右上角的笔进入编辑，可以删除；右下角 **+** 添加。
- 点一行右边的齿轮进入这个输入法的设置。
- 默认有拼音和英文；可以添加九键拼音、五笔、二笔、仓颉、自然码、双拼、五笔拼音、手写。

每个输入法的设置页只有它自己的选项；最上面一行写着"通用输入设置"，点它进入[通用输入](#通用输入)，联想、表情、滑行、档位这些各输入法共用的设置都在那里。

### 拼音

| 选项 | 意思 |
|---|---|
| **拆字**（开） | 先按 u 再打字的各部分的拼音，打出不会读的字：`uniuniuniu` 犇。只有全拼有。见[拆字](pinyin.md#拆字)。 |
| **中英混输**（开） | 拼音里直接打英文单词，比如 iphone 出 iPhone。只有全拼有。 |

### 双拼

| 选项 | 意思 |
|---|---|
| **双拼方案**（自然码） | 用哪种双拼：自然码、微软、紫光、智能 ABC、中文之星、拼音加加、小鹤、国标。 |

### 九键拼音

| 选项 | 意思 |
|---|---|
| **连按选字母**（关） | 打开后，快速连按同一个键就是它的第几个字母（按两下是第二个，再按下去轮回第一个），不再当成几个键；按一下仍由输入法判断是哪个字母；关着时每按一次都是一个键，输入法按上下文判断。关 / 快（0.4 秒）/ 中（0.6 秒）/ 慢（0.9 秒）：两次按键间隔在这个时间以内才算连按。1 键连按换标点也按这个设置，关掉就不换（九键英文的 1 键和连按打法总是连按，关着时按 0.6 秒算）。 |
| **九键英文打法**（预测） | 预测：每个键可以是它的任一个字母，输入法猜出整个词（4663 是 good、home、gone）；连按：快速连按同一个键是它的下一个字母，直接上屏。网址、邮箱和不要提示的输入框里总是连按（密码框里键盘自己换成全键盘英文）；关掉英文的 **单词提示** 时也是连按。九键英文用九键拼音的 **中/英** 键切过去，见[九键英文](keyboard.md#九键英文)。 |
| **按键字母** | 自定义每个数字键打出哪些字母，每键最多五个，可以重复。不在任何键上的字母，含它的拼音就打不出来。 |
| **按键长按** | 自定义长按 1–9 时多出的符号，每键最多十个，用空格分开，单个的数字或字母不能填（2–9 的长按已经有这个键的数字和大小写字母）。2–9 的符号排在数字和字母上面，默认是这个键几个字母在全键盘上的角标，开着中文标点时打出中文的；1 键的标点原样打出。清空就是这个键不加符号；改过的键可以重置。和全键盘的 **按键字符** 互不影响。 |

### 五笔等码表

五笔、二笔、仓颉、自然码、五笔拼音各有一页，选项相同，默认值不同：

| 选项 | 意思 |
|---|---|
| **只有一个候选时直接上屏** | 编码打满且只有一个字时直接上屏，不用按空格；再按下一个键打不出东西时，也直接上屏第一个候选。 |
| **显示编码提示** | 在每个候选旁显示还要按的键，方便学编码。 |
| **常用的字词排前面** | 打得多的字词往前排，重码还按前面打的内容排；关掉就严格按码表顺序（适合靠位置盲打的人）。五笔、五笔拼音的一、二级简码不受影响。 |
| **自动造词 · 最长造多少字的词** | 一个字一个字打出来的词，最多造到几个字：不自动造词 / 最多 2、3、4、6 个字 / 不限。 |
| **自动造词 · 造出的词何时记住** | 从候选里选过一次后 / 打过 1、2、3、5、10 次后。 |

各码表的默认值：

| 码表 | 编码提示 | 常用排前 | 最长造词 | 何时记住 |
|---|---|---|---|---|
| 五笔 | 开 | 开 | 最多 4 个字 | 打过 3 次后 |
| 五笔拼音 | 开 | 开 | 最多 4 个字 | 打过 3 次后 |
| 二笔 | 关 | 开 | 最多 4 个字 | 从候选里选过一次后 |
| 自然码 | 开 | 开 | 不限 | 从候选里选过一次后 |
| 仓颉 | 关 | 关 | 不限 | 从候选里选过一次后 |

"只有一个候选时直接上屏"默认都开。

### 手写

怎么写见[手写](other-input-methods.md#手写)。

| 选项 | 意思 |
|---|---|
| **停笔多久算写完一个字**（中） | 停笔超过这个时间，就算写完一个字、开始写下一个。很短（0.3 秒）/ 短（0.5 秒）/ 中（0.7 秒）/ 长（1 秒）/ 很长（1.5 秒）：写得快调短，写一个字中间常停顿的调长。 |

### 英文

| 选项 | 意思 |
|---|---|
| **单词提示**（开） | 显示以已打字母开头的单词，以及拼错时的改正；关闭后按键直接上屏。 |
| **句首自动大写**（开） | 在句子开头自动打开 Shift（应用的输入框要求时）。 |
| **英文词库** | 打过或添加的英文词，打的时候会给出；添加的和打过两次的不会被改错。可以搜索、添加、删除。 |

## 通用输入

各输入法共用的设置，改一次所有输入法都生效。从首页进，也可以从任何一个输入法设置页最上面那行"通用输入设置"进。某一项对哪些输入法不起作用，它的说明最后一句会写"不适用：……"。

### 所有输入法

| 选项 | 意思 |
|---|---|
| **滑行输入**（关） | 手指不离开键盘，依次划过一个词的键即可输入：英文、全拼、双拼划字母，九键划字母所在的数字键，码表划编码。网址、邮箱和密码框里不能滑：这些框里的内容不是词，滑行只会猜出错的词，密码框里也看不见滑错了什么。见[英文](other-input-methods.md#英文)、[拼音](pinyin.md#滑行输入)、[码表](other-input-methods.md#码表输入法五笔仓颉自然码二笔五笔拼音)。不适用：手写。 |
| **括号和引号成对输入，光标停在中间**（开） | 见[括号成对](keyboard.md#括号成对)。 |
| **点算式结果时替换整个算式**（关） | 打完算式和 `=` 后，栏上会显示结果（见[计算结果](keyboard.md#工具栏)）。关着时点结果，结果接在等号后面（`1+2*2=5`）；打开后点结果，整个算式连同等号换成结果（`5`）。 |

### 中文输入法

| 选项 | 意思 |
|---|---|
| **联想下一个词**（开） | 打完（写完）一个词，接着给出可能要打的下一个词。|
| **表情候选**（开） | 打的词有对应的表情时一并给出：哈哈 😄、点赞 👍；排在第三个候选起，码表里编码只有这个词、自己上屏时出在联想最前，点了替换这个词。见[表情候选](pinyin.md#表情候选)。不适用：手写。 |
| **自带的日期时间**（开） | 打出"日期""时间""星期"这几个词时，后面给出今天的日期、现在的时间、星期几（排法和表情一样）；全拼里打 `rq`、`sj`、`xq` 也出。关掉后这几条都不出，你自己加的自定义短语不受影响。不适用：手写。见[自带的日期时间](words.md)。 |
| **性能档位**（高档） | 低档：只按词频和搭配，最省电。中档：每次按键（手写是每写一笔）按整句通顺程度重排。高档：停顿时（手写是一个字写完时）再用大模型精挑首选，最准。档位越高越准，也越费电。|
| **中文标点** | 打中文时每个英文标点键对应哪个中文标点，可以编辑。"交替"指连按时轮换（比如引号左右交替），"可选"指同一个键还可以选的其他标点。|

### 拼音（全拼、双拼、九键）

| 选项 | 意思 |
|---|---|
| **纠正错拼和按偏的键**（开） | 比如把 gn 当成 ng，或按到了旁边的键。见[纠错](pinyin.md#纠错)。不适用：九键拼音。 |
| **模糊音**（未开启） | 勾选分不清的音：u↔v、an↔ang、en↔eng、ian↔iang、in↔ing、u↔ou、uan↔uang、c↔ch、f↔h、l↔n、l↔r、s↔sh、z↔zh。u↔v 对九键不起作用（u、v 在同一个键上），勾选框里也这样注明。见[模糊音](pinyin.md#模糊音)。 |

## 外观

上方是键盘预览，改了马上能看到。下面两页：

### 主题

点一个主题使用。**新增主题**："选择图片…"用一张图片做背景（可以调亮度、选深色按键、重新裁剪），"导入文件…"导入别人导出的主题，或"复制内置主题…"把一个内置主题复制成可以修改的自己的主题。自己加的主题：点上面的编辑按钮修改或删除，长按导出成文件；内置的动态取色主题也能长按导出，导出的是它的一份副本。开着 **跟随系统夜间模式**（默认开）时点主题不会换，而是提示不能手动更换，点 **禁用它** 就关掉跟随，同时换上点的那个主题。

### 大小与样式

**大小**

| 选项 | 意思 |
|---|---|
| **键盘高度**（标准） | 矮 / 标准 / 高 / 很高。竖屏和横屏各有对应的高度。键盘连同上面的候选栏最多占屏幕高度的约 70%，横屏选"很高"在矮的屏幕上也会留出输入框。 |
| **键盘两侧边距**（无） | 无 / 窄 / 宽。手大屏小时加宽能减少按到边上的键。 |
| **键盘底部边距**（无） | 无 / 少 / 多。全面屏手势条挡键时加一点。 |
| **分体键盘**（横屏且屏幕够宽时） | 字母键分成左右两半，每边 5 列，方便两个拇指打字，中间留空（和 Gboard 一样）；G、V 两边各有一个，哪只手都能按；空格横跨中间。屏幕越宽，中间留得越多，字母键宽度不变；中间最多留到键盘宽度的四成，屏幕再宽（多数手机横过来、平板），字母键就跟着屏幕变宽。默认手机横屏、平板横屏时分开，竖屏不分；也可以选总是或关。只影响全键盘（拼音、双拼、英文、码表），九键和手写不分。 |
| **分体时其他面板**（靠右） | 分体时，数字键盘、九键、手写板、符号、表情、剪贴板这些面板连同工具栏缩成单手宽，靠右 / 靠左放，拇指够得着；选"铺满"就和不分体时一样占满整个宽度。屏幕太窄、键盘旁边放不下时（比如竖屏手机选了"总是"），面板也铺满。面板旁边的空白处有个箭头，点一下移到另一边，等于改这个设置。分体键盘选"关"时这一项不可用。 |
| **单手模式**（关） | 键盘不分体时，整个键盘缩到屏幕宽度的八成，靠右 / 靠左放，单手好按；旁边的箭头换边、斜箭头恢复全宽。工具栏 **⋯** 里也能开关。见[单手模式](keyboard.md#单手模式)。 |
| **悬浮键盘**（关） | 键盘缩小、浮在应用上面，按住顶上的横条拖到任意位置；应用不被顶起。工具栏 **⋯** 里也能开关。见[悬浮键盘](keyboard.md#悬浮键盘)。 |

**按键样式**

| 选项 | 意思 |
|---|---|
| **启用按键边框**（开） | 每个键画成一个独立的块；关掉就是平铺的样式。 |
| **按键间距**（标准） | 紧凑 / 标准 / 宽松。 |
| **按键圆角**（圆角） | 直角 / 圆角 / 大圆角。悬浮键盘的四角跟着它：直角时是直角，否则按按键的圆角加上按键离边的间距算（关了 **按键边框** 时按键是方的，只按间距算）。 |
| **标点位置**（右上） | 键上小字的位置：无（不显示）/ 底部（仅限竖屏）/ 右上。 |

**白天与夜间**

| 选项 | 意思 |
|---|---|
| **跟随系统夜间模式**（开） | 系统切换深色模式时自动换下面两个主题；开着时不能在上面手动选主题（点主题会提示，可以就地关掉）。 |
| **亮色模式主题** | 系统是浅色时用哪个主题。 |
| **暗色模式主题** | 系统是深色时用哪个主题。 |

**动画**

| 选项 | 意思 |
|---|---|
| **禁用动画**（关） | 关掉键盘和面板切换时的动画。 |

## 按键

| 选项 | 意思 |
|---|---|
| **按键时弹出显示字符**（开） | 按下时在手指上方放大显示这个字符。 |
| **划动输入标点符号及数字**（下划） | 滑动字母键打出键角的小字：下划 / 上划 / 禁用。 |
| **长按延迟**（中） | 按住多久算长按：短（0.2 秒）/ 中（0.3 秒）/ 长（0.45 秒）。 |
| **空格键长按行为** | 文字版默认"无"，语音版默认"语音输入"（按住说话）。其他：轮换输入法 / 在当前输入法和第一个输入法之间切换 / 显示输入法选择对话框。 |
| **划动空格键以移动光标**（开） | 在空格键上左右滑动来移动光标；字母键盘和数字键盘的空格都算。 |
| **显示语言切换键**（开） | 底排是否显示地球键。关掉后可以用空格长按切换输入法。 |
| **按键字符** | 自定义每个键长按弹出的字符。第一个字符就是滑动打出的字符，也就是键上的小字。 |

**按键字符**的编辑：点一个键，弹出它的字符列表，可以 **设为首选**（放到第一个，成为键上的小字）、**左移**、**右移**、**删除**，或 **添加字符**（多个用空格分开）。改过的键可以恢复默认。

## 剪贴板与表情

### 剪贴板

| 选项 | 意思 |
|---|---|
| **记录剪贴板历史**（开） | 复制过的内容保存在键盘的剪贴板面板里。关掉后面板里不再增加新条目。 |
| **剪贴板历史记录上限**（10） | 最多保留多少条（置顶的不算）。超过的旧条目自动删除。 |
| **显示剪贴板提示**（开） | 刚复制了东西时，在键盘上方的栏里显示出来，点一下就粘贴。30 秒后消失。 |
| **粘贴后回到键盘**（开） | 在剪贴板面板里点一条粘贴后，面板收起，回到键盘。关掉后留在面板里，可以接着粘贴别的。 |
| **隐藏敏感信息（如密码）**（开） | 应用标为敏感的内容（密码管理器复制的密码等）在面板和提示里显示为圆点。 |
| **去除链接中的跟踪参数**（开） | 复制的链接存入剪贴板历史前，按 ClearURLs 规则清理。不改动系统剪贴板。 |

剪贴板历史只存在手机上。标为敏感的条目不会进备份文件。

### 表情

| 选项 | 意思 |
|---|---|
| **默认表情肤色**（无） | 人物和手势表情默认用哪种肤色：无（黄色）或五种肤色之一。 |

## 实体键盘

接蓝牙或 USB 键盘时用到：

| 选项 | 意思 |
|---|---|
| **显示候选窗口**（根据输入设备而定） | 系统默认 / 根据输入设备而定（接了实体键盘才显示）/ 禁用。 |
| **实体键盘快捷键**（开） | 单按 Shift 或 Ctrl+空格切换中英，Ctrl+Shift 轮流切换输入法。常误按 Shift 切走输入法（比如开了粘滞键），可以关掉；关掉后这几个键照常交给应用。 |
| **候选词列表方向**（自动） | 自动 / 横向 / 纵向。 |
| **候选词字体大小**（20 sp） | 候选窗里字的大小。 |
| **每页候选数**（7） | 光标旁的候选小窗一页放几个候选，3–10，按数字键选的就是这一页里的。所有输入法都用，包括英文。屏幕键盘的候选栏是横着滑的一整排，不分页，不受这个设置影响。 |

## 备份与恢复

| 选项 | 意思 |
|---|---|
| **备份全部** | 把设置、学到和添加的词、自定义短语、导入的词库、主题和剪贴板记录（复制过的密码也在内，但应用标为敏感的不在）存成一个文件 `youmo_<时间>.zip`。文件不加密，请自己保管好。 |
| **从备份恢复** | 选一个备份文件，确认后覆盖现在的全部数据，应用会自动重启。 |
