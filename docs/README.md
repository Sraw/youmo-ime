# 幽默输入法使用说明

幽默输入法是一个完全离线的 Android 中文输入法：拼音、九键、双拼、五笔等码表、英文，键盘上直接手写，导入语音包后还能说话打字。
所有输入都在手机上处理，不联网。

这份说明按"怎么用"组织。想知道某个设置是什么意思，直接看[设置逐项说明](settings.md)。
