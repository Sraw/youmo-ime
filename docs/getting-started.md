# 安装与上手

## 选哪个版本

安装包在 [GitHub Releases](https://github.com/Sraw/youmo-ime/releases)，每次发布有两个：

| 文件名含 | 版本 | 区别 |
|---|---|---|
| `text` | 文字版 | 只有打字。只申请振动权限。 |
| `voice` | 语音版 | 多了离线语音输入：按住空格说话。多申请录音权限，安装包大约多 180 MB。 |

两个版本都不联网，打字部分完全一样。只支持 64 位 ARM 手机（arm64-v8a），近几年的手机都是。
包名是 `io.github.sraw.youmo`，可以和上游的 Fcitx5 同时安装。两个版本互相覆盖安装，设置和学到的词都会保留。

下载后可以用 `SHA256SUMS.txt` 核对文件。

## 第一次打开

打开"幽默输入法"，会进入设置向导：

1. **启用输入法**：跳到系统的"屏幕键盘"设置，打开幽默输入法。系统会提示输入法可能收集你输入的文字，这是所有第三方输入法都会出现的提示；本输入法不联网，输入的内容不会离开手机。
2. **选择输入法**：在弹出的列表里选幽默输入法，把它设为当前键盘。

完成后进入设置首页。之后在任何输入框里都能直接用。

## 添加和排列输入法

默认有**拼音**和**英文**两个。要用九键、双拼、五笔等，在设置首页点 **输入法**：

- 右下角 **+**：添加输入法。可选九键拼音、五笔、二笔、仓颉、自然码、双拼、五笔拼音。
- 拖动左边的 **═**：调整顺序。
- 右上角的笔：进入编辑，删除不用的输入法。
- 每一行右边的齿轮：这个输入法自己的设置（见[设置逐项说明](settings.md#输入法)）。

在键盘上切换输入法：

- 点空格右边的**地球键**：按列表顺序切到下一个。空格键上会显示当前输入法的名字。
- 长按地球键：弹出系统的输入法选择框（也能切到别的输入法应用）。
- 九键拼音用自己的九宫格键盘，其他输入法用 26 键全键盘。

## 从旧版本换过来

本项目改名为幽默输入法之前，包名和上游一样是 `org.fcitx.fcitx5.android`。从那时的版本或上游 Fcitx5 换过来：

1. 在旧版的"高级"设置里导出用户数据（得到一个 `.zip`）。
2. 在本应用 **高级 → 从备份恢复** 里选这个文件。

设置、主题、剪贴板、自定义短语和导入过的词库会带过来。

- 从**上游 Fcitx5** 换过来：它的拼音（libime）学到的词和词频也在备份里，第一次用拼音时会读进来。
- 从**改名前的本项目**换过来：那时的备份不含引擎学到的词和词频，这部分要重新积累（现在的备份包含它们）。
- 以前导入过**新词包**（`.words` 文件）：包里的词现在随应用内置，这些文件在升级或恢复后会被删掉，词库页不再列出；停用过的词包也一样，它的词会照常出现，不想看到的词可以[屏蔽](words.md#用户词库)。

## 版本太旧时

新词随新版本发布（每月一版），应用不会自己联网更新。如果你装的版本里的数据已经超过半年，设置首页最上面会出现 **"这一版已超过半年"**，点它会打开下载页。
