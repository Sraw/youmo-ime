# 安装与上手

## 下载什么

从 0.6.0 起只有一个安装包。词典和模型不在安装包里，而在两个**资源包**（`.youmopack` 文件）里，装好应用后导入：

| 资源包 | 里面有 | |
|---|---|---|
| 文字包 | 拼音、英文、五笔等码表、笔画、句子模型、手写 | 必须有：没有它键盘不能打字 |
| 语音包 | 离线语音识别（按住空格说话，或点工具栏的麦克风说话） | 可选 |

[GitHub Releases](https://github.com/Sraw/youmo-ime/releases/latest)（最新版）每次发布有：

| 文件 | 内容 |
|---|---|
| `…-text.zip`（文字版） | 安装包 + 文字包 |
| `…-voice.zip`（语音版） | 安装包 + 文字包 + 语音包 |
| 单独的安装包和资源包 | 升级时，资源包没有新版本就只要下安装包；发布说明里写着这一版哪个资源包更新了 |

解开 zip，先装安装包。应用不联网，录音权限在你第一次用语音输入时才问。只支持 64 位 ARM 手机（arm64-v8a），近几年的手机都是。
包名是 `io.github.sraw.youmo`，可以和上游的 Fcitx5 同时安装。

下载后可以用 `SHA256SUMS.txt` 核对文件。

## 导入资源包

打开应用，在 **设置 → 资源包** 点 **导入资源包**，在文件选择器里选解开的 `.youmopack` 文件（可以一次多选）。还没导入文字包时，键盘上也会写"需要导入文字包才能打字"，点一下就到这一页。

- 导入时检查签名和每个文件，空间不够、文件坏了、不是这个应用的资源包都会说明，原来的资源包不受影响；导入到一半被打断也一样，下次打开时清理。
- 资源包复制进应用自己的目录，选的原文件不删，导入完可以自己删掉。
- 资源包有自己的版本号（v1、v2…），和应用的版本无关。应用要更新的资源包时，资源包页写"需要更新到 vN"，键盘或麦克风也会提示；资源包比应用新时，写"需要更新应用"。
- 升级应用（覆盖安装）资源包还在，不用重新导入；卸载应用会一起删掉。

## 第一次打开

打开"幽默输入法"，会进入设置向导：

1. **启用输入法**：跳到系统的"屏幕键盘"设置，打开幽默输入法。系统会提示输入法可能收集你输入的文字，这是所有第三方输入法都会出现的提示；本输入法不联网，输入的内容不会离开手机。
2. **选择输入法**：在弹出的列表里选幽默输入法，把它设为当前键盘。

完成后进入设置首页。导入文字包后（见上），在任何输入框里都能直接用。

## 添加和排列输入法

默认有**拼音**和**英文**两个。要用双拼、五笔、手写等，在设置首页点 **输入法**：

- 右下角 **+**：添加输入法。可选五笔、二笔、仓颉、自然码、双拼、五笔拼音、手写。
- 拖动左边的 **═**：调整顺序。
- 右上角的笔：进入编辑，删除不用的输入法。
- 每一行右边的齿轮：这个输入法自己的设置（见[设置逐项说明](settings.md#输入法)）。

在键盘上切换输入法：

- 点空格右边的**地球键**：按列表顺序切到下一个。空格键上会显示当前输入法的名字。
- 长按地球键：弹出系统的输入法选择框（也能切到别的输入法应用）。
- 手写用书写板，其他输入法默认用 26 键全键盘（横屏时可以分成左右两半，见[分体键盘](keyboard.md#横屏分体键盘)）。
- 拼音可以改用九键、18 键或两个字母一个键的 14 键：在拼音的齿轮里选 **键盘**，打字时也可以点工具栏 **⋯ → 键盘** 换（见[换键盘](keyboard.md#换键盘)）。双拼的齿轮里也有 **键盘**，可以选 18 键、14 键或九键（见[双拼](pinyin.md#双拼)）；英文可以选九键。
- 接了蓝牙或 USB 键盘时，怎么打字、怎么切换见[实体键盘](keyboard.md#实体键盘)。

## 从旧版本换过来

从 **0.5.x** 升级：直接覆盖安装，设置、学到和添加的词都在；升级后键盘提示导入文字包，导入后照常打字（以前用语音版的，再导入语音包）。

本项目改名为幽默输入法之前，包名和上游一样是 `org.fcitx.fcitx5.android`。从那时的版本或上游 Fcitx5 换过来：

1. 在旧版的"高级"设置里导出用户数据（得到一个 `.zip`）。
2. 在本应用 **备份与恢复 → 从备份恢复** 里选这个文件。

设置、主题、剪贴板、自定义短语和导入过的词库会带过来。

- 从**上游 Fcitx5** 换过来：它的拼音（libime）学到的词不再读进来，要重新积累。
- 本应用 0.3.0 及更早版本的备份不能直接恢复：先装 0.4.x，在那里恢复、打几个字、停一下、重新备份，再在这一版恢复新的备份。
- 从**改名前的本项目**换过来：那时的备份不含引擎学到的词和词频，这部分要重新积累（现在的备份包含它们）。
- 以前导入过**新词包**（`.words` 文件）：包里的词现在随应用内置，这些文件在升级或恢复后会被删掉，词库页不再列出；停用过的词包也一样，它的词会照常出现，不想看到的词可以[屏蔽](words.md#用户词库)。

## 版本太旧时

新词随新版本发布（每月一版），应用不会自己联网更新。如果你装的版本里的数据已经超过半年，设置首页最上面会出现 **"这一版已超过半年"**，点它会打开下载页。
